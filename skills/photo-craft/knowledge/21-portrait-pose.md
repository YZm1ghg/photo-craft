## 1. 一张人像先看什么（现场 5 秒自检）

按**优先级**排序 —— 前面的垮了，后面的再好也救不回：

1. **眼睛实不实**（对焦在近侧眼）→ 不实 = 废片
2. **表情对不对**（眼神有没有聚焦、嘴角是否僵硬）
3. **光对不对**（脸上有没有干净的过渡、有没有难看的阴影切在脸上）
4. **姿态顺不顺**（有没有僵直、关节正对镜头、手不知道放哪）
5. **背景乱不乱**（有没有抢戏元素、头上有没有"长东西"）
6. **裁切合不合理**（没切关节、没切头顶）

**一条铁律**：宁可一张"普通但干净"的片子，不要一张"有想法但脏乱"的片子。

## 2. 焦段选择速查

| 焦段 | 人像效果 | 适用 | 注意 |
|---|---|---|---|
| 24-35mm | 环境人像、有生活气息、腿长 | 街拍人像、旅拍、大长腿 | 近距畸变严重，别怼脸 |
| 50mm | 接近人眼、自然 | 半身、入门挂机 | 距离需要近，脸型一般 |
| **85mm** | 人像黄金 | 特写/半身、脸型最友好 | 需要退后，室内可能不够 |
| 135mm | 压缩强、虚化奶油 | 特写、抓表情、远距偷拍 | 需要更大距离 |
| 70-200mm | 灵活 | 外拍主力 | 重、显眼 |

**脸型急救**：脸宽 → 换更长焦段 + 机位略降 + 脸侧转 15-30°。

## 3. 摆姿底层几何（记住这 5 条就能救 80% 的僵姿势）

1. **重心落在一条腿上**（后脚承重），另一条腿放松 —— 立刻消除"立正"
2. **身体侧转 15-45°**，不要正对镜头 —— 立刻瘦 5 斤
3. **肩线与胯线不要平行**（一侧高一侧低）—— 消除呆板
4. **手"有事做"**：插兜露拇指、撩发、扶帽、拿道具、搭肩、抚领 —— 避免无处安放
5. **关节不正对镜头**（肘、膝、腕都微弯侧向）—— 避免"断肢感"

**三不原则**：不僵直、不对称、不重复。

**下巴与视线**：下巴微收（不是低头）避免双下巴；讲话时略抬头提神。
视线方向：看镜头 = 交流感；看镜头外侧 30-45° = 思考感；看远处 = 故事感。

## 4. 常用口令（可直接照念，完整 51 条在 references）

| 你想调整 | 这样说 |
|---|---|
| 站位 | "侧过身去，对，肩膀朝我这边一点，来，重心放到后面那条腿上" |
| 手 | "手插兜里，把拇指露出来，对，就这样，别动" |
| 头 | "下巴收一点点……太多了，回来一点点，好" |
| 视线 | "眼睛看我左手，对，别动，看着我手指尖" |
| 笑 | "别笑，先别笑……（数三下）好，笑！" |
| 放松 | "深呼吸，肩膀放松，往下沉，对，吐气的时候我们拍" |
| 走起来 | "往前走，慢慢走，走到我数三的时候回头看我" |

**引导真笑的秘诀**：让被摄者**先不笑**，说一句真逗的话（或做怪动作）在按下快门前一瞬间触发。
假笑 = 只有嘴动；真笑 = 眼角有纹、苹果肌上提。**眼角不动就是假笑。**

## 5. 不同题材的机位与要点

| 题材 | 焦段 | 机位 | 核心要点 |
|---|---|---|---|
| 个人写真 | 35/50/85 | 眼平为主 | 先聊 10 分钟再拍；给明确口令；每套服装换 2 个场地 |
| 情侣 | 35/50/85 | 眼平 | 少喊"看镜头"；让他们**互动**（说话/打闹/耳边说悄悄话），你抓 |
| 家庭 | 35/50 | 蹲下来和孩子同高 | 排列不要排排站；让家人自然坐着/靠着 |
| 儿童 | 35/50 | **必须蹲下** | 玩具吸引、连拍抓表情、单次不超过 40 分钟 |
| 孕妇 | 85/135 | 略低（仰拍显肚子） | 侧身展示肚型、手护肚、逆光勾轮廓 |
| 证件/商务 | 85/105 | 严格眼平 | 光要正（双灯平衡）、背景统一、表情中性微收下巴 |
| 古风/主题 | 35/85 | 视风格 | 服装道具先行、环境选景优先、善用逆光与烟饼 |
| 街拍 | 35/50 | 眼平/盲拍 | 预判 + 连拍；侧逆光最有味道；先构好图等人进画 |
| 旅拍 | 24-70 | 变化 | 环境占 1/3 以上；不要只拍脸，要拍"人在这个地方" |

## 6. 儿童专项速记

| 年龄 | 行为特征 | 策略 |
|---|---|---|
| 0-1 岁 | 不可控、爱睡、脖子软 | 安全第一、家长在身边、等状态、用声音吸引 |
| 1-3 岁 | 到处跑、注意力 1 分钟 | **连拍**、追着拍、玩具/食物引诱 |
| 3-6 岁 | 能听懂指令、爱表现 | 讲游戏、给任务（"帮我数一下有几个"） |
| 6-12 岁 | 有自己想法、会僵硬 | 当大人对待、聊兴趣、避免"笑一个" |

**安全红线**：不让孩子站在高处边缘、不做危险道具、家长必须在视线内、注意道具小零件。
**哭闹处理**：先停拍 → 让家长安抚 → 换个环境或换道具 → 不要硬拍哭脸（除了刻意要的情绪片）。

## 7. 翻车诊断（快速版，完整 36 条在 references）

| 症状 | 原因 | 修正 |
|---|---|---|
| 脸大/脸圆 | 机位过高 + 广角近距 | 换 85mm、机位降到眼平、脸侧转 15-30° |
| 双下巴 | 下巴过低 + 机位过低 | 下巴前送微收、机位抬到眼平略上 |
| 身体僵直 | 立正站姿 | 侧转 + 单腿承重 + 手找事做 |
| 腿短 | 机位太高 | 机位降到腰部、略仰拍、脚向镜头伸出 |
| 手臂显粗 | 手臂贴紧身体被压扁 | 手臂离开身体（留缝隙）、侧向镜头 |
| 表情假 | 喊"笑一个" | 先不笑，用话题/动作触发真笑，抓拍 |
| 眼睛不亮 | 光位太正/缺少眼神光 | 加眼神光源（灯/反光板/窗口），调角度至瞳孔出现亮点 |
| 背景杂乱 | 机位单一 | 移动机位、换焦段、拉开主背景距离、后期压暗 |
| 肤色脏 | 混合光源白平衡乱 | 统一光源色温、校白平衡、分开处理人物与背景 |
