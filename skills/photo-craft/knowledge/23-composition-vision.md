## 1. 构图的本质

**构图不是套公式，是控制观众先看什么、再看什么。**
拍照是**减法**：不是往画面里加东西，是把不重要的东西移出去。

**眯眼验证法**：眯起眼睛看画面——如果主体还是第一眼被看到，主体够突出；
如果背景跳出来，就要处理背景。

## 2. 十一法速查（含"什么时候别用"）

| 构图法 | 怎么用 | 什么时候**不要**用 |
|---|---|---|
| 三分法 | 主体放在九宫格交点 | 需要中心对称/极简时——中心构图更有力 |
| 中心对称 | 主体压正中 | 画面本来就很乱时，中心会更呆 |
| 对角线 | 主体/线条沿对角排 | 需要稳定庄重时（对角=动感） |
| 引导线 | 用路/栏杆/光带把视线引向主体 | 引导线指向画面外（把观众带跑） |
| 框架式 | 用门窗/树枝框住主体 | 框架本身很抢戏（喧宾夺主） |
| 留白 | 主体周围大面积空白 | 留白没意义时（空≠好，空要有用） |
| 重复与韵律 | 相同元素规律排列 | 完全无变化（死板）——要破一个 |
| 对比 | 大小/明暗/色彩/虚实/动静 | 对比过多（画面打起来） |
| 三角构图 | 三个元素成三角，稳定 | 三角过于对称（呆板） |
| 黄金分割 | 比三分法更精细的分配 | 拘泥到影响拍摄速度 |
| 填充画框 | 主体占满画面 | 需要交代环境时 |

**关键认知**：这些是**结果描述**，不是**操作指令**。
真正的操作是：移动机位 → 观察画面变化 → 选择更好的一版。

## 3. 层次与纵深（让照片"立起来"）

前后层次 = 前景 / 中景（主体）/ 背景。**有前景的照片立刻有纵深。**

营造纵深的 7 个手段：
1. **加前景**（树枝、栏杆、草、窗框）
2. 线性透视（路、桥、走廊向远处收束）
3. 空气透视（远处发灰、发淡——用好雾气）
4. 重叠遮挡（一个物体挡住另一个 → 立刻有前后）
5. 大小对比（远小近大）
6. 虚实对比（前虚后实 / 前实后虚）
7. 光影分层（亮-暗-亮 或 暗-亮-暗）

---

## 4. 人像构图红线

- **不切关节**（腕、肘、膝、踝）—— 产生截肢感
- **不切头顶**（要么留出整个头，要么切在额头以上）
- **下巴与画框保留呼吸空间**（不要刚好卡在下巴）
- 视线前方留出**更多空间**（看向左边 → 左边留白）——否则"撞墙"
- 主体**不要正压正中**（除非刻意对称），也不要贴边
- 背景里的**竖线不要从头顶长出来**（柱子、树、灯杆）

## 5. 构图诊断（快速版，完整 25 条在 references）

| 症状 | 原因 | 修正 |
|---|---|---|
| 画面散、不知道看哪 | 多个视觉中心竞争 | 明确唯一主体，压暗/移除次要元素 |
| 主体不突出 | 主体与背景反差不足 | 换机位让背景干净、拉开主体与背景距离、用虚化 |
| 照片"平" | 缺前景/缺纵深 | 加前景、改用侧向机位制造透视 |
| 头顶"长树" | 背景竖线与头顶重合 | 平移机位半步或蹲下 |
| 画面闷 | 没有留白/主体太大 | 退后、让主体占比降到 1/3~1/2 |
| 画面空 | 留白没内容 | 缩小画面、加前景、或换长焦压缩 |
| 地平线歪 | 手持未校平 | 开电子水平仪、后期校正 |
| 地平线居中把画面切成两半 | 未做取舍 | 要么抬高（留地），要么压低（留天） |
| 手臂被切一半 | 画框切在关节 | 退后或改变裁切位置 |
| 人物"撞墙" | 视线方向留白不足 | 让视线前方留出更多空间 |
| 照片呆板 | 完全对称/完全居中/水平线全平 | 打破一处：侧转、倾斜、错位 |

## 6. 观看与审美训练

**每天看片的正确方法**（不是"刷图"）：
1. 选 1 位摄影师，看 20 张他的作品
2. 问三个问题：他的**光**怎么用？**机位**在哪？**取舍**了什么？
3. 挑 1 张，写下"如果是我会怎么拍"
4. 一周后回看自己写的东西

**从模仿到个人语言**：
- 模仿阶段：一比一复刻，**连参数机位都还原**（学的是决策，不是形式）
- 找出母题：你反复被什么吸引？（孤独感？肌理？光斑？关系？）
- 做系列：同一母题拍 30 张以上，风格会自己浮现
- **不要过早定型**：前两年多试，别急着说"我只拍 XX"
