# 知识卡 · 用光与闪光灯地图

> 展开看 `references/lighting-flash.md`；要原文出处则检索你自己的书库（见 `references/library-map.md` §三）。

---

## 1. 看光四步（到任何现场先做这四件事）

1. **找主光方向**：光从哪来？（窗/太阳/灯）→ 决定机位与脸朝向
2. **判光质**：硬还是软？看阴影边缘 —— **边缘锐利 = 硬光；边缘渐变 = 柔光**
3. **量光比**：亮部与暗部差几档？测光分别测脸亮面与暗面
4. **定色温**：是暖是冷？和环境是否冲突？

**柔光的本质**：光源相对被摄体的**视觉面积越大，光越柔**。
所以"把柔光箱移近"比"换更大的柔光箱"更有效（近 = 相对更大）。

## 2. 光位速查（人像最常用 5 种）

以脸为钟面，相机在 6 点位置：

| 光位 | 位置 | 效果 | 适用 |
|---|---|---|---|
| **顺光**（正面光） | 相机附近 | 平、无立体感、少阴影 | 证件照、需要干净无瑕 |
| **前侧光 45°** | 10 点或 2 点 | 有立体感又保留细节 | **最安全的人像光位** |
| **侧光 90°** | 9 点或 3 点 | 明暗对比强、戏剧化 | 男性、性格片、艺术人像 |
| **侧逆光 135°** | 10-11 点或 1-2 点 | 边缘光勾轮廓、层次好 | **最有质感的人像光位** |
| **逆光 180°** | 主体背后 | 剪影、发丝光、朦胧 | 小清新、梦幻、轮廓表达 |

**顶光**（正午阳光下）→ 眼窝黑、鼻下阴影重 → 抬头、用反光板补下巴、或换到阴影里。
**底光**（从下往上）→ 恐怖/诡异 → 慎用，除非刻意。

## 3. 光比（lighting ratio）

亮部与暗部的**档位差**：

| 光比 | 档差 | 感觉 | 用途 |
|---|---|---|---|
| 1:1 | 0 | 平、无立体 | 证件照、高调 |
| **1:2** | 1 档 | 自然、柔和 | **最常用人像** |
| 1:3 | 1.5 档 | 立体感明显 | 大多数写真 |
| 1:4 | 2 档 | 强对比、有性格 | 男性、戏剧 |
| 1:8 以上 | 3+ 档 | 低调、暗调 | 艺术、氛围片 |

**怎么控光比**：调辅光强度（或加/减反光板），不是动主光。

---

## 4. 反光板速查

| 颜色 | 效果 | 用途 |
|---|---|---|
| 白色 | 柔和中性补光 | **最常用**，降光比 |
| 银色 | 强、冷、反差大 | 需要强补光但无电时 |
| 金色 | 暖、强 | 制造暖调、日落感 |
| 黑色（吸光板） | 加深阴影 | **增加光比**、塑造轮廓 |
| 柔光板（透光） | 把硬光变软 | 正午阳光下柔化 |

**距离法则**：反光板越近，补光越强（平方反比）。放在颧骨高度、朝上 30-45° 补下巴阴影。

## 5. 经典人像光型（一灯起手）

| 光型 | 主灯位置 | 特征 | 适合脸型 |
|---|---|---|---|
| **蝴蝶光 / 派拉蒙** | 正前方，**高位 45°** 向下 | 鼻下蝴蝶形阴影 | 颧骨高、脸型立体；**不适合宽脸** |
| **伦勃朗光** | 前侧 45°，略高 | 暗面颊上有一个**三角光斑** | 通用、有戏剧感 |
| **环形光** | 前侧 30-40°，与眼平齐 | 鼻影在鼻翼旁成小环 | 通用、最保险 |
| **分割光** | 正侧 90° | 半边亮半边暗 | 戏剧、男性、强性格 |
| **宽光** | 光打在**朝向镜头**的那半边脸 | 脸显宽 | 脸窄的人 |
| **窄光** | 光打在**背向镜头**的那半边脸 | 脸显窄 | **脸宽的人首选** |
| **轮廓光/发丝光** | 主体后方，勾边缘 | 与背景分离 | 任何场景加分离度 |
| **眼神光** | 让瞳孔出现一个亮点 | 有神、有生命 | **几乎所有好的人像都有** |

## 6. 热靴闪光灯速查

- **GN（闪光指数）**：`GN = 光圈 × 距离（米，ISO100）` → `光圈 = GN ÷ 距离`
  例：GN 36 的灯，距离 4m → f/9
- **同步速度**：普通同步通常 1/200s 或 1/250s（机身限制），超了会出现黑边
- **高速同步（HSS/FP）**：可超过同步速度 → **代价是损失约 1.5-2.5 档闪光功率**
- **跳闪（bounce）**：灯头打向天花板/墙壁 → 光变大变柔，**室内最实用的一招**
- **慢速同步**：用慢快门记录环境光 + 闪光凝住主体 → **夜景人像必用**
- **前帘/后帘同步**：后帘同步让运动轨迹拖在主体后面，更自然

## 7. 压光（白天户外用闪的核心）

**为什么压光**：白天环境光很亮，直接闪光只会把人打得"油亮"且背景过曝。
压光 = 用**小光圈 + 快快门**把环境光"压暗"到合适，再用闪光给主体正确曝光。

**实操步骤**：
1. 先不管闪光，调到 **M 档**，让**背景**曝光比正常**欠 1-2 档**（背景会被压暗、色彩更浓）
2. 打开闪光灯（TTL 或手动），调闪光功率让**主体**曝光正常
3. 检查：主体亮、背景稍暗、边缘有勾边 → 成功
4. 需要超过同步速度 → 开 HSS（并接受功率损失）

**一句话记忆**：**快门管环境，光圈管闪光**（同步速度内）。

## 8. 常见题材用光方案（速查）

| 题材 | 方案 |
|---|---|
| 日系小清新 | 侧逆光 or 逆光 + 反光板补脸；高调曝光（+0.7）；低对比 |
| 商务/证件 | 双灯 45°/45° 对称，或单灯 + 两侧反光板；光比 1:1~1:2 |
| 逆光氛围 | 逆光（太阳在主体后）+ 反光板/闪灯补脸，避免脸全黑 |
| 夜景人像 | 慢速同步：慢门记环境色 + 闪光打人脸；用 CTO 暖光贴肤色 |
| 棚拍单人 | 主灯 45°高位 + 辅光对侧 + 发丝光 + 背景光，四灯齐全 |
| 婚礼仪式 | 尽量自然光；暗场用跳闪（打天花板）；抓拍优先，别频繁爆闪 |
| 婚礼宴会 | 跳闪 + 慢速同步保留氛围；避免直闪把人打成油脸 |
| 儿童 | 自然光优先（窗口/阴影）；避免直闪伤眼；必要时跳闪 |
| 商品静物 | 柔光箱侧上方 45° + 对侧反光板；高反光要控反光（见 commercial） |

## 9. 用光诊断（快速版）

| 症状 | 原因 | 修正 |
|---|---|---|
| 脸太平、没立体 | 光位太正 / 光比不足 | 主灯侧移 15-45°、降低辅光、把光比做到 1:2~1:3 |
| 脸一半全黑 | 光比过大 | 加反光板或辅光 |
| 眼窝黑（顶光） | 正午顶光 | 让被摄者抬头、补下巴、或移到阴影 |
| 鼻影难看 | 主灯过高 | 主灯降到略高于眼平、或改侧位 |
| 双下巴阴影重 | 光位太低太正 | 抬高主灯 30-45°，下巴微前送 |
| 眼神呆 | 没有眼神光 | 加灯/反光板/靠窗口，调角度直到瞳孔有亮点 |
| 逆光脸全黑 | 只测到背景 | 对脸点测光 + 补光/闪光，或拍剪影（刻意） |
| 闪光打得油亮 | 直闪 + 灯在轴上 | 灯离机 45°、跳闪、加柔光罩 |
| 夜景人脸惨白 | 闪光过强 + 色温不匹配 | 降闪光功率、加 CTO 暖片、用慢速同步 |
| 背景过曝没人压住 | 没压光 | 按 §7 压光三步：先压背景 1-2 档再补主体 |
| 光斑/杂反光 | 环境反光（水面/玻璃/白桌） | 换角度、加旗板遮光、用偏振镜 |
| 每张明暗不一 | 环境光在变/自动模式 | 改 M 档固定参数；补光用恒定功率 |
