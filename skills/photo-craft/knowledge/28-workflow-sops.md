> 展开看 `references/workflow-sops.md`。要原文出处则检索你自己的书库（见 `references/library-map.md` §三）。

---

## 1. 项目生命周期

`需求确认 → 策划 → 器材准备 → 现场执行 → 素材管理 → 修图 → 交付 → 复盘`

每个阶段的**产出物**：需求单 → shot list + 场地踩点 → 器材清单 → 素材包 → 选片 → 成片 → 交付清单 → 复盘笔记。

---

## 2. 拍摄前必问的 15 个问题

1. 用途是什么？（自用/社交/印刷/电商/参赛）
2. 想要什么**风格**？有参考图吗？
3. 需要**多少张**成片？
4. **什么时候**要？最晚交付时间？
5. 拍摄**场地**在哪？需要我踩点吗？
6. **几个人**拍？大人小孩老人？
7. **服装**谁准备？几套？
8. 需要**化妆师**吗？谁负责？
9. **预算**范围？
10. 版权与**使用授权**范围？
11. 可以公开发布吗？（很多客户不想被展示）
12. 交通/停车/进场是否方便？
13. 场地有**时间限制**吗？
14. 有特殊要求或**禁忌**吗？（不能拍的角度、宗教/习俗）
15. 付款方式与**定金比例**？

> 问不完就减少；但**用途、风格、数量、交付时间、预算**这 5 个必须问。

## 3. 器材准备检查表（出门前必做）

**必查**
- [ ] 电池（机身 + 闪光灯）——**至少 2 块满电**
- [ ] 存储卡——**格式化过的空卡**，且带备用
- [ ] 镜头清洁（气吹 + 布）
- [ ] 参数复位（上一位用户/上次的设置可能还在）
- [ ] 机身时间与日期正确
- [ ] 备份方案（双卡双机 / 至少双卡）

**按题材加带**
| 题材 | 加带 |
|---|---|
| 人像 | 反光板、85mm、道具 |
| 婚礼 | 双机、闪光灯 + 备用灯、电池 ×4、卡 ×4 |
| 儿童 | 玩具、快速对焦镜头、高 ISO 可用机身 |
| 商品 | 三脚架、快门线、柔光箱、色卡、背景纸 |
| 风光 | 三脚架、ND/GND、快门线、保暖 |

## 4. 现场三十分钟流程

1. **提前到**（至少 20-30 分钟）
2. 绕场地一圈，找 **3 个可用机位**与光的方向
3. 试拍（对模特/客户）——检查曝光、白平衡、对焦
4. 开场沟通：说明拍摄流程、看一张试拍片建立信任
5. 从最容易的**热身**开始（不要一上来就要求高难度）

---

## 5. 素材管理（3-2-1 原则）

**3 份拷贝，2 种介质，1 份异地**

- 现场：**边拍边导**（至少拍完立即导），**不要格式化卡直到确认落盘**
- 目录规范：`日期_客户_题材/` 下分 `RAW/`、`选片/`、`成片/`
- 命名：`20250930_客户名_001.CR3`
- **原始文件只读**，所有调整在副本上做

## 6. 交付检查清单

- [ ] 数量符合约定
- [ ] 尺寸与色彩空间正确（**网络发布必须 sRGB**）
- [ ] 水印/署名（如约定）
- [ ] 没有明显废片混进去
- [ ] 私有照（如客户要求）已确认不外传
- [ ] 备份已完成
- [ ] 交付沟通（发送方式 + 说明 + 后续沟通渠道）

## 7. 应急手册（现场救急）

| 状况 | 当机立断 |
|---|---|
| 灯不闪了 | 换备用灯；先靠环境光 + 高 ISO 顶住关键瞬间 |
| 卡满了 | 现场删废片 / 换卡；**绝不格式化正在用的卡** |
| 电池没电 | 换备用；关闭防抖/降低回放省电 |
| 相机摔了 | 先检查能否开机、镜头是否错位；能拍就继续，用备用机身 |
| 客户迟到 1 小时 | 顺势利用：先用available light 拍环境/细节；调整后续时间表 |
| 下雨 | 转室内或找有顶空间；雨伞反成道具；先保护器材 |
| 白平衡全错 | 拍 RAW 都能救；拍 JPEG 的话记录一张灰卡/白纸作为后期参考 |
| 模特/孩子情绪崩 | **停拍**，给空间与时间；改拍不需要情绪的内容（手/细节/环境） |
| 场地突然不让拍 | 礼貌沟通 + 备选场地方案；先拍好已允许的部分 |
| 存储卡读写错误 | 停止使用该卡，换卡；用恢复软件抢救（不要再写入） |
| 环境光急剧变化 | 改 M 档固定参数，或接受环境变化（拍成系列也行） |
| 忘了带关键器材 | 明确告知客户并给替代方案（如用反光板代替补光灯） |

## 8. 训练四阶段

| 阶段 | 目标 | 关键动作 |
|---|---|---|
| **0-3 月** | 参数自动化 | 每天 20 张同主题；眼睛必实训练 |
| **3-12 月** | 找到题材 | 选定 1 个题材拍系列；每次写 shot list |
| **1-3 年** | 形成风格 | 3 组命题拍摄；建作品集；每月看画册 |
| **3 年+** | 商业化 | 报价体系、合同、客户管理、稳定出片 |

**停滞的四个原因**：不复盘、不练审美、只拍一种、不敢给人看。

## 9. 预算档位建议

| 档位 | 机身 | 镜头 | 灯 | 逻辑 |
|---|---|---|---|---|
| **入门**（5k-1w） | APS-C 套机 | 套头 + 50/1.8 | 1 支热靴灯 | 先练技术，别先买器材 |
| **进阶**（1.5w-3w） | 全画幅 | 35 + 85 定焦 or 24-70 | 2 支灯 + 引闪 | 定焦提画质，双灯开始玩光 |
| **职业**（4w+） | 全画幅 ×2（双机） | 24-70/2.8 + 70-200/2.8 + 85/1.4 | 3-4 灯 + 各种控光 | 双机避免换镜丢瞬间 |

**取舍**：宁可**机身便宜、镜头好**；灯和控光器材的投资回报远高于机身。
二手镜头性价比高，但闪光灯与机身买新更稳。
