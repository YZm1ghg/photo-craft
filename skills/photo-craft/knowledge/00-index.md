## 2. 两类问题，两种答法

**A 类：技法问题**（"这个光线怎么打""怎么引导她笑"）
→ 直接给**可执行方案**：光位/参数/话术/机位，配上"为什么"。
先读 `references/` 对应模块，再回 `22/21/23` 知识卡交叉验证。

**B 类：出处问题**（"哪本书讲过这个""原文怎么说的"）
→ 走 `corpus/tools.py search`，给**书名 + 页码 + 原文摘录**。

**C 类：评析问题**（"这张照片哪不对""我的片子为什么平"）
→ 走**五层诊断**（见 `SKILL.md` §1），逐层排除，落到具体动作。

## 3. 检索速查

```bash
cd <photo-craft 技能目录>/corpus
python tools.py list                       # 已抽取书目状态
python tools.py search "眼神光"             # 全库检索
python tools.py search "压光" --book 热靴     # 单书检索
python tools.py read 7 120 124             # 读某本 p120-124
python tools.py index                      # 重建章节索引 out/index.json
```

`out/index.json` = 每本书的页数/字符数/**章节标题列表**，用来快速定位"哪本书哪一章讲这个"。
