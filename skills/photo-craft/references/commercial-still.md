## 0. 商业摄影的判断标准

### 0.1 客户花钱买的是什么

商业摄影不是"拍得好看"，是"拍得能用"。客户付款买的是四样东西，按优先级排序：

| 优先级 | 要素 | 具体含义 | 不合格的后果 |
|---|---|---|---|
| 1 | **准确** | 颜色不偏、形态不变形、材质不撒谎、数量无误 | 客户收到货投诉"和图片不一样"，退货率上升 |
| 2 | **质感** | 该亮的地方有高光、该暗的地方有层次、材质能被一眼识别 | 图片看起来"平"，点击率低 |
| 3 | **调性** | 与品牌定位一致（高端冷调 / 亲民暖调 / 科技冷白 / 复古暖棕） | 品牌方内部评审不通过 |
| 4 | **可用性** | 尺寸、格式、留白、抠图边缘、文件命名符合平台规范 | 上架流程卡住，返工重拍 |

**为什么是这个顺序**：准确度不过关是"错"，会被追责；调性不合是"审美分歧"，可以沟通。先把不可谈判的做对，再谈发挥空间。

### 0.2 与艺术摄影的根本区别

| 维度 | 艺术摄影 | 商业摄影 |
|---|---|---|
| 决策权 | 摄影师 | 客户（摄影师提供专业建议） |
| 目的 | 表达自我 | 促成销售 / 建立品牌认知 |
| 成功标准 | 打动观众 | 客户满意 + 数据达标（点击率/转化率） |
| 拍摄前 | 可以空手出门靠偶遇 | 必须有脚本、参考图、道具清单 |
| 后期尺度 | 按个人美学 | 不得改变产品客观属性（颜色/数量/附带物） |
| 交片 | 挑最好的几张 | 按清单交齐，含备用角度与细节图 |

**红线**：商业后期不得虚构产品不具备的功能、颜色、尺寸、配件。这不是"审美问题"，是虚假宣传，属于法律风险。

### 0.3 三条先问自己的话

① 这张图最终出现在哪里（详情页首图/场景图/社媒/印刷海报）→ 决定画幅、留白、分辨率。② 客户最想让观众第一眼看到产品的哪个部分 → 决定主光与构图重心。③ 如果只能交一张，交哪张 → 决定精力分配。

**红线补充**：商业后期不得虚构产品不具备的功能、颜色、尺寸、配件。这不是审美问题，是虚假宣传，属于法律风险。

## 1. 影棚基础

### 1.1 空间与背景系统

| 项目 | 推荐规格 | 原因 |
|---|---|---|
| 最小拍摄空间 | 4m × 6m，层高 2.8m 以上 | 主体到背景要有 1.5~2m 距离，灯到主体 1.5~2m，相机到主体 1~2m，加上人走动 |
| 无缝背景纸 | 宽 1.35m / 2.72m，长 11m | 纸卷拉出后自然下垂，形成"无地平线"背景，是电商白底与纯色场景的标配 |
| 背景纸颜色 | 白、灰（18% 灰最通用）、黑、浅粉/浅蓝（服饰常用） | 灰背景能同时当"白底抠图源"和"过渡色"，最省成本 |
| 无缝背景布 | 3m × 6m 绒布，黑/白/灰/绿 | 吸光、不起皱、可水洗；绒布黑是拍玻璃与金属压暗环境的利器 |
| 桌面台 | 拍摄台面 60cm × 120cm，台面离地 75~90cm | 桌面静物的核心工作区，可与背景纸形成弧形过渡 |
| 弧形背景（cyclorama） | 直角弧或软弧，半径 ≥ 50cm | 消除台面与背景的硬边线，拍瓶子、化妆品、鞋类必备 |
| 亚克力板 | 3mm 白透 / 磨砂白 / 黑亮 | 白透做透射光台，磨砂白消影，黑亮做镜面倒影 |

**无缝背景使用要点**：纸卷拉出长度 = 主体后方 1.5m + 台面长度 + 前方 0.5m，一次性拉足不中途接；主体站位必须是没被踩过的干净段，每拍完一个产品往后挪 30~50cm；背景纸受潮起波浪会在画面里变成"明暗不匀的横纹"，必须换纸或压平。

### 1.2 灯架与夹具

| 器材 | 用途 | 关键参数 |
|---|---|---|
| C 型魔术腿 | 挂柔光箱、旗板、反光板 | 承重 ≥ 10kg，腿压沙袋 |
| 灯架 | 小灯、柔光伞 | 承重 ≥ 5kg，气垫式更安全 |
| 旗板（flag/gobo） | 遮挡杂光、局部压暗 | 黑卡纸、黑绒布、黑旗 |
| 大力夹 / 超级夹 | 固定反光板、背景纸 | 夹口带橡胶垫防刮 |
| 沙袋 | 压灯架底部 | 每架 2 袋（约 5kg/袋） |
| 顶灯横臂 | 顶光、顶反光 | 长 ≥ 1.2m，必须配配重 |

**动线原则**：三脚架固定后，把"主光—相机—背景—道具桌"布置成顺时针半圆，人只在该半圆后侧移动。换产品时不用绕灯，效率翻倍。

### 1.3 常亮灯 vs 闪光灯

| 维度 | 常亮灯（LED / 钨丝） | 闪光灯 |
|---|---|---|
| 所见即所得 | 是，直接看到光影 | 否，需试拍看回放 |
| 功率 | 100~300W 常见，弱 | 200~1000Ws，强 |
| 凝固运动 | 差，快门决定 | 极强，闪光持续时间 1/800~1/10000s |
| 色温稳定性 | 好（5000~5600K 标定） | 好，但不同灯管/不同品牌有差异 |
| 发热 | LED 低，钨丝高 | 低 |
| 适合 | 视频、直播、儿童、微距、需要精细看光 | 商品、人像、大场景、需要大功率压环境 |
| 成本 | 入门低、高功率贵 | 入门中、大功率贵 |

**建议**：商品静物起步用"1 盏 400Ws 闪光灯 + 2 盏 LED 补光"的混合方案。闪光灯做高强度主光，LED 做可见的辅光/背景光，调试时先用 LED 定型光位，再换成闪光输出。

### 1.4 色温统一

一个场景里所有灯（含环境灯、窗光）色温必须一致，误差 ≤ 200K。商品摄影标准色温 **5500K ± 200K**（接近日光）。混光后果：白平衡调好后，某个光源打出的区域整体偏黄或偏蓝，白底图上出现"色块"，抠图后边缘发灰。实操：每盏灯拍摄前用灰卡/色卡在同一位置测一遍；LED 要确认标称色温是"实际输出"而非"贴牌标称"。闪光灯色温通常 5500~6000K，加柔光箱后略降（约 -100K），加柔光布再降，需重新标定。

### 1.5 工作区动线

五个区：**拍摄区**（相机—灯—主体三角，地面贴胶带画相机位与灯位十字）、**待拍区**（推车或桌子，按拍摄顺序排列，标签朝上）、**成品区**（拍完直接装箱，不要放回待拍区）、**道具/清洁区**（手套、无绒布、气吹、酒精片、静电毛刷、粘毛滚筒）、**电脑区**（联机拍摄屏幕放在一眼能看到的距离，边拍边看，避免"拍完回去发现全废"）。

## 2. 商品与静物布光

### 2.1 四种光的分工

| 光位 | 作用 | 典型位置 | 功率占比（参考） |
|---|---|---|---|
| **主光（Key）** | 决定整体明暗结构与质感方向 | 主体 10 点或 2 点方向，高度 30°~45° | 100%（基准） |
| **辅光（Fill）** | 提升暗部，降低反差，控制层次 | 主光对侧，略低，与主光夹角 90°~120° | 1/4 ~ 1/8 主光 |
| **背景光（Background）** | 分离主体与背景，制造渐变/光斑 | 背景后方两侧或正后方 | 独立控制，视需要 |
| **轮廓光（Rim / Kicker）** | 勾出边缘，让主体"跳"出背景 | 主体后侧左右，略高于主体，朝相机 | 1/2 ~ 1/4 主光 |

**为什么轮廓光要"略高于主体、朝相机"**：光只在边缘掠射，落在镜头上是细亮线，落在产品正面则变成"第二个主光"打乱结构。

### 2.2 柔光箱尺寸与距离法则

核心公式：**柔光相对尺寸 = 光源发光面尺寸 ÷ 光源到主体的距离**

| 比值（面/距） | 效果 | 用途 |
|---|---|---|
| < 0.5 | 硬光，边界锐利，阴影深 | 强调纹理、制造戏剧感、金属高光条 |
| 0.5 ~ 1 | 半硬，有明确方向 | 一般商品主光 |
| 1 ~ 2 | 柔和，阴影过渡自然 | 化妆品、食品、服饰 |
| > 2 | 极柔，几乎无影 | 高反光体、婴儿、无影白底 |

**实操数**：60cm 柔光箱距主体 60cm → 比值 1，柔；距 120cm → 比值 0.5，变硬（这就是"灯拉远会变硬"的原因）。想更柔又不改光位：换 120cm 柔光箱并保持 120cm 距离，比值仍为 1，但光包围角更大，过渡更顺。距离翻倍时按平方反比光强降为 1/4 → 需补 2 档功率。

**常用柔光配件**：方/长方柔光箱（均匀可控，通用主光）；条形柔光箱（细长高光，酒瓶/口红/细长产品与轮廓光）；八角柔光箱（圆形光斑、眼神光天然，人像与圆形产品）；透射柔光伞（散射大、便宜、不精密，适合大场景补光）；反光伞（硬朗、效率高，大面积铺光）；柔光罩/光帐篷（全包围无影，高反光小件）；蜂巢（收窄光束、抑制溢光，用于背景光/轮廓光）；束光筒（极窄光柱，点状背景光）。

### 2.3 分材质布光策略

#### A. 高反光材质（金属、镀铬、亮面银器、珠宝、亮面塑料）

**物理特性**：几乎不产生漫反射，拍到的是"环境在它表面的镜像"，所以**控制反光面 = 控制环境**。

| 手法 | 操作 | 效果 |
|---|---|---|
| 光帐篷 / 光罩 | 白布或柔光布把产品整个罩住，灯从外部打 | 表面均匀白亮，无杂影 |
| 黑卡控形 | 在白帐篷上开缝，或贴黑卡条 | 金属上出现黑白交替的"形"，读出体积感 |
| 白卡补光 | 产品两侧摆白卡反光 | 提高暗部，让金属不死黑 |
| 偏振膜 + CPL | 光源前贴偏振膜，镜头前加 CPL | 消掉大面积反光，看到底层材质或颜色 |

**关键数字**：金属拍摄时"纯白无黑卡"= 死白一块看不出形状；必须有至少一条黑卡边缘或渐变，才能读出圆润度。

#### B. 吸光材质（布料、毛绒、绒面、针织、深色衣物）

**物理特性**：吸光、无高光、细节藏在微小凹凸里。**要的是"纹理"，不是"光滑"**。

| 手法 | 操作 |
|---|---|
| 硬一点的侧光（比值 < 0.7，或裸灯 + 蜂巢） | 让纹理产生微小阴影，纹理才可见 |
| 光角度压低到 15°~30° | 掠射光最能凸显织物起伏 |
| 不追求无影 | 适当的阴影是表现厚度的必要信息 |
| 补光克制 | 辅光太强会填平纹理阴影，织物看起来像纸 |
| 提前熨烫拉直 | 褶皱在硬侧光下会被放大成"瑕疵" |

#### C. 透明材质（玻璃杯、瓶子、香水）

见第 3 章专项。核心逻辑：**透明体靠"折射和透射"成像，靠"边缘"被看见**。

#### D. 哑光材质（木、纸、陶瓷、哑光塑料、哑光包装盒）

**物理特性**：漫反射为主，容易拍，也容易拍"平"。用中大面积柔光主导提供均匀底色；加一条轮廓光让边缘离开背景（尤其深色产品）；用反光卡在产品侧面制造由亮到暗的渐变，读出曲面；注意纹理与光线方向垂直时纹理最明显。

### 2.4 布光顺序（每次都按这个顺序，别乱）

① 关掉所有灯只开主光 → 看阴影位置、高光位置、质感是否对。② 调主光功率与距离 → 定整体曝光与反差。③ 加辅光 → 只解决"暗部死黑"，功率从 1/8 起往上加，不要一次加满。④ 加背景光 → 决定"白底全白"还是"渐变灰"。⑤ 加轮廓光 → 最后加，可选，加了会让产品"立起来"。⑥ 逐项关灯回检 → 关掉背景光看主体是否还成立，关掉轮廓光看主体是否还清楚；任何一盏灯关掉后主体就"垮"的，那盏是主力，要重新分配。

## 3. 高反光与透明体专项

### 3.1 金属与珠宝

**四种经典方案**：

| 方案 | 结构 | 适用 | 注意 |
|---|---|---|---|
| 帐篷法 | 白布/柔光布全包，外部 1~2 盏灯 | 小件、形状复杂、多面反光 | 需开缝或贴黑条，否则无形状 |
| 半帐篷 + 黑卡 | 顶部与后方白布，前方敞开，两侧黑卡 | 珠宝、手表、戒指 | 黑卡位置决定"金属的形" |
| 背光透射（用于宝石） | 光从宝石后方/下方透射 | 透明宝石、钻石 | 需要点光源或束光筒，正面用白卡补 |
| 环形灯/同轴光 | 镜头同轴出光 | 极高反光的平面（镜片、镀层） | 会留下环形倒影，后期要修 |

**珠宝拍摄的硬性要点**：戒指用蜡泥/蓝丁胶固定并**立起来**拍，不要平躺（平躺看不到钻石火彩）；钻石火彩来自多角度点光源，可用 2~3 个小反光镜/小白卡从不同角度反射同一盏灯；金属戒指的"白面"要有渐变否则像塑料，用黑卡在白帐篷上拉出一条渐变黑边；全程戴手套（指纹放大后是致命瑕疵）；微距 1:1 需消除相机反光，镜头前加黑卡圈或穿黑衣。

### 3.2 玻璃：明视野法与暗视野法

**这是透明体拍摄的分水岭，必须掌握这两种。**

| | 明视野法（bright-field） | 暗视野法（dark-field） |
|---|---|---|
| 背景 | 纯白背景，背景光打满 | 纯黑背景（黑绒/黑纸），不发光 |
| 光路 | 光透过瓶子进入镜头 | 侧后方光只照到瓶子边缘，不进入镜头 |
| 效果 | 瓶子呈"深色轮廓 + 内部亮"，像超市货架上的效果 | 瓶子呈"亮边 + 透明内部"，像广告里的效果 |
| 关键 | 瓶子后面必须有一块干净的白色发光面 | 瓶子两侧各一块白卡/柔光板，光只打这些板，不打背景 |
| 适用 | 饮料、酒、药水瓶、需要看清液体颜色的 | 香水、化妆品、需要高级感的透明体 |

**实操：明视野法**
1. 背景纸打到纯白（测光比主体亮 1.5~2 档）。
2. 主体背后 30~50cm 放一块白透亚克力或白卡，光从后方打透它。
3. 相机与主体同高或略低，白面在瓶后形成"发光面"。
4. 瓶身两侧各放一块黑卡或白卡：黑卡做出"瓶身两侧的暗边"（读出圆柱感），白卡提高亮度。
5. 正面加一盏极弱的前光（1/16 功率）或反光板，让标签可见。

**实操：暗视野法**（1）背景用黑绒布，背景光关闭。（2）雾面白卡或不锈钢白板放在瓶身两侧、略靠瓶后。（3）两盏灯从侧后方打这两块板，光只落板上不落背景。（4）瓶子两条边缘反光由白卡产生 → 形成亮边。（5）顶部用一小块柔光布加一条"顶盖亮边"，让瓶口有形状。（6）正面如有标签需交代，加极弱的柔和前光。

**去杂反光清单**：相机与摄影师的倒影（穿黑衣 + 镜头前加黑卡圈 + 用长焦拉开距离）；天花板灯管反光（拉黑布遮天花或加顶部旗板）；背景杂物反光（背景与主体之间加黑旗）；瓶内气泡（拍摄前静置 20~30 分钟）；瓶身指纹水渍（无绒布 + 手套，拍前最后一步再擦）；玻璃底部反光（垫灰卡或黑卡）。

### 3.3 液体

| 目标 | 手法 |
|---|---|
| 清澈透亮 | 背光/底光透射，液体颜色由透射光决定 |
| 有泡沫（啤酒、咖啡） | 拍前刚倒，泡沫最多维持 1~3 分钟，一次连拍 |
| 有冷凝水（冷饮） | 甘油:水 = 1:3 喷涂，喷后立即拍，避开"水珠流下" |
| 冰块 | 真冰易化，可用亚克力假冰；真冰拍前用刀修出透明感 |
| 液体流动（倒酒、倒咖啡） | 高速闪光（闪光持续 1/2000s 以上）或高速同步凝固水滴 |
| 液体飞溅 | 高速摄影 + 触发，或先慢快门构图再高速定格 |
| 去气泡 | 提前静置，或用针挑掉边缘大泡 |

**冷凝水配方**：水 3 : 甘油 1，喷在瓶身。甘油延缓蒸发、水珠形状饱满。喷完 10~30 秒内拍摄，久了会流淌。

## 4. 布景与道具

### 4.1 道具选择原则

| 原则 | 说明 |
|---|---|
| **不抢主** | 道具的颜色饱和度、亮度、大小都必须低于产品 |
| **同材质或反材质** | 要与产品有材质关联（木桌配陶杯），或强对比制造张力（水泥台配瓷器） |
| **可解释** | 每个道具都要能回答"它为什么在这"（使用场景 / 制造层次 / 补空白） |
| **真不假** | 假花、假书（空白封皮）在特写下会露馅，宁缺毋滥 |
| **可去可留** | 摆完后逐个拿掉，如果拿掉更好，就不要 |
| **数量克制** | 1 主 + 2~3 辅是安全上限，超过 5 个物件画面必乱 |

### 4.2 色彩搭配

**三种可靠配色法**：邻近色（产品色 ± 相邻色相，安全高级，适合家居/食品/护肤）；互补色（色轮对面 + 面积对比 70:30，适合运动/饮料/年轻品牌）；无色系（白灰黑木 + 产品本色，适合 3C/珠宝/高端）。

**色彩比例**：底色 60% / 道具 30% / 点缀 10%。避免三色各占 1/3（那是杂乱不是平衡）。背景与产品色差不足时用明度差分离（深色产品放浅背景）。

### 4.3 场景叙事

| 层级 | 内容 | 用途 |
|---|---|---|
| 纯产品图 | 产品 + 干净背景 | 主图、抠图源 |
| 简单场景图 | 产品 + 1~2 道具 + 材质台面 | 详情页中段、社媒 |
| 完整情境图 | 有人物、动作、环境，讲一个故事 | 品牌形象、广告 |
| 氛围特写 | 局部 + 光影 + 材质 | 情绪补充、留白配文 |

**叙事三问**：谁在用（决定人的手/衣服/年龄感）、在哪用（决定台面材质与光向）、什么时候用（决定季节与节日元素）。

### 4.4 季节与节日主题

| 主题 | 色板 | 道具 | 用光倾向 |
|---|---|---|---|
| 春 | 嫩绿、樱粉、米白 | 花瓣、藤编、轻纱 | 高调、柔和、长阴影 |
| 夏 | 青蓝、柠檬黄、白 | 水、冰、藤编、亚麻 | 高调、硬光、强对比 |
| 秋 | 焦糖、赭石、酒红 | 干叶、粗麻、木、麦穗 | 暖色调、侧逆光 |
| 冬 | 冰白、雾灰、深绿 | 松枝、霜、毛毯、金饰 | 冷调、低照度、高光冷白 |
| 春节 | 大红、金、朱砂 | 春联、灯笼、橘子 | 暖、饱和度高、对称构图 |
| 中秋 | 月白、深蓝、金 | 月饼、茶具、桂花 | 低调、月色侧光 |
| 圣诞 | 红、绿、金、白 | 松果、灯串、礼物 | 暖黄点光、小光斑 |

### 4.5 主次关系

**三级层次**：主体（产品）最清晰、最亮、最大、位于视觉重心；次体（道具）略暗、可景深虚化、位于三分点；环境（背景/台面）最弱最匀、不吸引注意力。**检查方法**：把照片缩到手机屏幕 5cm 大小看一眼，第一眼没落在产品上就是构图失败。

## 5. 拍摄技法

### 5.1 焦段选择

| 焦段（等效 135） | 特征 | 适合 |
|---|---|---|
| 24~35mm | 透视夸张、近大远小 | 大件家具、需要夸张层次的场景 |
| 50mm | 视角接近人眼 | 中型商品、场景图 |
| 85~100mm | 透视平实、畸变小 | **商品与静物的主力焦段** |
| 100~135mm | 压缩空间、背景虚化强 | 小件、首饰、需要与背景剥离 |
| 微距 100mm | 1:1 放大、平场 | 珠宝、表盘、接口、面料细节 |

**为什么 85~135mm 是主力**：商品需要"平的透视"。广角会让盒子看起来上大下小，客户会说"我的产品是变形的"。长焦在 2~3m 距离拍小件，透视接近正交投影，形状不失真。

### 5.2 景深控制

- 商品主图：**光圈 f/8 ~ f/16**，保证整个产品在景深内。
- 珠宝微距：f/11 ~ f/16 + 焦点堆栈，因为微距下景深只有毫米级。
- 场景图/氛围图：f/2.8 ~ f/4，虚化道具，突出产品。
- 衍射极限：APS-C 超过 f/11、全画幅超过 f/16 后，画质因衍射开始下降。需要更大景深时优先用堆栈，不要一味缩光圈。

**景深估算（全画幅，85mm，物距 1m）**：f/2.8 ≈ 2cm，f/5.6 ≈ 4cm，f/11 ≈ 8cm，f/16 ≈ 12cm。微距 1:1 时景深缩到 mm 级，必须堆栈。

### 5.3 焦点堆栈（focus stacking）

**适用**：产品纵深大于景深（瓶子、首饰、表、多层摆放、45° 俯拍的平面产品）。

**流程**：
1. 三脚架 + 快门线/延时，相机不动。
2. 光圈定在 f/8~f/11（画质与景深平衡点），不要用极小光圈。
3. 手动对焦，从最靠前的位置开始，每次向后退一个小步进。
4. 步进量取景深的 1/2~1/3，重叠保证不出断层。
5. 拍摄 8~30 张（视纵深与光圈）。
6. 后期用专用合成软件（Helicon Focus / Zerene Stacker）或 Photoshop 自动混合图层。

**避坑**：全程手动曝光 + 手动白平衡（否则各张亮度不一致，合成出条纹）；关闭机内降噪与自动亮度优化（会逐张变化）；闪光灯拍堆栈要注意输出一致性（回电是否够）。

### 5.4 移轴与垂线校正

移轴两大用途：**垂线校正**（相机上仰拍产品/建筑时垂线会汇聚，平移像场把垂线拉直）；**前组倾斜控制合焦面**（拍 45° 俯视的平铺产品时让合焦面与产品平面平行，一张全清楚，省掉堆栈）。移轴贵，替代方案是后期透视校正 + 裁切，代价是损失像素。

**日常垂线校正**：开相机电子水平仪；拍方盒正面时前组必须与盒面平行，否则出现梯形变形；俯拍平铺产品时用 90° 垂直俯拍 + 水平仪，配合移轴或后期避免"上窄下宽"。

### 5.5 微距

三脚架 + 快门线（最好加微距导轨）；光源用环形灯、双头微距闪光或离机小灯 + 柔光布；光圈 f/8~f/16 并注意衍射；用黑卡圈套镜头、穿黑衣、加偏振镜控制反光；拍前气吹清产品灰尘，同时清传感器（f/16 下传感器灰尘全暴露）。

### 5.6 多角度拍摄清单（电商标准 5~8 张）

| 编号 | 内容 | 说明 |
|---|---|---|
| 1 | 正面主图 | 纯白底，占画面 75%~85% |
| 2 | 45° 侧面 | 显示厚度与立体 |
| 3 | 背面 | 包装、标签、说明 |
| 4 | 侧面（左侧或右侧，取信息多的一侧） | 显示高度比例 |
| 5 | 俯视 | 显示顶面设计 |
| 6 | 细节特写 1 | 工艺、材质、接缝 |
| 7 | 细节特写 2 | 五金、logo、绣标 |
| 8 | 场景图 | 使用状态、比例参照 |

细节特写自带"比例感"：旁边放一枚硬币或尺子，或将手入镜（但要干净、指甲修剪）。

## 6. 后期与交付

### 6.1 白底图规范

| 项目 | 标准 |
|---|---|
| 背景 RGB | 纯白 **255,255,255**（不是 250,250,250） |
| 白的容差 | 边缘外侧 5~10px 必须为 255，不能有灰边 |
| 产品边缘 | 无白边（halo）、无锯齿、无残留背景色 |
| 投影 | 可选择"保留柔和投影"（更立体）或"完全无影"（平台要求时用前者居多） |
| 产品占比 | 通常宽或高占画面 75%~85%，四周留白均匀 |
| 文件 | sRGB 色彩空间，JPG 质量 ≥ 90%，最长边按平台要求 |

**抠图边缘处理步骤**：① 通道/选择工具做初选，羽化 0.5~1px；② "选择并遮住"精修毛发与半透边；③ 垫纯白底层，放大到 400% 检查边缘；④ 半透明产品（纱、玻璃）用"蒙版 + 通道"保留半透，不要用硬边选择；⑤ 检查边缘有无原背景色偏（蓝边/绿边）→ 用"去边/净化颜色"。

**投影怎么做才自然**：
- 用"接触阴影"：产品正下方一小块深色软影，越往外越淡。
- 不要用"投射阴影"式的长影，除非客户要求。电商白底图的影子通常极短且柔。
- 影子的方向必须与产品主光方向一致，否则画面"打假"。

### 6.2 色彩还原与色卡

| 工具 | 用途 |
|---|---|
| 24 色 / 140 色色卡 | 每换一次光源/场景拍一张色卡，后期做色彩匹配 |
| 18% 灰卡 | 白平衡校准 + 曝光基准 |
| 白卡 | 快速白平衡（不如灰卡精确，但够用） |
| 分光光度计 | 高精度复现特定色（服装、化妆品品牌色） |

**流程**：
1. 拍第一张：色卡放在产品位置，与产品同光位。
2. 后期用配套工具的"相机校准"生成 profile，一键套用到同场景所有照片。
3. 品牌标准色（如某品牌红）单独做 HSL 微调，但**不得改变产品的实际色相**。

### 6.3 电商平台尺寸要求（通用参考，以平台最新规范为准）

| 平台/用途 | 常用尺寸 | 说明 |
|---|---|---|
| 淘宝/天猫主图 | 800×800（≥800 才有放大镜效果），建议 1200×1200 | 正方形白底 |
| 京东 | 800×800 起，建议 1000×1000 | 可白底或场景 |
| 亚马逊主图 | 建议 2000×2000 | **强制纯白底 RGB 255,255,255，产品占 85%** |
| 拼多多 | 750×750 / 800×800 | |
| 通用详情页 | 宽 750 / 790 / 1200，高度不限 | 竖向长图 |
| 小红书 | 3:4 竖图 1242×1656 | 场景图为主 |
| 抖音商品 | 1:1 或 3:4 | |
| 印刷 | 300dpi | 尺寸按成品 + 出血 3mm，CMYK |

### 6.4 批量处理

建立"动作/预设"流水线：白平衡 → 曝光 → 色卡 profile → 输出锐化。白底抠图：同材质同光位的产品可用批处理抠图，异形产品必须逐个处理。命名规范 `品牌_品名_SKU尺寸_角度_序号.jpg`（例 `A牌_纯棉T恤_M-黑_正面_01.jpg`）。交付前跑一遍"两屏测试"，在手机与电脑两块屏各看一遍，避免只在调色屏上成立。

### 6.5 交付格式

| 格式 | 用途 | 参数 |
|---|---|---|
| JPG | 电商上传、社媒 | sRGB，质量 90~95 |
| PNG | 透明底、无损需求 | 24 位 + Alpha |
| TIFF | 印刷、存档 | 16 位，AdobeRGB 或 CMYK |
| PSD | 分层交付（客户要改） | 保留图层、蒙版 |
| RAW | 原始素材（视合同） | 通常不交付，除非合同约定 |

**交付包结构**：`原图/`、`精修/`、`白底/`、`场景/`、`细节/`、`色卡/`，附 README 说明命名规则与授权范围。

## 7. 接单与报价

### 7.1 报价构成

| 项目 | 说明 | 常见计价 |
|---|---|---|
| 拍摄费 | 摄影师的时间与技术 | 按天或按图 |
| 后期费 | 修图、抠图、合成工作量 | 张数 × 单价 |
| 道具费 | 采买、制作、租赁 | 实报实销 + 30%~50% 组织费 |
| 场地费 | 影棚租金、外景场地 | 按天/半天 |
| 模特/化妆费 | 需要出镜时 | 按人天 |
| 灯光/器材租赁 | 移轴、微距导轨、大功率灯 | 按天 |
| 差旅费 | 异地拍摄 | 交通 + 住宿 + 餐补 |
| **授权费** | 使用范围与期限 | 见 7.4 |
| 加急费 | 48 小时内交付 | 总价 +30%~100% |

### 7.2 按图计价 vs 按天计价

| | 按图计价 | 按天计价 |
|---|---|---|
| 客户视角 | 预算明确、可控 | 不确定最终张数 |
| 摄影师视角 | 需精确估工时，容易低估 | 收入确定、风险低 |
| 适合 | 白底图、固定角度、批量标准化产品 | 创意场景、大量试错、外拍 |
| 风险 | 客户反复加需求 → 须写清"含几张、几张内免费改" | 客户现场拖时间 → 须写清"当天 8 小时" |
| 常见区间（国内参考） | 白底图 30~150 元/张；精修场景图 200~2000 元/张 | 商业静物 2000~8000 元/天；广告级 8000 元/天以上 |

**混合报价最实用**：基础包（含 N 张 × 单价）+ 超出部分单价 + 加急费。

### 7.3 合同要点

| # | 条款 | 关键表述 |
|---|---|---|
| 1 | 交付物清单 | 张数、角度、尺寸、格式、色空间 |
| 2 | 交付时间 | 按工作日计，明确"自客户确认需求起算"，防止客户拖延确认却怪你慢 |
| 3 | 修改次数 | 含 2~3 轮小改（曝光/色彩/裁剪）；结构性重拍另计 |
| 4 | 付款方式 | 定金 30%~50%（摄影师违约才退）；交片前付清尾款 |
| 5 | 授权范围 | 媒介、地域、期限、是否独家 |
| 6 | 超额使用 | 超出约定范围需补授权费 |
| 7 | 素材保存期 | 原图保存 3~12 个月，过期删除，客户自行备份 |
| 8 | 署名权 | 是否署名、在哪署名（社媒可要求，电商白底图通常不署名） |
| 9 | 取消条款 | 提前 N 天取消的定金退还规则 |
| 10 | 免责 | 不可抗力、客户提供的道具/场地导致的延误 |

### 7.4 版权与使用授权

**默认原则**（中国法律框架）：委托创作的著作权归属由合同约定；未约定时著作权归**受托人（摄影师）**，委托人可在约定用途内使用。

| 授权维度 | 等级示例 | 价格影响 |
|---|---|---|
| 媒介 | 仅电商详情页 < 电商 + 社媒 < 全网 + 户外广告 | 每升一档 +30%~100% |
| 地域 | 中国大陆 < 大中华区 < 全球 | 全球约为大陆的 2~3 倍 |
| 期限 | 1 年 < 3 年 < 永久买断 | 买断常为基准价 3~5 倍 |
| 独家 | 非独家 < 品类独家 < 完全独家 | 独家溢价 50%~200% |

**常见陷阱**：客户说"随便用用"，实际拿去投户外广告。所以报价单必须写"授权范围：XX 平台，期限 1 年；超出另议"——哪怕不签合同，报价单也要写明。

**报价心态**：不要按"张数 × 时间"算成本，要按"这张图对客户值多少"算价值。报低价只会吸引最挑剔的客户，低价 + 高要求 = 亏损 + 差评。客户预算低于成本线时，正确做法是**缩减交付范围**（少拍几张、不含场景图、不包抠图），而不是降价干同样的活。

## 8. 客户沟通与流程

### 8.1 需求确认清单（拍摄前必问，逐条打勾）

| # | 问题 | 为什么问 |
|---|---|---|
| 1 | 产品是什么？有哪些 SKU、颜色、数量？ | 决定工时与道具 |
| 2 | 最终用在哪里？（平台/印刷/户外） | 决定尺寸、分辨率、色彩空间、授权 |
| 3 | 要几张？哪些角度？要不要场景图？ | 决定拍摄清单 |
| 4 | 有没有参考图？喜欢哪张、讨厌哪张？ | 避免"审美鸡同鸭讲" |
| 5 | 品牌色/VI 规范是什么？有字体/配色手册吗？ | 决定道具与背景配色 |
| 6 | 有没有必须出现的元素（logo、包装、赠品）？ | 防止交片后被要求补拍 |
| 7 | 有没有不能出现的元素（竞品、旧包装、某颜色）？ | 防止踩雷 |
| 8 | 交付时间？上架/发布的时间节点？ | 决定排期与加急费 |
| 9 | 谁来做最终确认？决策人是谁？ | 避免"改到第 5 轮又来了个领导" |
| 10 | 预算区间？ | 决定方案与交付范围 |
| 11 | 产品什么时候能到？样品是否擦净/组装好？ | 样品不到位 = 当天不能拍 |
| 12 | 修图尺度？能不能修掉瑕疵、能不能改颜色？ | 有法律风险的事必须书面确认 |

### 8.2 参考图沟通

- **要"喜欢"和"不喜欢"两组参考图**，各 3~5 张。
- 对每张参考图追问三件事：喜欢的是**光**、**色调**、还是**构图/场景**？往往客户说"喜欢这张"其实只是喜欢背景色。
- 把参考图拆成可执行要素：光位（左/右/顶/逆）、光质（硬/柔）、背景色（RGB/色名）、道具（木/石/布）、色调（冷/暖）。
- 拍一条**"试拍样片"**（1~2 张，正式拍摄前发客户确认），成本极低，能挡掉 80% 的返工。

### 8.3 拍摄前准备

提前 1 天：确认样品到手、场地可用、灯具备齐、存储卡与电池清空/充满；把拍摄清单发给客户确认"拍这些够不够"。当天开工前：拍一张含色卡 + 产品标签的测试屏照片发给客户作为"今天的起点"；现场摆好"待拍区 / 成品区"避免产品混淆。

### 8.4 现场确认

每拍完一组角度立刻联机回传（客户在场）或发 1~2 张样片（不在场）；现场确认过的后期不再大改，未确认的写进"次日确认"；记录每次确认的时间与内容，出现分歧时可回溯。

### 8.5 改稿流程

| 轮次 | 内容 | 收费 |
|---|---|---|
| 第 1 轮 | 客户提意见 | 免费 |
| 第 2~3 轮 | 小改（色彩/亮度/裁剪/去点） | 免费 |
| 第 4 轮起 | 任何修改 | 按小时或按张收费 |
| 结构性修改 | 换背景、换角度、重拍 | 重新报价 |

**防无限改稿**：交片时附一张"待确认清单"，把不确定的点一次列出让客户统一回复，而不是让他一张一张看、一条一条提。

### 8.6 催稿应对

客户催稿通常三种原因：他自己被他的客户催、他以为你拖了、他忘了约定的时间。应对手段：**先给一张**——发 1~2 张已完成的高质量图，比说一百句"我在做了"有用；提前设置具体预期（"明天下午 3 点发前 10 张，晚上发全部"），比"尽快"强；反复催且超出约定时间的，礼貌引到合同条款并给"加急费"选项；客户半夜发消息，第二天早上统一回复，不要被他的节奏带走（除非约定 24 小时响应）。

## 9. 商业摄影诊断表

| 症状 | 原因 | 修正 |
|---|---|---|
| 白底图抠完有灰边/白边 | 抠图羽化过大，或原图产品边缘与背景明度接近 | 羽化降到 0.5~1px；拍摄时把背景打得比产品亮 1.5~2 档，拉开边缘明度差 |
| 白底不够白，是 250 灰 | 背景光不足，或后期没提白场 | 背景光+N 档直到直方图右端贴边；后期用"色阶"把白场定在 250→255（用吸管点背景） |
| 产品边缘有蓝色/绿色残影 | 原背景色溢出到边缘，去边没做 | 后期"选择并遮住 → 净化颜色"；拍摄时用中性灰或白背景 |
| 金属产品一片死白、看不出形状 | 光帐篷全白无黑卡 | 在帐篷或白卡上加黑卡条（至少一条），制造明暗交替 |
| 金属表面有奇怪的人影/灯影 | 环境被反射了 | 穿黑衣、加黑旗、镜头前加黑卡圈、用光帐篷隔离 |
| 玻璃瓶拍出来发黑、像塑料 | 用了明视野法但背景没打亮 | 背景打到纯白，瓶后放白透板，或改暗视野法做亮边 |
| 玻璃瓶上全是杂反光 | 环境太杂、灯太多 | 加黑旗隔离，只保留必要的发光面；用长焦拉开距离减少倒影 |
| 透明产品抠图边缘发毛 | 用了硬边选择，半透明部分被切掉 | 用通道/蒙版保留半透，或用明视野法拍成白底直接出图 |
| 深色产品糊成一团黑，看不出细节 | 辅光不足、背景太亮导致反差过高 | 加辅光或白卡，把背景压暗，让产品相对"亮"起来 |
| 织物纹理拍不出来 | 光太柔、光位太高 | 改硬一点的光（比值 < 0.7）+ 压低到 15°~30° 掠射 |
| 产品照片看起来"比实物显大/显小" | 透视失真或缺少比例参照 | 换中长焦（85~135mm），加一枚硬币/尺子/手作参照 |
| 包装盒拍成梯形 | 相机没与盒面平行 | 开电子水平仪，前组与盒面平行；或移轴校正 |
| 同批产品颜色不一致 | 白平衡漂移、灯功率不稳定、电池衰减 | 每换灯位或每 30 分钟重拍灰卡；用交流电供电，避免电池输出不稳 |
| 后期调完在手机上偏色 | 只在 AdobeRGB 调色屏上修，输出没转 sRGB | 交付前统一转 sRGB；在两块屏上做终检 |
| 微距照片焦点只有一条线清楚 | 微距景深只有 mm 级 | 焦点堆栈（8~30 张），或前组倾斜让合焦面与产品平行 |
| 堆栈合成出现条纹/亮度跳变 | 各张曝光或白平衡不一致 | 全手动曝光 + 手动白平衡，关闭机内自动优化与降噪 |
| 产品上有灰尘/指纹被放大 | 未清洁、未戴手套 | 气吹 + 无绒布 + 手套；f/16 下要同时检查传感器灰尘 |
| 拍摄现场灯倒/器材损坏 | 没上沙袋、C 型腿没压 | 每灯架 2 袋沙袋，C 型腿重物压底，线缆用胶带固定 |
| 拍摄时间永远不够 | 没排拍摄顺序，道具临时找 | 提前列拍摄清单，按"同光位合并"排序，道具提前摆好 |
| 客户说"感觉不对"但说不清 | 参考图沟通不到位 | 追问"喜欢的是光/色/构图哪个"，做试拍样片确认后再正式拍 |
| 客户无限改稿 | 合同没写修改次数 | 合同写"含 2~3 轮小改"，第 4 轮起收费，结构性修改重新报价 |
| 客户把电商图拿去投户外广告 | 授权范围约定不清 | 报价单写明媒介/地域/期限，超出补授权费（30%~100% 起） |
