## 0. 婚礼摄影的总体判断

### 0.1 婚礼摄影的三条底层认知

1. **不可重来**。婚礼是"一次性事件"，没有补拍机会。任何"这张我回去再调"的想法都必须改成"现场再确认一次"。这意味着：宁可多拍，不可漏拍；宁可参数保守（保证成功），不可冒险（追求惊艳）。
2. **纪实为主，摆拍为辅**。婚礼的本质是"记录发生了什么"，不是"导演一场电影"。欧美主流婚礼摄影是纯纪实（documentary），国内主流是"仪式纪实 + 摆拍精修"混合。**一般建议：仪式与敬酒环节纯抓拍，化妆/出门前/外景/合影环节摆拍**。
3. **双人分工**。单人拍全天婚礼，体力与注意力都会在前 4 小时后断崖式下滑。标配是"主摄（关键瞬间 + 摆拍）+ 副摄（补角度 + 抓花絮 + 换电池换卡）"。

### 0.2 不可重来的关键瞬间清单（这些没拍到等于事故）

| 优先级 | 瞬间 | 说明 |
|---|---|---|
| S 级 | 交换戒指 | 手部特写 + 全景各一张 |
| S 级 | 新人第一次看到对方 | 迎亲进门那一刻、仪式入场那一刻 |
| S 级 | 父母的表情 | 母亲拭泪、父亲交接手的那一刻 |
| S 级 | 接亲/堵门 | 红包、找鞋、背新娘、抱出门 |
| A 级 | 化妆完成的第一镜 | 新娘全套妆造 + 捧花 |
| A 级 | 车队/出发 | 车门、花车、挥手 |
| A 级 | 签婚书/敬茶 | 动作完整，不要只拍背影 |
| A 级 | 敬酒 | 主桌 + 逐桌，至少覆盖每桌一张 |
| A 级 | 抛捧花/合影 | 全景 + 抓到的人脸表情 |
| B 级 | 场地空镜、桌花、请柬、戒指盒 | 用于串联的"氛围素材" |

### 0.3 体力与卡量准备

| 项目 | 参考数值 | 原因 |
|---|---|---|
| 全天拍摄时长 | 8~14 小时（早妆到送客） | 需要按小时排能量分配 |
| 快门数 | 2000~6000 张（双人合计） | 纪实性质决定必须覆盖 |
| 存储卡 | ≥ 128GB × 2 卡槽（备份写入），或 256GB × 2 | 一卡到底风险高，双卡备份是底线 |
| 电池 | 机身电池 3~4 块 + 闪光灯电池 2~3 组 | 闪光灯回电变慢就是电池要换的信号 |
| 镜头 | 24-70/2.8 + 70-200/2.8 + 35 或 50 定焦 | 覆盖广角、中焦、暗光 |
| 备份 | 现场用笔记本或双卡备份，当天完成 | 卡片丢失/损坏是真实风险 |
| 体力 | 前一天早睡、穿舒适鞋（不是新鞋）、带水和能量棒 | 注意力先于体力崩溃 |

## 1. 婚礼全流程拍摄清单

以下时间线为国内常见流程（各地有差异，必须提前与新人确认当地习俗）。

### 1.1 新娘家：化妆准备（约 2~2.5 小时）

| 时间点 | 必拍内容 | 说明 |
|---|---|---|
| 到场 | 房间空镜、婚纱挂拍、戒指盒、鞋、请柬、捧花 | 摆拍细节，用于开篇 |
| 上妆中 | 镜前化妆、妈妈帮忙、伴娘说笑 | 抓拍为主，少打扰 |
| 上妆后 | 新娘单人肖像（窗光/柔光）、妆面特写、戒指手部特写 | 摆拍，交代"今天的新娘" |
| 换装 | 穿婚纱过程（背影、系带）、妈妈帮忙 | 有情绪的瞬间 |
| 出门前 | 与父母的合影、挥手告别 | **错过就没了** |

**光线方案**：新娘化妆多用窗光（顺光或侧光），必要时用 LED 常亮板补光（闪光灯在化妆间会打断化妆师节奏，且多次闪光让人不适）。

### 1.2 新郎家 / 集合点（约 30~60 分钟）

| 必拍内容 | 说明 |
|---|---|
| 换装、系领带、手表、皮鞋 | 对新郎的"流程记录" |
| 与伴郎团的合影 | 排一排、跳起来、搞怪 |
| 出发前与父母的告别 | 常被忽略，但父母很在意 |
| 车队出发、花车特写 | 全景 + 细节 |

### 1.3 接亲 / 迎亲（约 30~60 分钟）

| 必拍内容 | 说明 |
|---|---|
| 堵门、塞红包 | 门缝里的手、红包、门外新郎表情 |
| 找鞋、穿鞋 | 已找到鞋的那一刻，新郎的手 |
| 抱新娘出门 / 背新娘 | 全景 + 家人反应 |
| 敬茶、改口 | 父母接茶的那一秒 |
| 出门、上车、挥手 | 家人的表情是重点 |

**关键提醒**：接亲现场空间小、人多、光杂（楼道灯昏暗且偏色）。副摄必须站到"门外/侧后方"补角度，主摄跟核心区域。

### 1.4 仪式（约 30~60 分钟）

| 必拍内容 | 说明 |
|---|---|
| 场地空镜、签到台、桌花、婚戒托盘 | 仪式前完成 |
| 宾客入场 | 全景 + 亲友特写 |
| 新人入场（单人或父亲交接） | **正面 + 背面 + 父母表情**，三机位最稳 |
| 交接手 | 父亲把女儿的手交给新郎，手部特写 |
| 誓言/交换戒指 | 手部特写 + 拥抱全景 |
| 揭面纱/亲吻 | 侧面机位最佳 |
| 签婚书 | 动作完整过程 |
| 父母席反应 | 抓拍，尤其母亲 |
| 退场/撒花/抛捧花 | 全景 + 空中花束 |

**关键提醒**：仪式中新人的正面机位必须提前占位并预留退路（不要挡宾客视线）；一名摄影师站侧后方拍"新人 + 宾客反应"的双重画面。

### 1.5 宴会 / 敬酒（约 2~4 小时）

| 必拍内容 | 说明 |
|---|---|
| 入场、上台、致辞 | 全景 + 致辞人特写 |
| 父母台上讲话 | 抓拍新人听的表情 |
| 切蛋糕/倒香槟/点烛台 | 取决于流程，逐项确认 |
| 敬酒（逐桌） | 每桌至少一张，主桌多拍 |
| 游戏互动/才艺表演 | 高潮瞬间 |
| 宾客合影 | 快速调度（见 3.5） |

**关键提醒**：宴会厅光杂、色温乱（暖白吊灯 + 冷白舞台灯 + 闪光），是让摄影师最头疼的场景，方案见第 2 章。

### 1.6 送客（约 20~30 分钟）

| 必拍内容 | 说明 |
|---|---|
| 新人站在门口送客 | 与每位亲友握手/合影 |
| 收红包/回礼 | 动作 |
| 亲友合影 | 这是当天最后一批"自然合影"，别省 |
| 新人疲惫但幸福的表情 | 非常有价值的收尾素材 |

## 2. 婚礼用光

### 2.1 四个典型场景的用光方案

| 场景 | 光环境特征 | 方案 |
|---|---|---|
| **室内仪式（教堂/礼堂）** | 常禁止使用闪光灯、光线稳定但暗、色温偏暖 | 大光圈定焦（f/1.4~f/2.8）+ 高 ISO（3200~12800）；不打扰原则下靠自然光；若允许，用"跳闪"（bounce flash）打天花板 |
| **酒店宴会厅** | 吊灯密集、色温混杂（2700K 钨丝吊灯 + 5600K 舞台灯）、有大面积白桌布会反射 | 主摄用机顶闪光 + 离机闪；白平衡固定 4000~4500K（折中）拍 RAW 后期统一；副摄用大光圈抓现场光 |
| **户外（草坪/海边/黄昏）** | 光比大、前景逆光、有强烈阴影 | 优先找"阴影边缘"（open shade）；逆光用闪光灯补面（-1.5~-2EV），保留背景氛围；日落前 30 分钟是黄金时段 |
| **烛光/暗场（晚宴、荧光棒派对）** | 极暗、只有点光源 | f/1.4~f/2 + ISO 6400~25600；补一点微弱前光（LED 常亮板，功率 5%~10%）；不要用强闪光破坏氛围 |

### 2.2 热靴闪光灯在婚礼中的用法

| 手法 | 操作 | 适用 |
|---|---|---|
| **跳闪（bounce）** | 灯头朝上打天花板，靠漫反射照亮 | 天花板白色、高度 ≤ 4m 的室内；效果柔和自然 |
| **后拉卡纸（bounce card）** | 灯头抬高，拉出白色反光卡 | 天花板太高或是有色时，给眼睛留一点眼神光 |
| **侧墙跳闪** | 灯头打侧面白墙 | 天花板太高（宴会厅常见）时的替代方案 |
| **离机 TTL 辅光** | 副摄或助手举灯在侧后方，TTL 联动 | 仪式入场、敬酒 |
| **慢速同步（slow sync）** | 快门降到 1/15~1/30，闪光凝固主体，慢门吸收环境光 | 宴会厅、夜景、需要"环境氛围 + 主体清晰" |
| **后帘同步** | 闪光在快门关闭前触发 | 需保留拖影氛围（舞蹈、烛光） |

**闪光灯关键参数**：
- 输出：机顶闪 TTL 起手，通常 -0.7~-1.3EV 比较自然（不要用满功率"白墙式"直闪）。
- 闪光同步速度：普通同步 1/200~1/250s；高速同步（HSS）可到 1/8000s 但输出衰减大。
- 回电时间：全功率约 2~5 秒，半功率约 1~2 秒。**回电变慢 = 电池要换**。
- 电池：镍氢充电电池（如 2500mAh）比碱性电池回电快得多，请备 2~3 组。

**为什么"直闪"在婚礼上不好看**：直闪会在人身后留下硬阴影、脸上出现油光、背景被压黑失去环境感。婚礼需要"氛围"，直闪会消灭氛围。

### 2.3 混合光源下的白平衡处理

**核心原则：拍 RAW，现场固定色温，后期统一**。

| 做法 | 说明 |
|---|---|
| 固定白平衡（如 4200K 或 4500K） | 让同一场景内所有照片色调一致，后期批量统一 |
| 拍 RAW | 混合光无法用 JPEG 救回来，必须 RAW |
| 分区调色 | 后期对"钨丝区"和"闪光区"分别做局部白平衡 |
| 闪光灯加滤色片 | 若环境是钨丝（2700K），给闪光灯加 CTO 滤片，让闪光也变暖，减少色差 |
| 闪光灯加 CTO/CTB 实战 | 暖场（宴会厅）贴 1/2 或全 CTO；冷场（教堂/白灯）用 1/4 CTO 或裸闪 |

**常见错误**：摄影师用自动白平衡，结果同一张照片里"闪光打的地方是白的，没打的地方是黄的"——这是直闪 + 混合光的典型表现。修正方法：给闪光加 CTO 让两者接近，或后期局部调整。

## 3. 婚纱美姿

### 3.1 双人摆姿的六种基本结构

| 结构 | 要点 | 常见错误 |
|---|---|---|
| **站立并排** | 两人身体略成 V 字（不要平行重叠），重心在靠后那条腿；新娘身体向新郎倾斜 | 两人完全平行站立 → 死板、看不出关系 |
| **站立相对** | 面对面，间距 20~30cm，额头互触或对视 | 距离太远 → 无亲密感 |
| **坐姿** | 新娘坐、新郎站/半蹲在侧后方；或两人同坐长椅 | 新郎手无处安放；腿线条被压短 |
| **拥抱** | 新娘双臂环新郎脖子，新郎双手环新娘腰；身体不要贴死，留出腰线 | 完全贴紧 → 身体轮廓融成一团 |
| **牵手行走/回眸** | 走动中回眸，或牵手正面走来 | 走路时手甩太高、表情僵 |
| **背对（背影）** | 新郎从后抱住新娘，或两人并排背影；可配合回眸 | 只拍背面显得"无脸"，宜加回眸或侧脸 |

### 3.2 通用美姿原则

1. **重心在后腿**：站立时把重心放在离镜头远的那条腿上，前腿微屈 → 身体线条呈 S 形，显瘦。
2. **关节点微弯**：肘、膝不要完全伸直锁死，微弯显得松弛（伸直会显得僵硬且显粗）。
3. **手要有事做**：牵手、摸头发、扶腰、拿捧花、玩戒指。空手悬着最难看。
4. **下颌前伸一点**：下巴微向前下方送 1~2cm，可以收紧下颌线（俗称"消除双下巴"）。
5. **身体转 3/4 侧向**：正对镜头会显宽，身体 3/4 侧向 + 脸转向镜头，是最安全的显瘦角度。
6. **视线要有对象**：看对方、看花、看远方、看镜头。避免"眼神放空"。
7. **手不要平摊正对镜头**：手掌面积大且易拍成"没有手指"，用侧掌或握持。
8. **新娘的手在新郎身上，新郎的手在新娘腰上**：这是最自然的"关系表现"。

### 3.3 服装与裙摆处理

| 项目 | 处理 |
|---|---|
| 裙摆铺展 | 大裙摆要"抖开再落"，用手从内向外托起再放下，形成优美弧形；不要生生摊平（会显得像一块布） |
| 拖尾 | 从后方拍摄时把拖尾拉直拉满；从正面拍时把拖尾收到侧后方，避免"垫在两腿间" |
| 头纱 | 顺风抛起、微风吹动、隔着面纱拍摄（半透明遮挡）都是经典手法；面纱在脸上要有"形状"，不要糊在脸上 |
| 手捧花 | 花头朝前下方 30°~45°，不要抱在胸前挡住脸；不要挡住腰线 |
| 西装 | 扣上第一颗扣子，口袋巾露出，袖口露出衬衫 1~1.5cm |
| 鞋 | 蹲拍或躺拍时手扶鞋，或"提鞋"造型 |

### 3.4 戒指与细节特写

| 目标 | 拍法 |
|---|---|
| 戒指盒 | 俯拍，戒指盒打开呈 45°，旁边放请柬/花瓣/戒指枕 |
| 对戒 | 用蓝丁胶立起，两枚并排或交叉；黑卡/镜面亚克力增加层次 |
| 戒指 + 手 | 手部特写（指甲要干净），可用新娘手放在新郎手上 |
| 戒指在花上 | 花心放戒指，微距俯拍 |
| 戒指在请柬上 | 请柬烫金 + 戒指反光，注意杂反光 |
| 戒指 + 婚鞋 | 鞋里放戒指的画面很出片 |
| 镜头建议 | 100mm 微距，f/8~f/11，三脚架 + 黑卡背景 |

### 3.5 亲友合影的排列与快速调度

**排列层级（从前到后）**：
1. 前排：儿童、坐着的长辈
2. 中排：新人/主角
3. 后排：身高较高的、站直的

**基本阵型**：
| 人数 | 阵型 |
|---|---|
| 2~4 人 | 一字排开，身体交错侧向，略成弧形 |
| 5~8 人 | 两排，前排可蹲或坐 |
| 9~15 人 | 三排，前后错位（不要对齐成方块，会互相遮脸） |
| 16+ 人 | 分层站台阶/凳子；摄影师站高一点俯拍 |

**快速调度话术（一句话完成摆位）**：
- "高的朋友往两边，矮的往中间。"
- "前排的朋友蹲下来一点点，不用一直蹲，数三下就好。"
- "大家把脸往里侧一点点，笑一下，看我这里，一、二、三。"

**效率要点**：
- 摄影师先站好位（并架好灯），再喊人过来。不要反过来。
- 提前准备好"合影脚本"：要拍哪几组、每组谁在，现场按名单喊，不要临时想。
- 每组控制在 60~90 秒内完成，避免宾客不耐烦。
- 相机参数提前设好（光圈 f/5.6~f/8，闪光灯 TTL），现场只按快门。

## 4. 婚礼拍摄难点与应急

### 4.1 光线差

| 症状 | 应急方案 |
|---|---|
| 全场极暗，只有蜡烛/手机光 | 定焦大光圈（f/1.4）+ ISO 开到 12800~25600；接受噪点，噪点比模糊好；用一盏极弱的 LED 常亮板（10%~20%）做面光 |
| 逆光强，人脸全黑 | 闪光灯补面 -1.5EV，或请新人转身 15°；实在不行宁可要剪影的"氛围感" |
| 混色光（黄+青） | 闪光灯贴 CTO 匹配环境，或固定色温拍 RAW 后期分区调 |
| 顶光（正午/宴会厅射灯） | 让新人进阴影边缘（open shade），或用手/请柬给眼窝遮一点光 |
| 舞台追光过曝 | 对脸部点测光，宁可背景过曝也不要脸过曝 |

### 4.2 场地小 / 人多

- **换长焦压缩**：用 70-200 站在角落远距离拍，减少"全场都入镜"的杂乱。人越多越要用长焦。
- **抬高机位**：站到椅子、台阶上俯拍，是"人多场地"最快的解法。
- **利用门框/窗框/花门**做前景遮挡，把杂乱的人挡在画面外。
- **副摄专攻花絮区**：主摄拍核心，副摄拍宾客反应，避免两人抢同一个机位。

### 4.3 时间被压缩

| 情况 | 应对 |
|---|---|
| 仪式推迟 30 分钟 | 提前拍完空镜与合影，把"摆拍"全部前置；等待时拍宾客花絮 |
| 流程合并（跳过某环节） | 立刻在清单上划掉并告知新人"这个环节没拍到"，避免事后被质疑 |
| 敬酒时间只有 10 分钟 | 请新人提前划出必敬的 5~8 桌；其余用全景一张交代 |
| "再多拍两张"（新人临时加需求） | 给 3 张，同时说明剩余时间安排，把决定权交回新人 |

### 4.4 人群遮挡

- 摄影师要在仪式开始前 10 分钟占好位并**观察退路**。
- 婚礼现场"举手机的人"是最常见的遮挡源 → 提前请司仪在开场时提示大家放下手机。
- 备选机位：舞台侧前方低机位（从人缝里仰拍）、后方高机位（拍全景）。
- 被挡的瞬间：不要硬等，立刻换机位；宁可少一张全景，不要漏掉特写。

### 4.5 设备故障

| 故障 | 应急 |
|---|---|
| 机身死机 | 拔电池重装（比按电源键快）；备机必须带，且提前设好参数 |
| 卡满/卡坏 | 双卡备份写入是底线；备 1~2 张空卡 |
| 闪光灯不闪 | 检查电池、触点、TTL 模式；立刻切换为"现场光 + 高 ISO"方案 |
| 镜头进灰/起雾 | 起雾（从空调房到室外）用镜头布擦，或提前把器材放在室外适应 20 分钟 |
| 电池告急 | 备用电池 + 关掉防抖/蓝牙/触屏（省电），降低连拍 |

### 4.6 天气变化

| 情况 | 应对 |
|---|---|
| 户外仪式下小雨 | 提前准备透明伞；雨滴在透明伞上是很出片的元素；器材用防雨罩或用毛巾裹 |
| 大雨/大风 | 立刻转入备用室内方案；请司仪配合调整流程；优先保证核心瞬间 |
| 阴天 | 阴天是"超大柔光箱"，非常利于人像；提高色彩饱和度，避免灰蒙蒙 |
| 强光直射正午 | 找阴影、用闪光灯补面、或加白色柔光反射板；避免正午顶光拍人 |
| 日落太快 | 提前把"外景摆拍"排到日落前 40 分钟完成，剩余时间抓剪影 |

## 5. 儿童摄影的总体判断

### 5.1 三条底层认知

1. **儿童不是成人的缩小版**。成人的"看镜头、笑一个、别动"对儿童完全无效。儿童的注意力只有 2~5 分钟，拍摄节奏必须按这个尺度设计。
2. **安全第一，永远第一**。任何造型、道具、姿势，只要可能让儿童摔倒、卡住、误食，立刻放弃。摄影师对现场安全负有责任（尤其高处、水边、宠物、电线旁）。
3. **以抓拍为主，引导为辅**。儿童的"最好看"永远出现在他忘记镜头的时候。摄影师的核心技能是"隐身"和"等待"，而不是"指挥"。

### 5.2 家长的期待管理

**拍摄前必须说清楚**：
- "孩子今天状态不好，我们优先保证他有 2~3 张自然的好照片，不会强求他配合。"
- "有的孩子需要 20 分钟热身，前 20 分钟请给孩子时间适应，不要催。"
- "如果孩子哭闹严重，我们暂停、休息、吃点东西再继续，不要硬拍。"
- "请不要在镜头后喊孩子的名字或做鬼脸（会让孩子看向家长而不是镜头，注意力被分散）。"

**常见误区**：家长拿着手机在旁边猛拍 → 孩子看向家长、注意力被抢、照片里全是"看侧边"的眼神。请家长站在摄影师正后方。

## 6. 儿童年龄段策略

### 6.1 年龄段总览

| 年龄段 | 行为特征 | 拍摄策略 | 沟通/吸引方式 | 道具 | 单次时长 |
|---|---|---|---|---|---|
| **0~3 个月（新生儿）** | 睡眠多、动作少、不能支撑头部、颈部脆弱 | 俯拍/侧拍为主；包裹（包巾）、蜷缩姿势；用长焦（100mm+）避免打扰 | 不用沟通；靠白噪音、轻摇、喂奶后睡着的时段 | 包巾、小帽子、篮子、父母的手 | 1.5~3 小时（含喂奶休息），实际有效拍摄 30~60 分钟 |
| **3~12 个月（婴儿）** | 会躺、会翻、会坐、会爬；对声音和光敏感 | 从仰拍到俯拍；抓拍"举手踢腿""吃脚""笑出声" | 摇铃、纸巾摩擦声、父母在旁说话 | 毛绒玩具、气球、毯子、浴盆 | 45~60 分钟，分 2~3 段 |
| **1~3 岁（学步）** | 会走但不听指令；好奇心强、注意力极短 | **蹲下**到他的高度；让他自由活动，摄影师跟着拍；连拍 | 吹泡泡、躲猫猫、装动物叫、扔球 | 泡泡、气球、小车、帽子、小椅子 | 30~45 分钟，注意他困了/饿了 |
| **3~6 岁（幼儿园）** | 能听懂简单指令、爱表演、爱角色扮演 | 半引导半抓拍；设计"小游戏"而不是"摆姿势" | "你能跳多高""学小猫走路""帮我看这个镜头里有什么" | 绘本、玩偶、扮装服、画板 | 45~60 分钟，中间休息 |
| **6~12 岁（学龄）** | 能配合、有自尊心、怕"拍得不好看" | 可以摆拍，但要让他参与决定（选道具、选位置） | 平等对话、给他看回放、夸具体细节 | 球、乐器、书、宠物、运动器材 | 60~90 分钟 |

### 6.2 新生儿专项要点

| 项目 | 做法 |
|---|---|
| 时机 | 出生后 5~12 天最佳（此时仍爱睡、身体柔软、有"新生儿蜷缩"姿态） |
| 温度 | 室温 26~28℃，可用暖风机预热拍摄区（拍摄前关掉，避免噪音） |
| 安全 | 所有"抱姿/悬空"造型必须有成人双手托住，后期再修掉手；**绝不用蛮力掰姿势** |
| 光源 | 大面积柔光（窗光 + 柔光板），避用直闪（会惊吓婴儿，且伤害视力发育） |
| 声音 | 白噪音（吹风机/吸尘器录音）、轻摇、轻拍 |
| 道具 | 用软垫、篮子、包巾，硬道具加软垫 |
| 父母入镜 | 父母的手、父母的怀抱是重要素材，别只拍婴儿 |

### 6.3 学步期（1~3 岁）专项要点

- **必须蹲低**：站着的成人视角拍 1 米高的孩子，全是俯视大头顶。摄影师要蹲下甚至趴下，相机与孩子的眼睛齐平。
- **不追不喊**：让孩子自由活动，摄影师"跟踪"；追着喊"看这里"只会得到僵硬的回头。
- **连拍是核心**：1~3 岁表情变化极快，用 5~10fps 连拍，事后挑选。
- **给他一个任务**："帮我把球扔给妈妈""能不能把这本书翻给我看"，动作自然产生。
- **饥饿和困倦**：拍摄时间避开午睡与饭点。孩子开始吃手、揉眼、发呆 = 要休息了。

## 7. 儿童拍摄技法

### 7.1 机位要低

**核心原则：相机的高度 = 孩子眼睛的高度。**

| 孩子状态 | 摄影师位置 |
|---|---|
| 躺着 | 俯拍（趴在孩子正上方，注意安全）+ 侧拍（与孩子同一水平面） |
| 坐着 | 与孩子同高，蹲下或坐在地上 |
| 站着 | 跪/蹲（约 60~70cm 高），不要站着俯拍 |
| 走动/跑 | 蹲低跟拍，用连拍抓 |

**为什么**：成人站立俯拍会放大额头、压缩四肢、把孩子拍"矮小"。同高度拍摄才能得到与孩子"平等对视"的感觉，眼睛更容易成为视觉中心。

### 7.2 连拍抓表情

- 儿童的自然笑容只持续 0.5~2 秒，用连拍（5~10fps）覆盖。
- 预计"快要笑了"之前就开始连拍（如刚吹出泡泡、刚扔出球）。
- 拍完立刻看回放，找到"眼睛弯、露牙"的那张。
- 存储不是问题，挑片成本才是问题 —— 用连拍，但要定期在相机里清掉明显废片。

### 7.3 声音与玩具吸引

| 方法 | 效果 | 注意 |
|---|---|---|
| 摇铃/发声玩具 | 吸引注意力（0~2 岁最有效） | 只用在"需要看镜头"的关键一张，用多了脱敏 |
| 吹泡泡 | 吸引 + 制造动作，几乎对所有年龄段有效 | 逆光下泡泡有彩色光斑，非常出片 |
| 捏塑料纸/纸巾 | 婴儿对"沙沙声"极敏感 | 只能偶尔用，会很快失效 |
| 藏猫猫（peek-a-boo） | 1~3 岁必杀 | 由家长在摄影师正后方做 |
| 大声/突然的怪声 | 得到"惊讶的睁大眼" | 不要惊吓到哭 |
| 给家长指令（"妈妈亲他一下"） | 产生真实的互动瞬间 | 家长放在摄影师正后方 |

### 7.4 引导而非命令

**错误**："坐下、看这里、笑一个、别动"
**正确**：
- "你能帮我看看这个镜头里有什么吗？"（引导视线）
- "我们来比赛谁能跳得更高！"（制造动作）
- "你最喜欢哪个玩具？拿给我看看。"（制造互动 + 道具入镜）
- "我们数三下，然后你做一个最厉害的表情。"（游戏化）

**引导的本质**：让孩子以为在玩，实际上在完成你想要的动作。

### 7.5 家长配合

| 家长应做 | 家长不应做 |
|---|---|
| 站在摄影师正后方 | 站在摄影师旁边或侧面（孩子会看偏） |
| 用熟悉的声音安抚但不喊名字 | 大声喊"笑一个""看这里" |
| 在孩子需要时喂食/换尿布/哄睡 | 在镜头范围内走动 |
| 提前准备好吃喝、换洗衣物、玩具 | 拍摄前让孩子睡太少或吃太饱 |

### 7.6 安全红线（绝对不可妥协）

| 红线 | 原因 |
|---|---|
| 新生儿"悬空""单手托举"造型必须有成人双手托住 | 颈部无力，坠落风险极高 |
| 不给能抓握的儿童小件道具（珠子、硬币） | 误食窒息风险 |
| 不让孩子站在高处（桌子、台阶边）无人扶 | 坠落 |
| 不在水边、泳池边无人监护 | 溺水 |
| 不使用强闪光直射婴儿眼睛 | 视网膜/视觉发育风险 |
| 不让孩子接触灯具、电线、加热设备 | 烫伤与触电 |
| 不强行掰动孩子肢体摆姿势 | 骨骼与关节损伤 |
| 拍摄前确认无过敏源（花粉、宠物、毛絮） | 过敏反应 |

### 7.7 哭闹的识别与处理

| 哭闹类型 | 信号 | 处理 |
|---|---|---|
| 饿了 | 吃手、吮吸动作、烦躁 | 立刻喂奶/点心，休息 20 分钟 |
| 困了 | 揉眼、打哈欠、眼神发直、脾气变差 | 停止拍摄，睡一觉再拍（可能当天拍不了，要提前排期） |
| 害怕（陌生环境/大镜头） | 往家长怀里缩、不看镜头、沉默 | 摄影师后退、让家长抱、给 10 分钟适应期；先拍父母，再拍孩子 |
| 不舒服（太热/衣服扎人） | 出汗、扭动、拉扯衣服 | 降温、换衣（准备了备用衣物） |
| 闹情绪（想玩别的） | 摔东西、躺地上 | 换道具/换场景，或干脆休息 |

**处理总原则**：**哭闹不是要"哄住继续拍"，是要"停下来解决需求"**。硬拍出来的照片全是扭曲的表情，且会让孩子对拍摄留下负面印象。

### 7.8 拍摄时长控制

| 年龄段 | 单次连续拍摄 | 全天总时长（含休息） |
|---|---|---|
| 0~3 个月 | 15~20 分钟 | 1.5~3 小时（分段） |
| 3~12 个月 | 20~30 分钟 | 45~90 分钟 |
| 1~3 岁 | 15~25 分钟 | 30~60 分钟 |
| 3~6 岁 | 25~35 分钟 | 60~90 分钟 |
| 6~12 岁 | 40~60 分钟 | 90~120 分钟 |

超过时长后，孩子状态下滑，照片质量断崖式下降 —— 见好就收比拍到"够多"更重要。

## 8. 家庭与亲子纪实

### 8.1 全家福的排列

| 人数 | 排列方式 | 要点 |
|---|---|---|
| 3 人（含 1 娃） | 父母并排，孩子在前/中间，或母亲抱孩子 | 孩子的视线给谁？给家人比给镜头更自然 |
| 4 人（2 娃） | 父母各抱/各牵一个，或两娃在前排 | 避免娃挡住父母的脸 |
| 5~8 人 | 两排：老人在前排坐，年轻人在后排站 | 老人不要站在后排（不要够高） |
| 含婴儿 | 母亲抱婴儿为核心，其余人围拢 | 保证婴儿的脸可见、不受凉 |

**排列三原则**：① 身高从中间往两侧递增（或递减）；② 前后排错位，不遮脸；③ 身体略向中间倾斜，形成"包围感"。

### 8.2 亲子互动的引导

| 引导语 | 产生的画面 |
|---|---|
| "把孩子抱起来转一圈" | 旋转的动态 + 孩子的笑 |
| "亲一下孩子的额头/脸颊" | 亲密的瞬间，最容易出片 |
| "一起看同一本书" | 低头、靠在一起、安静的画面 |
| "爸爸把孩子举高高" | 高举动作，人脸向上，非常出彩（注意安全） |
| "一起吹蜡烛/一起数数" | 共同注意，动作统一 |
| "妈妈蒙住孩子的眼睛，猜猜是谁" | 玩闹，孩子会笑 |

**关键**：不要拍"全家人看着镜头笑"的呆板合影作为唯一素材，一定要有"互动中的抓拍"作为补充。

### 8.3 家庭日常纪实的拍法

- **不摆拍**：吃饭、洗漱、换鞋、做作业、玩耍都是素材。
- **不打断**：摄影师在场景中"隐身"20~30 分钟，让孩子与家人恢复自然状态。
- **要完整**：除了"脸"，也要拍手、脚、背影、玩具、乱糟糟的地板 —— 这些才是"那一年"的记忆。
- **连续叙事**：一组 8~15 张构成"一个早上"的故事，比 1 张完美肖像更有价值。
- **保留不完美**：掉了一颗牙、衣服上有污渍、头发乱 —— 这些细节是纪实摄影的灵魂。

### 8.4 家居光线利用

| 家里常见光位 | 拍法 |
|---|---|
| 大窗户（漫射光） | 最佳光源。让孩子面向窗户（顺光）或侧向窗户（侧光）；摄影师站在窗户同侧或对侧 |
| 只有一扇小窗 | 摄影师靠近窗户，让孩子在窗边 1~1.5m 内；用白卡反光补暗部 |
| 顶灯（钨丝/暖白） | 色温低（2700~3000K），白平衡设 3000K 左右；顶光会在眼窝留阴影，尽量加一盏侧向的常亮灯或让孩子面向窗户 |
| 逆光窗（孩子背对窗户） | 从正面补光（反光板或 LED 板），或拍成剪影 |
| 夜间/无窗的房间 | LED 常亮板（柔光罩）打天花板做漫反射，模拟"室内日光" |

**家居拍摄三招**：① 关掉顶灯，只用窗光（立刻提升质感）；② 门窗光比过大时用白色浴巾/床单/广告板当反光板；③ 降低机位到孩子高度，蹲着拍。

## 9. 婚礼与儿童诊断表

### 9.1 婚礼部分

| 症状 | 原因 | 修正 |
|---|---|---|
| 仪式照片人脸全黑、背景通透 | 逆光对背景测光 | 改对脸部点测光 + 闪光灯补面 -1.5EV；或改拍剪影并接受氛围感 |
| 宴会厅照片一半发黄一半发白 | 混合光源（钨丝吊灯 + 闪光）+ 自动白平衡 | 固定色温 4200K 拍 RAW；给闪光灯加 CTO 让色温接近；后期分区白平衡 |
| 照片里的人脸有油光、身后有硬阴影 | 机顶闪光直闪 | 改跳闪（打天花板/侧墙）；闪光输出降到 -0.7~-1.3EV；加柔光罩 |
| 敬酒时闪光灯来不及回电 | 电池老化或输出功率过高 | 换成镍氢充电电池并备 2~3 组；降功率提 ISO；用离机双灯交替 |
| 暗场晚宴拍出全黑或全糊 | 光圈不够大、ISO 过低、快门低于安全值 | f/1.4~f/2 + ISO 6400~25600；快门不低于 1/60s；加微弱 LED 常亮补光 |
| 仪式时被宾客的手机/头挡住 | 未提前占位、机位无退路 | 仪式前 10 分钟占位并留退路；请司仪提醒宾客放下手机；备侧后方低机位 |
| 交换戒指的瞬间没拍到 | 只站了一个机位、未预判动作 | 双人分工：一人特写手部、一人拍全景；提前确认仪式的具体环节与顺序 |
| 新娘化妆照头顶有大片死白 | 化妆间顶灯直射 + 闪光直闪 | 关顶灯改窗光；用柔光板/LED 板；或跳闪打天花板 |
| 接亲时楼道照全糊 | 光线极暗 + 走动中快门过慢 | 开高 ISO + f/1.4/f/1.8；闪光灯跳闪（楼道天花板低，跳闪效果好） |
| 合影时后排的脸被挡住 | 阵型对齐成方块、未错位 | 前后排错位；摄影师抬高机位俯拍；喊"高的往两边" |
| 合影时表情不统一（有人不笑/有人闭眼） | 只拍了一张 | 连拍 3~5 张，事后挑选；用"数三下"统一节奏 |
| 抛捧花只拍到花没拍到人 | 机位太近或焦段太短 | 用 24-70 广角端退后拍全景；提前预判抛出的方向 |
| 婚礼当天有环节被跳过，事后新人抱怨 | 未提前核对流程、未当场告知 | 拍摄前列出流程表请新人确认；现场发现跳过立刻口头告知 |
| 送客段落草草收尾，缺素材 | 摄影师体力透支、提前收工 | 排能量分配：宴会中段休息 10 分钟进食；送客是"最后的高价值素材"，必须守住 |
| 照片交付延迟，新人投诉 | 6000 张照片的挑片与修图工作量被低估 | 交片前给"交片时间表"；先交 50 张精选（24 小时内），全部 2~4 周内交齐 |

### 9.2 儿童部分

| 症状 | 原因 | 修正 |
|---|---|---|
| 每张都是大头顶、短腿 | 摄影师站姿俯拍 | 蹲下或趴下，相机与孩子眼睛同高 |
| 孩子全程不看镜头 | 家长站在侧面喊名字、场外有干扰 | 让家长站到摄影师正后方；用声音玩具吸引；或干脆改拍"不看镜头"的自然状态 |
| 笑容僵硬（"假笑"） | 用"笑一个"指令 | 改用游戏/互动（吹泡泡、躲猫猫、扔球）产生真实笑容 |
| 照片全是残影/糊的 | 孩子动得快、快门过慢 | 快门 ≥ 1/250s（跑动时 ≥ 1/500s）；提高 ISO；用连拍 |
| 1~3 岁完全不配合、满地跑 | 用成人方式下指令 | 不追不喊，改为"他玩你拍"；设计小任务；用连拍覆盖 |
| 新生儿照片姿势别扭、有"硬掰"痕迹 | 强行摆姿势 | 只用自然蜷缩姿势；所有悬空造型必须成人双手托住，后期修手 |
| 婴儿眼睛发红、被闪光吓哭 | 用直闪近距离拍摄 | 新生儿禁用直闪；改用窗光 + 柔光板或极弱常亮灯 |
| 孩子哭到拍不下去 | 饥饿/困倦/害怕未及时处理 | 立即停下解决需求（喂奶/睡觉/给适应时间），不要硬拍；提前排期避开午睡与饭点 |
| 一场拍摄 2 小时，后面全是废片 | 未按年龄控制时长 | 1~3 岁单次 ≤ 25 分钟；0~3 月单次 ≤ 20 分钟；见好就收 |
| 道具太抢眼，孩子成了配角 | 道具颜色饱和、体量大 | 道具尺寸小于孩子头部、颜色饱和度低于孩子衣服；1 主 + 2 辅为上限 |
| 拍完发现照片背景有安全隐患元素 | 未提前检查拍摄环境 | 拍摄前清场：移开电线、尖锐物、易倒家具、宠物食盆 |
| 全家福里总有人闭眼/表情不好 | 只拍一张、没有统一节奏 | 连拍 3~5 张；用"数三下"统一；摄影师自己也要在快门时保持口令节奏 |
| 家居纪实拍得像摆拍 | 摄影师打断了家庭自然状态 | 先隐身观察 20~30 分钟；用长焦从远处拍；不要求"看这里" |
| 家居照片又黄又暗 | 顶灯（2700K）+ 未调白平衡 | 关顶灯只用窗光；白平衡设 3000~3500K；用白浴巾/白板反光补暗部 |
| 亲子互动照片中父母表情用力 | 父母紧张、被"要求表演" | 给父母具体的动作指令（"亲一下额头""把孩子举起来"），而不是"表现得开心一点" |
| 拍摄后家长说"和我想要的风格不一样" | 拍摄前未对风格达成一致 | 开拍前给 5~10 张参考图确认风格；先拍几张给家长看，确认方向再继续 |
| 孩子在陌生影棚不敢动 | 环境陌生 + 大灯大相机压迫感 | 提前让家长带孩子来熟悉 10 分钟；摄影师先与孩子玩，再拿相机；先用小相机或手机过渡 |
| 照片修完家长说"不像我孩子" | 过度磨皮/改变五官/色调过重 | 儿童后期只做基础调整（曝光、白平衡、轻微锐化、去污点），不磨皮、不改脸型、不改瞳色 |
