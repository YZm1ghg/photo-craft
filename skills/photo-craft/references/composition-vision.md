## 0. 构图的本质

### 0.1 构图是控制观看顺序，不是套公式

构图唯一的目的：**让观众的眼睛按照你设计的顺序移动，并在该停的地方停下来**。一张照片在观众眼里只活 1～3 秒，视线路径是：落点（最亮/最实/最对比处）→ 次落点 → 环境 → 出画。构图就是给这条路径铺路。

- 想让他先看眼睛 → 眼睛处必须有最高对比度（最亮的高光 + 最深的瞳孔 + 最锐的焦点）。
- 想让他看完脸再看手里的花 → 花的亮度与饱和度必须**低于**人脸 20%～30%，让它成为"第二站"而不是"抢站"。
- 不想让他看角落那个白色塑料袋 → 裁掉、压暗 1 档，或用虚化把它变成一团灰。

**最有效的判断法：眯眼看。** 眯到看不清细节，若画面里仍只有一个亮点在吸引你，构图成立；若同时有三四处在闪，构图散了。

### 0.2 秩序 vs 混乱

"秩序"不等于"对称"，而是**画面元素之间存在可被读懂的关系**。

| | 秩序感强 | 混乱 |
|---|---|---|
| 元素关系 | 元素之间有对齐/递进/呼应/重复 | 元素各占一处，互不解释 |
| 边界 | 每个元素都完整或有明确被切断的理由 | 元素被边框随意切一半 |
| 明暗 | 有主调（高调/低调/中间调），层次可控 | 到处都亮、到处都暗，无主调 |
| 观众反应 | "这是一张照片" | "这是随手一按" |

混乱的典型成因（按频率排序）：①主体不明确（两个同等抢眼的元素）②背景高光或高饱和色块抢戏 ③水平线歪了（歪 3° 就让人觉得"没拍好"）④边框切割元素切在难受位置（见 5.1）⑤前景挡了主体一小块且像失误而非设计。

### 0.3 先做减法

**构图的 80% 是排除，不是添加。** 现场永远先问："画面里有什么是可以不要的？"

减法清单（按优先级删）：①与主体无关的**人**（尤其背景里半个路人）②高光斑点（反光地面、玻璃、白车、天空露出的白块）③高饱和杂色（红绿灯、广告牌）④与主体重叠的干扰物（"头上长树""肩上长杆"）⑤画面边缘的碎块元素（半个叶子、半个人）⑥最后才收紧取景框。

**为什么减法优先于加法**：人的注意力是单通道的，任何多余元素都会按它的抢眼程度分走注意力，不会"并存"。你没法靠"主体拍得更亮"抵消一个抢眼的干扰物——只能删掉它。

**减法的三种手段**（按现场可行性排序）：①**换机位**：走两步、蹲下、站高——最有效也最被忽略 ②**换焦段/光圈**：长焦压缩 + 大光圈虚化，把背景化成色块 ③**等**：等路人走开、等车开走、等云挡住太阳。好构图经常是等出来的。

## 1. 取景与画幅

### 1.1 横画幅

| 属性 | 说明 |
|---|---|
| 心理感受 | 平静、开阔、稳定、叙事性强、像"看" |
| 视觉方向 | 强调水平方向的力量，横向读图 |
| 适合 | 风光、环境人像、双人并坐、街景、群体、叙事组图、电影感 |
| 不适合 | 单人竖向站立的全身、竖向建筑主体、强调高耸或压迫 |
| 常见失误 | 把主体放正中却左右各留一大块空白，两边都空 |

**为什么横画幅显得平静**：人的双眼水平排列、视野本身是横的，横画幅接近自然视野所以"不施压"；也因此需要更强的内部结构（引导线、分组）才不显平淡。

### 1.2 竖画幅

| 属性 | 说明 |
|---|---|
| 心理感受 | 高耸、紧张、聚焦、力量感、像"被看着" |
| 视觉方向 | 纵向读图，天生适合单一主体 |
| 适合 | 单人全身/半身、竖构图人像、高楼、树、瀑布、单枝花、时尚片 |
| 不适合 | 开阔风景（会变成上下两条空带）、横向排列的群体 |
| 常见失误 | 主体只占中间一小块，上下留大片无关空间 |

竖画幅是**人像的默认画幅**（与人体形状同构，天然排除左右干扰）。上下留白通常**头部上方略大于脚下**（人眼习惯给"上升空间"，见 4.1）。

### 1.3 方画幅

| 属性 | 说明 |
|---|---|
| 心理感受 | 稳定、端庄、复古、无方向性、像"被框住的一幅画" |
| 视觉方向 | 无主方向，逼观众在画面内打转 |
| 适合 | 中等距离肖像、静物、极简、双人对称、中画幅气质片 |
| 不适合 | 需要明确横向叙事或纵向拉伸张力的题材 |
| 常见失误 | 不做裁剪直接套方画幅，两边被切得莫名其妙 |

**方画幅最难也最能体现功力**：它取消了"往哪边铺展"这个偷懒的出口，平衡全靠画面内部元素自己完成。用方画幅时**主体几乎不放在正中**——除非你要的就是那种被凝视的静态感。

### 1.4 其他长宽比

| 比例 | 名称 | 气质 | 用途 |
|---|---|---|---|
| 3:2 | 全画幅原生 | 中性、通用 | 通用、新闻、日常 |
| 4:3 | M4/3、手机主摄默认 | 略扁、信息多 | 旅行记录、手机常用 |
| 16:9 | 宽银幕 | 电影感、开阔、孤独 | 风光、叙事、Vlog、封面 |
| 21:9 | 超宽 | 强烈的电影/史诗感 | 大风景、城市天际线 |
| 5:4 / 4:5 | 中画幅 / Instagram 竖 | 稳定、端庄、气场 | 肖像、杂志、社交平台竖图 |
| 1:1 | 方 | 复古、静物感 | 肖像、静物、极简 |

**选比例的顺序**：先想画面内容天然是什么形状（一条河 → 横；一栋楼 → 竖），再选比例，**不要先定比例再塞内容**。

### 1.5 留白

留白不是"空"，而是**有意留给眼睛休息与想象的部分**。

- **留白要"空得干净"**：白墙、天空、纯水面、虚化的草地算好留白；花哨的墙纸不算留白，那叫背景。
- **留白方向由视线决定**：人看向右边，右侧留白（"视线空间"）。方向错了会让人觉得"撞墙"（见 4.1）。
- **留白比例经验值**：极简片主体占 15%～30%；常规人像主体占 40%～60%；不留白的"满构图"适合纹理、图案、拥挤感。
- **留白下限**：主体与画框之间任一边空白若小于主体宽度的 10%，看起来就像"被挤住"——要么再挤紧（让它明确被切），要么放开到 15% 以上，**不要停在"没想清楚"的中间距离**。

### 1.6 裁切时机：前期切还是后期切

| | 前期（取景时裁） | 后期（二次构图） |
|---|---|---|
| 画质 | 无损，用满全部像素 | 有损，裁多少丢多少像素 |
| 判断力 | 所见即所得，逼你想清楚 | 屏幕大、能慢慢看，判断更准 |
| 风险 | 当时觉得好，回看发现构错了 | 裁多了画质崩、像素不够 |
| 适用 | 决定性瞬间、街拍、抓拍、动态主体 | 静物、人像、风光、可重拍题材 |

**混合策略（推荐）**：①现场按**最紧的构图**拍一张（保证主体拍到），不过度留余地 ②同时向外再拍 1～2 张"宽容版"（四边各多留 10%～15%）作后期原料 ③**不要"先随便拍回头裁"**——那会让你从不预判构图 ④**不要"现场裁到死"**——表情好但构图差一点就没退路。

**实用规则**：不确定时**宁可拍松一点**。裁掉 10% 是小事，缺 10% 是没救。

## 2. 基本构图法与其局限

**重要前提**：下面这些全是**经验总结**，不是物理定律。它们描述的是"大多数情况下人的眼睛喜欢什么"。真正好的构图经常来自刻意打破它们。**先学会，再违反**——但违反必须是有意图的，不是为了显得特别。

### 2.1 三分法（九宫格）

**原理**：把画面按横竖各三等分，四条线的四个交点放主体。为什么有效？因为把人眼最舒适的落点放在**偏离中心的位置**——中心太静态、太像"靶心"，而边缘又太不稳定。三分点介于两者之间，是"有张力但可控"的甜点区。

| 项目 | 说明 |
|---|---|
| 怎么用 | 开启相机九宫格辅助线；主体眼睛/地平线压在线上，主体重心放在交点上 |
| 常用变体 | 地平线压在上 1/3 线（强调地面）或下 1/3 线（强调天空）；人脸压在左上或右上交点 |
| 什么时候不要用 | ①强对称题材（建筑正面、倒影、镜面）②极简中心构图 ③需要表现被"钉死/困住"的压迫感 ④主体本身在正中心且画面元素向中心汇聚（隧道、走廊） |
| 常见滥用 | 每张都压线，导致所有照片看起来一个模子；地形线正好压在三分线却与画面中其他元素冲突；为了压线把主体切在尴尬位置 |

**最常被忽略的**：三分法是"线"与"点"两个工具，很多人只用点（交点放主体），忘了线（地平线、栏杆线、屋檐线压在三分线上往往比放中心更舒服）。

### 2.2 黄金分割（约 0.618）

**原理**：把一个整体分成 1 : 0.618 的比例被认为最悦目。它的视觉效果与三分法非常接近（0.618 ≈ 1.5/2.43，三分点是 0.667），**本质上是同一类审美**。

| 项目 | 说明 |
|---|---|
| 怎么用 | 主体居中偏离约 38% 处；螺旋线（斐波那契螺旋）适合安排"从大到小、从主到次"的递进元素 |
| 什么时候不要用 | 与三分法相同。不要为了"更精确"而在现场纠结 0.618 和 0.667 的差别——相机屏幕上看不出 |
| 常见滥用 | 拿螺旋线硬套画面，事后找线来"证明"构图合理；把黄金分割当成神秘法则，忽略内容 |

**务实建议**：不要背比例，背**感觉**——"主体放在三分之一到四成处"，差百分之几眼睛分辨不出来。

### 2.3 中心对称

**原理**：主体居中 + 左右（或上下）元素对称。人的大脑对对称有天然的"完成感"，因此对称画面**稳定、庄严、正式、有仪式感**。

| 项目 | 说明 |
|---|---|
| 怎么用 | 建筑正立面、走廊、桥、倒影、窗、门、对称的树、模特正面居中；必须做到**真的对称**（左右误差 < 2% 看不出），否则是失误不是风格 |
| 什么时候不要用 | 想表现动感、轻松、随意、生活化时；画面对称但背景不对称时（半张脸有光半张没有） |
| 常见滥用 | 对称不够彻底，观众会本能地觉得"偏了"；用对称构图拍活泼题材，得到一张僵硬的证件照 |

**不完美对称**：故意保留一个不对称的小元素（一个人走过、一个气球飞起）能打破僵硬、制造故事感——从"对称"升级为"对称 + 一点意外"。

### 2.4 对角线

**原理**：对角线是画面中最长的线，也最有动态。元素沿对角线分布，等于给视线铺了一条**贯穿全画面的高速路**。

| 项目 | 说明 |
|---|---|
| 怎么用 | 身体线（肩线、胳膊、腿）、道路、栏杆、山脊、光束沿对角线走；从角落向对角延伸能获得最强纵深 |
| 什么时候不要用 | 需要稳定、安宁、庄重时（对角线的紧张感会破坏）；主体本身不该有方向感时 |
| 常见滥用 | 为了对角而对角，导致画面像被"劈开"；对角线上没有内容，只有一条线，画面反而空 |

**升级用法**：两条交叉对角线（X 形）形成强烈的汇聚与张力，适合冲突、速度、戏剧性。

### 2.5 S 形与曲线

**原理**：曲线（S 形、C 形、弧形）比直线更柔和、更有韵律，视线沿曲线移动时会**放慢**，因此画面显得舒缓、优雅、有余味。

| 项目 | 说明 |
|---|---|
| 怎么用 | 河流、小径、海岸线、蜿蜒的公路、模特身体的 S 形姿态、飘起的裙摆、弯曲的树枝 |
| 什么时候不要用 | 主题是力量、直接、硬朗时（曲线会削弱）；曲线太弱看不出形状时不如用直线 |
| 常见滥用 | 号称 S 形但观众看不出来；曲线从画面边缘"突然进入"，没有起点交代 |

**关键**：曲线构图必须有**两个以上转折**才成立；只有一个弯的是"C 形"，观感是"一片弧"而非"一条流动的线"。

### 2.6 三角形

**原理**：三角形是最稳定的几何形，同时能建立视觉层级（顶点最受注意）。

| 类型 | 效果 | 用途 |
|---|---|---|
| 正三角（底边在下） | 极稳定、坚固、庄重 | 群体合影、山、建筑、家庭三角 |
| 倒三角（顶点在下） | 不稳定、紧张、动感 | 表现失衡、跳跃、瞬间、冲突 |
| 斜三角 | 有方向感的动势 | 运动、动态、行进 |

- **怎么用**：用三个人的头、三个物体、或身体线条（头—肘—胯）构成三角；顶点放三分点附近效果最好。
- **不要用**：画面已够复杂时再加三角 = 更乱；题材没有天然三角结构时别硬凑。
- **滥用**：两人合影一高一低的"斜线"是失败的三角——三角需要明显的**第三点**（后景的树、路牌）来闭合。

### 2.7 框架式构图

**原理**：用前景元素在画面内画一个"框"，把主体框在里面。它同时做三件事：①排除框外的干扰 ②制造"窥视"的心理暗示 ③增加一层景深维度。

| 框的类型 | 例子 | 注意 |
|---|---|---|
| 自然框 | 树枝、藤蔓、树叶间隙 | 树枝不要太抢眼，虚化处理 |
| 建筑框 | 门、窗、拱、柱子 | 框要竖直（尤其建筑内），歪了会毁掉整张 |
| 人框 | 两人之间的间隙、肩膀、手臂 | 适合群像里突出一个人，但要注意不要显得刻意 |
| 光影框 | 一束光打亮的区域 | 高级但难控，需要精确测光 |

- **什么时候不要用**：框太重太暗会把主体闷死（框要虚于主体）；主体太小导致"框里一片空"（框内主体占比建议 > 25%）；框的开口方向与视线方向冲突。
- **常见滥用**：框太宽（等于没有框）、框不在画面边缘（悬在中间显得像一堆杂物）、做框的前景比主体更抢眼。
- **量化提示**：做框的前景元素曝光建议**比主体低 0.7～1.5 档**，虚化程度以"能看出形状但看不清细节"为准。

### 2.8 引导线

**原理**：线条引导视线。任何有方向的元素——路、栏杆、影子、光束、河流、墙线、甚至一排人的视线——都能把观众的目光**运送到**主体。

| 类型 | 效果 | 强度 |
|---|---|---|
| 汇聚线（向主体收敛） | 最强，直接把视线钉到主体 | ★★★★★ |
| 平行引导线（向主体方向延伸） | 强，有纵深但不收敛 | ★★★★ |
| 曲线引导 | 舒缓，慢速运送 | ★★★ |
| 断线/虚线段（虚线状的栏杆、斑马线） | 有节奏，观感轻松 | ★★★ |
| 反向线（背离主体） | 破坏性，除非刻意用来制造"逃离感" | ★ |

- **核心规则**：引导线必须**从画框边缘出发**并**指向主体**。从画面中间凭空开始的线毫无作用。如果一条线指向画面里某个角落而不是主体，那就是"导错方向"——要么改裁切，要么在角落里放个东西。
- **什么时候不要用**：有多条引导线指向不同方向时（观众会混乱）；引导线太强时会喧宾夺主。
- **常见滥用**：以为画面里只要有线就是引导线；路边的线指向天空而不是人；多条线汇聚到画面外。

### 2.9 重复与韵律

**原理**：重复的元素（窗、柱、伞、人、树）形成"图案"（pattern），给人以秩序与韵律的美感。重复的**关键在于打破**——纯重复是壁纸，打破重复才成照片。

| 手法 | 做法 | 效果 |
|---|---|---|
| 纯重复 | 满画面同类元素 | 图案感、抽象、可作纹理 |
| 重复 + 打破 | 一排相同的窗，其中一个开了/亮了/有人 | 强烈的故事性，最推荐 |
| 重复 + 渐变 | 从大到小、从密到疏 | 纵深感、韵律感 |
| 重复 + 倾斜 | 排列方向与画框成角 | 动态、节奏 |
| 重复 + 遮挡 | 间隔出现 | 节奏与期待感 |

- **什么时候不要用**：题材本身元素杂乱且不构成规律时（那不是韵律是噪声）。
- **常见滥用**：把一堆相似的东西拍下来就说是"韵律"，但画面里没有任何变量或强调，"打破"的点不够明显。

### 2.10 对比

**原理**：视觉靠差异建立。两个元素只有在某维度上不同，才互相定义。**没有对比，就没有画面。**

| 对比类型 | 手段 | 具体数值/做法 |
|---|---|---|
| 大小对比 | 远近、参照物 | 大物体靠近 + 小物体远；人放在建筑旁作比例尺 |
| 明暗对比 | 曝光、光位 | 主体亮背景暗，或反之；光比 1:4 以上形成强明暗 |
| 色彩对比 | 色相、饱和度 | 互补色（红/青、蓝/橙）最抢眼；冷暖相对；一个高饱和色 + 大片灰 |
| 虚实对比 | 景深、拖影 | 主体锐背景糊；慢门人虚背景实；f/1.4～f/2.8 强虚化 |
| 动静对比 | 快门速度 | 1/8～1/30s 让人物轻微拖影，背景清晰；或反之 |
| 质感对比 | 材质并置 | 粗糙 vs 光滑、柔软 vs 坚硬 |
| 情绪对比 | 表情、氛围 | 大笑 vs 冷脸、热闹 vs 寂寥 |
| 数量对比 | 多 vs 少 | 一人 vs 一群人 |

- **什么时候不要用**：对比太多维度会互相抵消，一张照片**集中做一种对比**最有效。
- **常见滥用**：为了"色彩对比"塞进各种鲜艳颜色，结果是花不是对比；明暗对比过强导致高光溢出或暗部死黑。

### 2.11 本节小结：什么时候该丢掉套路

出现以下任一情况，就直接丢开构图法，**用眼睛判断**：

1. 画面里已经有强烈的结构（巨大的光影、强对称建筑、大面积色块）。
2. 主体处于极其罕见的瞬间（一个表情、一个动作），此时"拍到"高于"构好"。
3. 你在拍一组片，前面 10 张已经套用了三分法，第 11 张必须换个结构。
4. 画面里的元素实在无法归入任何法则，但它看上去就是对的——**相信眼睛，法则只是事后解释**。

## 3. 视觉元素与设计

### 3.1 点、线、面

画面里的所有东西都能还原成这三种基本元素。看懂它们，构图就从"感觉"变成"可分析"。

| 元素 | 定义 | 视觉作用 | 摄影中的例子 | 处理要点 |
|---|---|---|---|---|
| **点** | 画面中面积小、独立、被感知为"个体"的东西 | 吸引注意的最低单位；点越多画面越乱 | 人、鸟、船、月亮、花蕾、灯 | 点的位置决定构图；同一画面里**主要点不超过 2 个** |
| **线** | 有方向、有长度的元素 | 引导、分割、产生动势 | 树枝、路、栏杆、河、电线、地平线 | 线要有起止；不要有"横穿画面中间"的无效线 |
| **面** | 大面积的色块或明暗区域 | 决定画面的基调与重量分布 | 天空、水面、墙、草地、阴影 | 面与面的**边界**是构图的关键（边界在哪，观众就在哪读图） |

**点线面实战检查**：
- 画面里的"点"有没有超过 3 个？超过就考虑删或压暗。
- 主要的"线"有几条？超过 3 条会互相抢。**一条主线 + 一两条辅线**最稳。
- "面"的划分是否明确？如果明暗面切分得模棱两可，画面会"平掉"。

### 3.2 形状

观众在识别细节之前，先识别**轮廓形状**。所以画面在小尺寸下（手机缩略图、社交平台预览）好不好看，几乎完全由形状决定。

- **强形状**：圆（太阳、眼睛、球）、三角（山、帐篷）、矩形（窗、建筑）、漏斗形（路、走廊）。它们辨识度高，适合做主体的"骨架"。
- **负形（negative shape）**：主体之外的空白区域形成的形状。**负形和正形同等重要**——一个漂亮的负形（比如街拍里人物之间那片规则的天空）能救活一张构图平淡的照片。
- **形状呼应**：画面里出现两个形状相似的元素（圆形的路灯 + 圆形的头），会产生微妙的愉悦感，这是"设计感"的来源之一。
- **形状冲突**：画框是矩形，所以画面里太多与边框平行的矩形会显得死板；加入斜向、曲线形状能打破。

### 3.3 质感（texture）

质感是"表面给人的触觉暗示"。它需要**光**才能被看见：侧光最强，正面光最弱。

| 质感类型 | 表现手法 | 光位 | 案例 |
|---|---|---|---|
| 粗糙质感 | 强调颗粒、凹凸 | 侧光 45°～90°，小光源 | 砖墙、树皮、麻布、老人皮肤 |
| 细腻质感 | 强调平滑、柔和 | 散射光、大光源 | 丝绸、皮肤、瓷、水面 |
| 混合质感 | 粗糙与细腻并置 | 侧光 | 粗糙的手握着丝绸 |

- **质感的价值**：它给二维照片加了"第三维"的暗示，是廉价感和高级感的重要分水岭。
- **反面**：散射光下所有质感都会消失（这就是阴天拍东西"平"的原因），需要用**后期加清晰度/纹理**来部分弥补，或者**换题材**。
- **量化提示**：想让质感强烈，用**侧逆光 + 小光圈（f/8 以上）+ 高锐度**；实际布光时让光源与拍摄轴成 **60°～120°** 效果最明显。

### 3.4 图案（pattern）

图案是"重复的形状/质感/色彩"构成的规律。

- 图案本身可以成为**唯一主体**（墙上的砖、稻田的纹路、一把雨伞的排列）。这时图案的**规律性**就是内容。
- 图案的**中断**（一个不同的元素）把"图案"变成"故事"。
- **拍摄图案的技巧**：用长焦压缩（去掉透视，让重复更规整）、让图案充满画面到边缘、尽量正面垂直拍摄。

### 3.5 空间层次：前景 / 中景 / 背景

**一张有纵深的照片里，这三层各有任务**，缺一层画面就会"贴"在纸上。

| 层 | 任务 | 常见问题 | 处理 |
|---|---|---|---|
| **前景** | 交代环境、制造纵深、框住主体、提示"摄影师站得近" | 太抢眼、挡主体、脏乱 | 虚化（f/1.8～f/2.8 或长焦）、压暗 0.7～1.5 档、选有质感的元素 |
| **中景** | 主体所在层，必须最清晰、最有信息量 | 主体与背景粘连 | 保证中景是画面里对比度最高、最锐的区域 |
| **背景** | 交代环境、提供氛围、衬托主体 | 杂乱、抢戏、与主体融合 | 长焦压缩 + 大光圈虚化、换角度避开杂物、后期压暗降低饱和 |

**一条实用排序**：**前景最暗最虚 → 中景最亮最实 → 背景居中**（或者反过来，背景最亮），关键是要有明显的"三层明暗/清晰度差异"，三层一样就会糊成一片。

### 3.6 纵深营造（二维变三维）

照片是平的，纵深全靠"暗示"。**七种手段，用得越多纵深越强**，但一张照片用两三种就够。

| 手段 | 原理 | 具体做法 | 强度 |
|---|---|---|---|
| **线性透视** | 平行线在远处汇聚 | 找带汇聚线的构图（路、铁轨、长廊）；用广角加强 | ★★★★★ |
| **空气透视** | 远处的物体被大气减淡对比度、偏蓝、变浅 | 拍多层山/树/建筑，拉开层间距离；用长焦压缩后层次更明显 | ★★★★★ |
| **重叠遮挡** | 前面的东西挡住后面的，大脑推断"前后" | 让前景挡住背景的一部分（不要重叠太多，挡 1/3 以内） | ★★★★ |
| **大小对比** | 同样的东西远处看起来小 | 同一物体在画面里出现"大—小"两个版本（大小树、大小人） | ★★★★ |
| **清晰度递减** | 近锐远虚 | 大光圈 + 中长焦（85～200mm），虚化随距离递减 | ★★★★ |
| **明暗递减** | 近处亮远处暗（或反之） | 利用逆光/侧逆光，让远处蒙一层暗或亮 | ★★★ |
| **色彩递减** | 近处饱和远处灰 | 逆光或雾天最明显，可后期加"去雾/加雾" | ★★★ |

**最被低估的组合**：**重叠遮挡 + 空气透视 + 线性透视**。风景片里"一层层山从暗到亮推过去"就是这个组合。

### 3.7 视觉重量与平衡

**视觉重量**是"这个元素看起来有多重"。构图是否平衡，就是看左右上下两半的视觉重量是否相当（不一定相等，但要有**呼应关系**）。

决定视觉重量的因素（按影响力排序）：

| 因素 | 加重 | 减轻 |
|---|---|---|
| 大小 | 面积大 | 面积小 |
| 对比 | 与周围反差强 | 反差弱 |
| 亮度 | 亮（在暗背景里）或暗（在亮背景里） | 中间调、与背景接近 |
| 色彩 | 饱和、暖色、红黄橙 | 低饱和、冷色、青蓝 |
| 位置 | 远离画面中心、偏角落 | 靠近中心（中心最轻） |
| 内容 | 人脸、眼睛、文字、动物 | 纯背景、纹理 |
| 锐度 | 清晰 | 虚化 |
| 孤立度 | 四周空旷 | 与其他元素挤在一起 |

**平衡的实战判断法**：
1. 眯眼看，脑子里把画面竖切两半，比较左右的"压手感"。差太多 → 失衡。
2. 失衡时**优先在轻的一侧加小但重的元素**（比如一个亮点），而不是移动主体——移动主体会破坏原有的视觉中心。
3. 有意失衡也是一种表达（一侧极重 = 不稳定、压倒、孤独），但要有意图。

**常见错觉**：人像里人脸是超重的，所以人即使只占画面 20%，放在一侧也能压住整张画面。**不要为了"平衡"在另一边硬塞一个大物体**——那往往变成抢戏。

## 4. 视线与心理

### 4.1 视线方向与留白

**规则**：人在画中看向某处，**那一侧必须有留白，并且留白要大于背向侧**。

| 情况 | 效果 | 建议留白比 |
|---|---|---|
| 视线朝向的一侧留白 | 舒展、有期待、有故事 | 朝向侧 : 背向侧 ≈ 2:1 至 3:1 |
| 视线朝向的一侧不留白（"撞墙"） | 压抑、窘迫、紧张 | 只有刻意表现压迫感时用 |
| 直视镜头 | 打破第四面墙，与观众对视 | 留白可对称，也可偏向一侧做不对称 |

**为什么**：人看照片时会本能地把视线方向当成"运动方向"，并自动在视线前方留出心理空间。前方没空间 = 感觉主体被画框困住、下一秒要撞上边框。

**同理适用于**：
- 正在走路的人（朝向侧留白）。
- 骑行/驾驶的车辆（朝向侧留白）。
- 动物、飞鸟（朝向侧留白）。
- **例外**：背影（背向观众走远）时，走向的那一侧留白反而更强——"走向远方"。

### 4.2 被摄主体的朝向空间（look room / lead room）

给朝向空间的量：

- **特写**：视线前方留白 ≈ 头宽的 50%～150%。
- **半身**：前方留白 ≈ 头宽的 100%～200%。
- **全身 / 环境人像**：前方留白 ≈ 身高的 30%～80%。
- **运动主体**：前方留白 ≈ 主体宽度的 1～2 倍，越快要越多。
- **低于上述下限**：会"憋"；**高于上限**：主体显得很小、很孤单（有时正是要这个）。

### 4.3 引导观众眼睛的路径设计

设计一条路径，让眼睛按你想要的方向走。方法：

1. **确定落点**：最亮 + 最锐 + 对比最强的地方就是落点，这必须是你想让人先看的（人像 = 眼睛）。
2. **安排第二站**：给第二重要元素一个次级强调（稍低对比、稍低亮度、稍低饱和），**不要与落点同级**。
3. **铺路**：用引导线、明暗渐变、形状连续性把落点与第二站连起来。
4. **挡住出口**：在画面边缘（尤其是四个角）避免高对比元素，否则眼睛会被"漏出去"，路径断掉。
5. **收尾**：路径终点（或画面的"安静角落"）应该是留白或低对比区域，给眼睛一个停顿。

**验证方法**：闭眼 3 秒再睁眼，看第一眼落在哪，第二眼落在哪。如果与设计不符，就调整。这个测试比任何构图法则都直接。

### 4.4 张力与稳定

| 想要 | 手段 | 具体做法 |
|---|---|---|
| **稳定** | 水平线水平、对称、中心、正三角、大面积平铺、正面光 | 地平线放中心或三分线且水平；主体居中；构图四平八稳 |
| **张力** | 倾斜、失衡、被裁切的主体、大面积留白 + 极小主体、强对比、倒三角 | 相机倾斜 5°～15°（更多会显得像失误）；主体压在画面边缘；主体被边框切一半 |
| **紧张** | 视线撞墙、主体被挤在角落、前景遮挡、强烈明暗分割 | 让人物紧贴画框一侧，朝向侧不留白 |
| **辽阔 / 孤独** | 极小主体 + 极大环境、大量留白、高机位 | 主体占画面 < 10%，放在下 1/3 |
| **压迫** | 仰拍、主体充满画面、暗调、强烈暗角 | 主体占画面 > 70%，暗背景，仰角 20°～30° |

**关键区别**：**张力 = 画面内部有未解决的紧张关系，但整体仍平衡**。倾斜 3° 是错的，倾斜 10° 是有意的——**幅度决定是事故还是风格**。

### 4.5 静止与运动的心理暗示

- 水平 = 静止、安宁、死亡、终结。
- 垂直 = 生长、挺立、界限。
- 斜线 = 运动、变化、不稳定。
- 曲线 = 流动、柔和、连续。
- 汇聚 = 逼近、聚焦、速度。
- 发散 = 逃离、扩散、失控。

拍一个"安静地坐着的人"时用水平线增强静；拍"起跑的人"时用斜线增强动。**线条方向要服务于情绪**。

## 5. 人像构图专项

### 5.1 裁切禁忌（最常出错的地方）

| 禁忌 | 原因 | 正确做法 |
|---|---|---|
| **切在关节上**（腕、肘、膝、踝、指关节） | 观感像被截肢，观众会不适 | 切在关节**之间的中段**（小臂中段、大腿中段） |
| **切头顶**（把头顶削掉一点） | 看起来像失误、显得局促 | 要么**完整留出头顶**（上方留 3%～8% 头高），要么**明确切在额头/眉毛下**（这是有意的紧构图） |
| **切在下巴上**（下巴尖刚好被切） | 最难受的切法之一 | 要么留全下巴 + 脖子，要么切到嘴唇以上 |
| **切在脖子正中间** | 像断头 | 避免；要么含肩，要么到下巴以上 |
| **切在发际线/耳朵一半** | 观感怪异 | 避免 |
| **手被切一半** | 明显的失误感 | 要么完整拍到手，要么切在手腕以上（前臂中段） |
| **脚被切一半** | 全身照的经典失误 | 要么完整含脚并有少量下方留白，要么明确切在小腿中段 |
| **切在腰部最细处** | 会显得腰被"截断" | 半身像切在**腰线以下 5～10cm**（胯上方）或者干脆到胸下 |
| **切在高光炸裂的位置** | 视觉上被"烧掉" | 避免，或后期压高光 |

**一句话记法**：**裁切要么离关节远，要么离关节近到明显是"有意为之"，不要停在不尴不尬的中间。**

### 5.2 头部留白与下巴和画框的关系

- **头顶留白**：常规人像= 画面高度的 3%～8%；过紧显得压抑，过松显得头小颈长（写真片常用 10%～15% 显脸小）。
- **下巴到画框底部的距离**：特写里建议 > 下巴高度的 1 倍；否则下巴像"顶住"了画面底部。
- **头顶和下巴留白的关系**：不要让上下留白相等（会显得像证件照）。常规是**上略多于下**。
- **眼平线的位置**：在特写/半身里，眼睛通常放在画面**上 1/3 线**附近最稳。眼睛低于中线会让脸显长、显沉重。
- **不要把头顶留白留成"半个天空"**：如果主体小、天空大，那主体必须明确放在下 1/3，让空出来的部分承担"环境"的作用，而不是"主体没拍好"。

### 5.3 半身像与全身像的构图习惯

| | 半身像 | 全身像 |
|---|---|---|
| 画幅 | 竖画幅为绝对主流 | 竖画幅（环境人像可用横） |
| 主体占比 | 画面高度的 55%～80% | 画面高度的 40%～70% |
| 裁切 | 切在腰以下（胯上）或大腿中段 | 完整含脚，脚下方留 2%～5% |
| 眼睛位置 | 上 1/3 线附近 | 上 1/3 线略上方（因为头顶到脚距离大） |
| 手的位置 | 手要么完整入画（有动作），要么完全不入画（切成半身别把手露一点） | 全身照手必须有事做（插兜、扶腰、拿物） |
| 背景 | 长焦 + 大光圈虚化即可 | 需要交代环境 → 用中景层次、找有特征的背景 |
| 常见问题 | 手臂被切一半、头顶切掉、背景杂物"长头上" | 拍成"罚站"（无重心腿、无腰线）、脚下没有留白 |

### 5.4 双人与群体的排列

| 场景 | 排列要点 | 避免 |
|---|---|---|
| **双人（情侣/朋友）** | 两人**不要平行并立**。用前后错位（一前一后）、高度差（一站一坐）、朝向差（一人面向镜头、一人侧脸）、靠近（头/肩相接形成"一个整体"） | 两个人像"证件照"一样并排站；两人各自看不同方向但没有关系 |
| **双人（对望）** | 两人的视线形成一条线，中间留出"关系空间"，画面可以横向；构图用横画幅或方画幅 | 把两人分别放在画面两个边角，中间一大块空白无内容 |
| **三人** | 三角排列（正三角最稳）或者一前两后（V 字）；视线朝向统一或形成互动 | 三人一线排开（最呆板） |
| **群体（4～8 人）** | 高低错落（有人站有人蹲/坐），前后两排，脸部尽量在同一"高度带"；用中长焦 + 远距离避免透视变形；构图居中或对称最稳 | 各人头部高度差距过大；边缘的人被裁掉一半 |
| **大合影** | 必须用三脚架 + 小光圈（f/8）+ 正面均匀光；分排（前一排蹲，后排站）；画面横向居中，两侧留白对称；地平线/背景线避免穿头 | 用广角近距离拍（两侧人脸变形严重）；前后排人脸重叠遮挡 |
| **群像里的"主角"** | 群像里可以安排一个人站在不同位置、不同方向、或不同色衣服，来暗示他是重点 | 所有人平均分配，画面没有读图的落点 |

**群像的统一原则**：**视线统一**（都看镜头，或都看同一处）比"各看各的"好一百倍。拍照前喊一句"看这里"是性价比最高的动作。

### 5.5 环境人像：主体与背景的比例

| 类型 | 人物占比 | 目的 | 关键 |
|---|---|---|---|
| 环境人像（Environmental） | 人物 15%～35% | 用环境讲"这个人是谁/在哪/做什么" | 环境必须**有信息**（有故事的地标、物件），人物是环境的"锚点"而非中心 |
| 情境人像 | 人物 35%～60% | 环境与人并列 | 人物与环境的**关系**要明确（人在门口、人望向海、人倚着墙） |
| 常规人像 | 人物 60%～80% | 人物为主，环境为衬 | 环境虚化到只提供色调与氛围 |
| 特写 | 人物 80%+ | 情绪、细节 | 环境消失，靠光和皮肤质感支撑 |

**环境人像的常见失败**：人物太小但环境又没讲清楚任何事 → 变成"一张风景照里有个路人"。修正：要么放大人物，要么给环境更明确的特征（走近一个有文字的招牌、一面有图案的墙）。

**环境人像的机位提示**：为了让环境与人都不畸变，**退远 + 35～50mm** 通常比"近 + 24mm"好（后者会让背景元素被推远、人物被推大，关系失真）。

## 6. 风光与街拍构图

### 6.1 地平线处理

| 地平线位置 | 效果 | 适合 |
|---|---|---|
| 上 1/3 线 | 强调前景/地面 | 有强前景的风景、倒影、花海、星空（地面为主） |
| 下 1/3 线 | 强调天空 | 云层剧烈、日落、戏剧性天空、空旷 |
| 正中央 | 静止、对称、压抑或极简 | 水面倒影、极简、要"分割感"时 |
| 倾斜 | 动感/失衡 | 极少见于风光（会被读成失误），除非刻意的速度感 |

**铁律**：风光片的地平线**必须水平**（除非是刻意的倾斜）。歪 1° 在 24MP 屏幕上肉眼可辨。带电子水平仪（多数相机的水平仪精度 ±1°）、或后期用"旋转 + 裁切"校正。

**地平线不要穿过关键位置**：不要正好从人的脖子/眼睛穿过，不要正好切在头部。

### 6.2 前景运用

风光片的"高级感"大半来自前景。没有前景的风光 = 明信片式的平铺。

| 前景类型 | 作用 | 注意 |
|---|---|---|
| 花/草/石/枝（贴地） | 制造纵深 + 视觉入口 | 用超低机位（贴近地面 10～30cm），广角 16～24mm |
| 水面/倒影 | 对称感 + 延展 | 需要无风或极慢门（1/2s 以上）让水面平滑 |
| 岩石/冰/沙纹 | 质感 + 重量 | 侧光强调纹理 |
| 人工物（铁丝网、窗框、栏杆） | 框架 + 叙事线索 | 虚化/压暗 |
| 人物（背对镜头的人） | 尺度感 + 代入感 | 人占画面 5%～15%，放在引导线上 |

**前景的三条量化要求**：①虚化或压暗到不抢主体（比主体低 0.5～1.5 档）②占画面不超 1/3（除非它就是主体）③有明确形状或质感，不是一团模糊。

### 6.3 天气与光线的配合

| 天气 | 特点 | 适合拍 | 应对 |
|---|---|---|---|
| 晴天顺光 | 色彩饱和、平淡 | 记录、明信片、色彩鲜明的题材 | 加前景、找阴影做层次、换角度 |
| 晴天侧光（黄金时段） | 立体、有质感、色温暖 | **风光最佳** | 日出后/日落前 40 分钟，低角度光拉长影子 |
| 晴天逆光 | 通透、剪影、光斑、大气 | 剪影、透光叶、晨雾、水面反光 | 降曝光补偿 -1～-2EV，遮光罩防眩光，或刻意加眩光 |
| 阴天 | 柔、无影、无质感、平 | 人像（天然柔光箱）、森林细节、花 | 减少天空占比、靠构图与色彩撑、后期加清晰度 |
| 雨天/雨后 | 湿润质感、倒影、氛围 | 街拍、城市夜景、灯光倒影 | 保护器材；用倒影做主体；低饱和 + 高对比调色 |
| 雾/霾 | 空气透视极强、层次分明 | 多层山、林、氛围风光 | 用长焦压缩层叠；冷调；曝光可 +0.3～+0.7 |
| 雪 | 高反射、易欠曝 | 高调片 | 曝光补偿 +1～+2EV（白雪要拍成白）；冷暖对比 |
| 大风/暴雨 | 动态云、雨丝 | 长曝光云、雨帘 | 三脚架、防水；1s～30s 长曝让云成"流线" |

### 6.4 街拍的"决定性瞬间"

核心不是运气，是**预判 + 埋伏**：

1. **先找背景/光，再等人**（反向操作）。看到一个好背景（一束光、一个好墙面、一段好倒影），就站在那里等合适的人走进来。
2. **预构图**：按你希望画面成立的方式先把相机架好（含对焦、曝光），人一进画面就按。
3. **预判**：看到远处有人走来，判断他 3～5 秒后会在哪，把焦点区域/取景框放在那。
4. **连拍 + 小步幅移动**：人物走过去的过程拍 3～5 张，选姿态最好的一张。
5. **主体与背景的关系**：街拍的高级感来自"人 + 环境"的巧合（广告牌上的人 + 真实的人、影子 + 本体）。

**参数建议**：光圈 f/5.6～f/8（保证有合理景深且背景可辨），快门 1/250s 以上（凝固行人），ISO 自动（上限设 3200～6400），对焦用区域/连续 AF。

### 6.5 抓拍构图

| 抓拍场景 | 构图要点 |
|---|---|
| 行走的人 | 前方留白、地平线水平、把移动的人放在三分线上、用连拍选脚离地的一帧 |
| 交谈的两人 | 一正一侧，两人视线连线穿过画面，避免中间有柱子/杆 |
| 街头小贩/工匠 | 手的动作是重点，构图上给手留出空间；低机位或与手平齐 |
| 儿童 | 蹲下到儿童眼平（不要俯拍），抓动作瞬间，快门 > 1/500s |
| 反射/影子类 | 用玻璃、水洼、影子做"第二主体"，构图让反射与实体呼应或反转 |
| 剪影 | 找亮背景（天空、水面），主体曝光降 -2EV，构图上剪影要有清晰可辨的轮廓 |

**街拍构图的取舍**：抓拍时"清晰、有内容、有故事"优先于"完美构图"。**能事后裁的不在现场纠结。**

## 7. 后期二次构图

### 7.1 什么时候该裁

**该裁的情形**：
1. 画面里有明确的干扰物在边缘（半个路人、亮点、杂物）。
2. 地平线歪了需要旋转 → 旋转后必然要裁掉四个角。
3. 主体太小、周围留白无意义 → 裁紧。
4. 原画幅比例不合适（3:2 拍的内容更适合 4:5 或 1:1）。
5. 拍的时候宽容留了余地，现在要收紧。

**不该裁的情形**：
1. 只为了"更接近三分法"而裁（构图感不该靠裁补救）。
2. 裁完分辨率不够目标用途（见 7.3）。
3. 裁掉的部分里有重要的环境信息（人物比例、地标）。
4. 裁完主体离边缘过近（< 画面 8%），显得局促。

### 7.2 裁多少

| 裁切幅度 | 说明 | 画质影响 |
|---|---|---|
| ≤ 10% | 微调边缘、去杂物 | 无感 |
| 10%～25% | 常规二次构图 | 轻微，正常打印/发布无感 |
| 25%～50% | 明显重构（改比例、裁掉大量环境） | 有效像素降到 50%～75%，大尺寸输出会显现 |
| > 50% | 相当于换了一张照片 | 像素严重不足，仅在网络小图可用 |

**经验法则**：**如果打算做 50% 以上的裁切，说明当时就没拍对。** 回看去现场重拍，或换构图思路。

### 7.3 裁切与像素/画质的关系

- 裁切是**纯粹的像素损失**：裁掉一半面积 = 剩一半像素。2400 万像素裁到 50% → 1200 万。
- 目标用途决定能裁多少：

| 用途 | 需要像素（长边/总像素） | 可裁空间（从 24MP 起） |
|---|---|---|
| 微信/微博/小红书 | 长边 1080～2048 | 极大，裁到 1/4 也无妨 |
| 网页/邮件 | 长边 1200～1600 | 很大 |
| A4 打印（300dpi） | 2480 × 3508 ≈ 8.7MP | 可裁到 ~1/3 |
| A3 打印 | 3508 × 4961 ≈ 17.4MP | 可裁 ~1/4 |
| 大幅面海报/展陈 | 更长边 | 几乎不可裁，需重拍或用 AI 放大 |

- **裁切后先放大检查**：在 100% 视图看是否有噪点放大、锐度不足、色阶断层。发现就减少裁切量或降输出尺寸。
- **裁完必须重做锐化**：裁切后像素尺寸变了，原锐化参数不再适用（见 post-color.md 第 8 节）。

### 7.4 长宽比的选择（后期）

| 比例 | 什么时候改 | 常用场景 |
|---|---|---|
| 保持原生 3:2 | 默认，改动最小 | 通用、新闻、客户要求原图 |
| 改 4:5 竖 | 人像、社交平台竖图（占屏面积更大） | 人像、写真、Instagram |
| 改 1:1 | 主体适合方画幅、需要"安定感"、静物 | 头像、静物、极简 |
| 改 16:9 | 去上下多余空间、故事感、封面 | 风光、横幅、视频封面 |
| 改 5:4 / 4:3 | 主体略偏"方"、打印标准尺寸 | 肖像、打印装框 |

**改比例的原则**：**先决定主体周围要保留多少空间，再选比例**——而不是先选比例再硬塞。改比例时用一个**固定比例的裁切框**（LR/PS 里锁定比例），避免手感随意。

## 8. 构图诊断表

症状 → 原因 → 修正。

| # | 症状 | 原因 | 修正 |
|---|---|---|---|
| 1 | 画面散、不知道看哪 | 多个视觉中心竞争 | 明确唯一主体 + 压暗/虚化/裁掉次要元素 |
| 2 | 主体"糊"在背景里 | 主体与背景的明暗/色彩/清晰度没有分离 | 让主体最亮或最暗 + 加大对比 + 大光圈虚化或长焦压缩 |
| 3 | 人物像"罚站"、僵硬 | 无重心腿、无腰线、身体与画框平行 | 让一条腿受力、转肩胯形成角度、身体与画框成 30° 以上 |
| 4 | 人物头顶"长"了树/灯/杆 | 机位与背景的巧合重叠 | 左右挪半步或降低/升高机位，让头顶上方干净 |
| 5 | 画面看起来"歪" | 地平线或垂直线不水平 | 相机水平仪 + 后期旋转校正 + 裁切 |
| 6 | 主体朝向侧被"堵住" | 视线/运动方向的前方没有留白 | 在朝向侧增大留白，背向侧收紧，比例约 2:1～3:1 |
| 7 | 主体看起来很小很可怜 | 主体占比低且环境无信息 | 走近/换长焦放大，或让环境承担明确叙事 |
| 8 | 前景一团糊、没有意义 | 前景太虚太暗看不出形状 | 收小光圈让前景有形状，或换有质感的前景元素 |
| 9 | 照片"平"、没有纵深 | 缺少前景/层次/透视 | 加前景 + 找汇聚线 + 利用空气透视 + 大小对比 |
| 10 | 背景有一块很亮的斑 | 高光干扰物（白墙/车窗/反光） | 换角度避开 + 后期压高光 + 降低该区域亮度 |
| 11 | 边角有个抢眼的小色块 | 画面边缘未做减法 | 裁掉或后期降低饱和/压暗 |
| 12 | 裁切处让人觉得"断了" | 切在关节、下巴、头顶、脚踝 | 改切在关节之间的中段，或放宽到完整包含 |
| 13 | 两人并排像证件照 | 平行并立、无高度差、无互动 | 前后错位 + 高度差 + 朝向差 + 距离靠近 |
| 14 | 合影边缘的人被切一半 | 取景时没考虑群体宽度 | 退后拍 + 后期微调；或分成两排 |
| 15 | 对称建筑照片看着"别扭" | 对称不彻底或相机未保持水平 | 站在中轴线上、用水平仪、后期做透视校正 |
| 16 | 引导线指向了画面外 | 线的方向与主体不一致 | 换机位让线指向主体，或裁掉线的错误走向部分 |
| 17 | 画面上下都空 | 主体居中且上下留白等量 | 收紧一端的留白（上多下少或反之） |
| 18 | 倾斜了但看起来像失误 | 倾斜幅度处在"事故区"（1°～5°） | 要么彻底水平，要么倾斜 > 8° 明确成风格 |
| 19 | 风景平淡、像明信片 | 无前景、地平线居中、顺光 | 加前景 + 地平线移三分线 + 换黄金时段/侧光 |
| 20 | 街拍画面杂乱无主题 | 元素太多且无关系 | 找"人 + 环境"的对应关系，等一个干净的瞬间，或用长焦压缩隔离 |
| 21 | 主体被前景挡了一小块 | 前景位置刚好挡脸/挡关键部位 | 挪半步让前景移出主体区域，前景只压边缘 |
| 22 | 照片显得"闷" | 暗部过多、中间调偏暗、缺乏通透感 | 提亮中间调、加一点空气感/降黑、让高光有细节 |
| 23 | 视线被角落的高对比引出画面 | 四角有高对比元素 | 压暗四角（暗角）+ 降饱和 + 裁掉 |
| 24 | 构图很"标准"但没记忆点 | 机械套用三分法 | 换结构：极简、满构图、极端机位、强对比、非对称失衡 |
| 25 | 特写里脸显长显大 | 距离太近 + 机位过低 + 焦段太广 | 退远 + 85～135mm + 机位略高于眼平 10°～15° |

## 9. 大师观看方式

从观念摄影与经典作品、以及多位摄影家的观看经验中提炼的"怎么看"原则，用来提升审美判断。

### 9.1 先问"这张照片在说什么"，再问"怎么拍的"

看懂一张作品，先找它的**意图**：它在表达什么情绪、什么关系、什么观察？技术是手段不是目的。**一张技术上完美但无意图的照片，不如一张技术上粗糙但有话可说的照片。**

### 9.2 看"框"的选择，而不是框里的东西

经典作品的功力常常体现在**摄影师决定了把什么排除在外**。看一张好照片时，问：他为什么在这里切？为什么不要那边？如果把画框往外扩 20%，画面会变成什么样？

### 9.3 看时空关系：这个瞬间为什么是"这一刻"

好照片往往站在一个**转瞬即逝的时间点上**（做出动作的前一刻、表情变化的中点、光线最恰好的三十秒）。判断一张作品的时机价值：换一个瞬间它还剩多少？

### 9.4 看"决定性瞬间"之外：也有"平淡的凝视"

不是所有好照片都依赖瞬间。有的作品靠的是**长时间的凝视**（一堵墙、一片海、一张静止的脸），它的力量来自氛围与耐心。不要以为只有抓拍才高级。

### 9.5 看光，尤其是"不漂亮的光"

新手只看"漂亮的光"（夕阳、柔光）。看大师作品要特别注意他们怎么用难看的光（正午硬光、混合光、阴天的灰、闪光灯的直射），把它变成**内容的一部分**。

### 9.6 看主体与背景的关系是不是"有意义的巧合"

好照片里，主体与背景常常互相解释：背景的字与人、背景的画与真的人、背景的形状与人的姿态。**这种关系感是"摄影眼"的核心。** 练习方法：盯着一个背景看，问自己"什么样的人走进来会让这张照片成立"。

### 9.7 看"反构图"的作品，理解规则是可被打破的

很多经典作品刻意把主体放在正中央、刻意歪斜、刻意失衡、刻意过曝或欠曝。理解它们**为什么在打破规则时反而更强**，是判断力成熟的标志。**规则的用途是让你知道你在打破什么。**

### 9.8 看组照与序列，而非单张

单张好看是技术，一组照片成立才是表达。看一位摄影师的作品集时，看他的**重复主题、色调一致性、节奏（强片与弱片的分配）**，这比看单张更能理解他的观看方式。

### 9.9 看"减法做到了什么程度"

把一张好照片的元素列出来，通常会发现**元素少得惊人**。看完之后问自己：我拍同一个场景时，会往里加多少不必要的东西？

### 9.10 用"翻拍自己"的方式练习看

每隔一段时间回看自己半年前的照片，标出：哪些构图我当时觉得好现在觉得差？变化的是技术还是眼光？**审美判断的提升几乎总是先于技术提升**——先看出不好，才拍得更好。
