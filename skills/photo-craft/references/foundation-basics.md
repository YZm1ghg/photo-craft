## 0. 摄影的三条基本功

### 0.1 好照片三原则

摄影基础教材普遍以三条纲领开篇，一张好照片应当满足三条，缺一不可：

| 原则 | 含义 | 反面例子 |
|---|---|---|
| **鲜明的主题** | 每张照片都要能回答"这张照片想说什么" | 拍了一堆"感觉不错"但说不清拍了什么 |
| **主体突出** | 观众的视线必须被引到主体上 | 主体藏在画面角落，或与背景混淆 |
| **画面简洁** | 与主题无关的元素一律排除 | 背景有垃圾桶、路人、电线杆 |

**为什么这三条是"基本功"而不是"技巧"**：技术（曝光、对焦）只决定照片"能不能看"，这三条决定照片"值不值得看"。绝大多数新手照片的问题不在技术，在于拍之前没想清楚"我在拍什么"。

**实战检验法**：拍完一张，问自己三个问题 —— ① 这张想表达什么？② 第一眼看的是什么？③ 有没有多余的东西？三问都过，这张照片基本成立。

### 0.2 曝光 / 对焦 / 构图的优先级

| 优先级 | 项目 | 不可挽回程度 | 原因 |
|---|---|---|---|
| 1 | **对焦** | 最不可挽回 | 焦没对上，后期几乎无法救（轻微跑焦可锐化，严重脱焦无解） |
| 2 | **曝光** | 中度可挽回 | 欠曝可拉回 2~3 档（RAW），过曝高光一旦溢出就是纯白，无解 |
| 3 | **构图** | 最可挽回 | 可以裁剪，可以旋转，可以后期补救 |

**所以现场的执行顺序是**：先保证对焦，再保证曝光不溢出，最后再纠结构图。

**但注意**：这个优先级是"现场抢救顺序"，不是"学习顺序"。学习摄影应该反过来 —— 先学观察和构图（决定有没有好照片），再学曝光（决定照片能不能看），最后熟练对焦（变成肌肉记忆）。

### 0.3 从"自动"走向"手动"的意义

- 自动模式解决的是"平均情况"，而摄影的乐趣恰在"非平均情况"（逆光、暗场、高速运动）。
- 手动不是目的，**"知道机器在做什么"** 才是目的。有些场景用 A 档（光圈优先）比 M 档更快更稳（如抓拍），前提是你知道 A 档在做什么。
- 判断标准：能预测"如果我这样调，照片会变成什么样" —— 那就算入门了。

## 1. 曝光三要素

### 1.1 光圈 / 快门 / ISO 的作用与副作用

| 要素 | 作用 | 增加时的副作用 | 减少时的副作用 |
|---|---|---|---|
| **光圈（f 值）** | 控制进光量 + 景深 | f 值变大（如 f/16）= 进光少、景深大、画质受衍射影响 | f 值变小（如 f/1.4）= 进光多、景深浅、边缘画质下降、可能有暗角 |
| **快门（s）** | 控制曝光时间 + 凝固/拖影 | 时间变长（如 1/15）= 进光多，易手抖模糊、运动物体拖影 | 时间变短（如 1/2000）= 进光少，可能欠曝 |
| **ISO** | 控制传感器放大倍数 | ISO 升高 = 画面变亮，但噪点、动态范围下降、色彩变脏 | ISO 降低 = 画面干净，但需要更多光 |

**关键理解**：
- 光圈和快门是"物理进光量"，ISO 是"信号放大"。**能用光解决的，不要用 ISO 解决。**
- 光圈还有一个"副作用"：f 值越小，景深越浅。"景深浅"在人像里是优点，在风光里是缺点。
- 快门还有一个"副作用"：快门越快，需要的光越多，闪光同步也有限制（普通同步 1/200~1/250s）。

**光圈档位（标准整档，进光量减半）**：
`f/1.4 → f/2 → f/2.8 → f/4 → f/5.6 → f/8 → f/11 → f/16 → f/22`

**快门档位（整档）**：
`1s → 1/2 → 1/4 → 1/8 → 1/15 → 1/30 → 1/60 → 1/125 → 1/250 → 1/500 → 1/1000 → 1/2000`

**ISO 档位（整档）**：`100 → 200 → 400 → 800 → 1600 → 3200 → 6400 → 12800 → 25600`

### 1.2 曝光三角与等效曝光

**核心规律：三个要素中，任意一个增加 1 档，必须有另一个减少 1 档，总曝光量才不变。** 这就是"等效曝光"。

| 组合 | 光圈 | 快门 | ISO | 画面亮度 | 画面效果差异 |
|---|---|---|---|---|---|
| A | f/2.8 | 1/500 | 100 | 相同 | 浅景深、凝固动作、画面干净 |
| B | f/5.6 | 1/125 | 100 | 相同 | 中等景深 |
| C | f/8 | 1/60 | 100 | 相同 | 大景深、易手抖 |
| D | f/8 | 1/250 | 400 | 相同 | 大景深 + 快门的凝固 + 轻微噪点 |

**为什么这个表重要**：它告诉你"没有唯一正确的曝光组合"。同一个亮度可以有无数组合，**你要选的是"效果"，不是"亮度"**。
- 想要虚化背景 → 优先调小 f 值
- 想要凝固运动 → 优先调快快门
- 想要大景深 → 优先调大 f 值
- 光不够又想保住前两者 → 才动 ISO

### 1.3 直方图判读

直方图横轴是亮度（左暗右亮），纵轴是像素数量。

| 形态 | 含义 | 处理 |
|---|---|---|
| 山峰集中在左侧，右侧大量空白 | 欠曝 | 加曝光补偿 / 提高 ISO / 开大光圈 |
| 山峰集中在右侧，贴住右边界 | 可能过曝 | 检查是否有高光溢出（右端堆积被切断） |
| 山峰顶到右边界并"堆积成墙" | 高光溢出（死白） | 减曝光；若无法减，考虑包围曝光 |
| 山峰顶到左边界并堆积 | 暗部溢出（死黑） | 通常可接受（暗部可拉回），但注意噪点 |
| 山峰分布均匀、两端不堆积 | 曝光健康 | 保持 |
| 只有中间一根细高峰 | 低对比度（发灰、雾霾） | 加对比度 / 后期调整曲线 |

**关键判断**：**看右端，不看中间。** 右端有堆积（被切掉）就是高光溢出，不可挽回；右端留一点空隙最安全。

### 1.4 宁欠勿过 vs 宁过勿欠

| 策略 | 适用 | 原因 |
|---|---|---|
| **宁欠勿过**（稍微欠曝） | 数码相机、高光重要的场景（婚礼白纱、雪景、天空、白墙） | 数码传感器的高光一旦溢出就是纯白，无任何信息；暗部提亮有噪点但信息还在 |
| **宁过勿欠**（稍微过曝） | 暗部细节重要、噪点敏感的场景（暗场人像、夜晚城市、深色物体） | 提亮暗部会放大噪点与暗部色偏；适度过曝让暗部信息落在传感器高信噪比区 |

**实践建议**：用 RAW 拍摄时，采用"**向右曝光**（Expose To The Right, ETTR）"—— 在不溢出的前提下尽量让直方图靠右，后期拉回来。这样能获得最佳信噪比与动态范围。**前提是：必须能实时看直方图，且拍 RAW。**

## 2. 测光与曝光模式

### 2.1 三种测光模式

| 模式 | 测光区域 | 适用 | 注意 |
|---|---|---|---|
| **评价测光 / 矩阵测光** | 全画面分区计算（各家算法不同） | 光比均匀的场景、日常、风光 | 逆光、大面积白/黑背景时会算错 |
| **中央重点测光** | 画面中央圆形区域为主（约占 60%~80% 权重） | 主体居中的人像、环境肖像 | 主体偏离中央时失准 |
| **点测光** | 极小区域（约为画面 1.5%~3.5%） | 逆光、舞台、强烈明暗对比、精确控制 | 测错点就全错；必须知道"测的是哪" |

**点测光的实战用法**：
| 场景 | 测哪里 | 结果 |
|---|---|---|
| 逆光人像 | 测人脸（皮肤高光区） | 人脸正确，背景过曝（氛围感） |
| 舞台追光 | 测被照亮的演员脸部 | 主体正确，其余压暗 |
| 雪景 | 测雪 + 加 1~2 档曝光补偿 | 雪是白的，不是灰的 |
| 剪影 | 测背景亮部 | 主体变纯黑剪影 |
| 月亮 | 测月亮本体 | 月亮有细节，不是一团白 |

### 2.2 各曝光模式何时用

| 模式 | 含义 | 最适合 | 不适合 |
|---|---|---|---|
| **M（手动）** | 光圈快门全手动 | 影棚闪光、全景拼接、延时、固定光线下的连拍、需要严格一致性 | 光线剧烈变化的抓拍 |
| **A / Av（光圈优先）** | 你定光圈，机器算快门 | **人像、风光、街拍、绝大多数场景**（推荐新手主力模式） | 需要固定快门的运动摄影 |
| **S / Tv（快门优先）** | 你定快门，机器算光圈 | 运动、鸟类、流水（长曝）、追焦摇拍 | 需要固定景深的人像 |
| **P（程序自动）** | 机器选取参数组合，可偏移 | 快速抓拍、不熟悉场景时的应急 | 需要精确控制景深/运动 |
| **自动 / 场景模式** | 全自动 | 手机化拍摄、纯记录 | 任何需要表达的场景 |

**推荐工作流**：A 档做主力（定光圈定景深，快门交给机器）→ 光比复杂或需要固定曝光时切 M 档 → 运动场景切 S 档。

### 2.3 曝光补偿

**曝光补偿（±EV）只在自动/半自动模式下有效**（M 档时改的是参数本身，不是补偿）。

**白加黑减原则**：

| 场景 | 测光表会怎么想 | 应该怎么做 |
|---|---|---|
| 白雪、白墙、白婚纱（大面积白） | 测光表以为"太亮了"，自动压暗 → 拍成灰 | **加曝光（+1~+2EV）**，让白是白 |
| 黑色背景、黑西装、夜景（大面积黑） | 测光表以为"太暗了"，自动提亮 → 拍成灰 | **减曝光（-1~-2EV）**，让黑是黑 |

**为什么**：测光表的目标是把所有场景都拍成"18% 中灰"。它不知道你拍的是雪还是煤，只能假定是灰的。

**常见场景曝光补偿速查表**：

| 场景 | 补偿 | 原因 |
|---|---|---|
| 雪景/沙滩 | +1 ~ +2 EV | 大面积高反射 |
| 逆光人像（不用闪光） | +0.7 ~ +1.7 EV | 主体背光，机器被背景骗 |
| 舞台追光/聚光灯下的主体 | -0.7 ~ -1.3 EV | 保留高光层次 |
| 日落/晚霞 | -0.3 ~ -1 EV | 加深色彩、保留高光（让霞更红） |
| 夜景灯光 | -1 ~ -2 EV | 保留灯光的光点与色彩，避免一片死白 |
| 大面积绿地/树林 | +0.3 ~ +0.7 EV | 绿色反射率低于中灰 |
| 黑色物体（黑猫、黑车） | -0.7 ~ -1.3 EV | 让它保持黑，不要拍成灰 |
| 白色物体为主的主体 | +0.7 ~ +1.3 EV | 让它保持白 |
| 室内窗户逆光（拍人） | +1 ~ +2 EV 或改用闪光 | 光比过大 |
| 婚礼白纱 + 白墙 | +0.7 ~ +1.3 EV | 白上加白 |

## 3. 对焦

### 3.1 对焦模式

| 模式 | 名称 | 行为 | 适用 |
|---|---|---|---|
| **AF-S / One Shot** | 单次对焦 | 半按快门锁定焦点，合焦后停止 | 静止主体、风光、静物、摆拍人像 |
| **AF-C / AI Servo** | 连续对焦 | 持续追踪移动主体 | 运动、儿童、宠物、婚礼走动、鸟类 |
| **AF-A / AI Focus** | 自动切换 | 机器判断静止/移动并切换 | 不可靠，**不建议使用**（判断失误率高） |
| **MF** | 手动对焦 | 全手动 | 微距、星空、隔着玻璃/栅栏、弱光下 AF 失效时 |

**推荐**：人像/静物用 AF-S；运动/儿童/婚礼用 AF-C；**永远不要用 AF-A**。

### 3.2 单点 vs 区域对焦

| 方式 | 说明 | 适用 |
|---|---|---|
| **单点（Single Point）** | 精确指定一个对焦点 | 人像（对眼睛）、静物、需要精确控制焦点的场景 |
| **小区域 / 扩展点** | 一个主点 + 周围辅助点 | 运动中的主体（主体稍微偏离仍能跟上） |
| **大区域 / 全区自动** | 相机自己选对焦点 | 应急抓拍；但会"对到最近的物体"（如前景） |
| **眼部对焦（Eye AF）** | 自动识别并锁定眼睛 | **人像的最佳选择**，现代相机的必备功能 |

**为什么单点 + 眼部对焦是人像首选**：人像的焦点必须在眼睛（离镜头近的那只）。区域自动对焦可能对到鼻尖、衣领、背景高对比处。

### 3.3 对焦锁定（Focus Lock / AF-L）

**用法**：中心对焦点对准主体 → 半按快门（或按 AF-L 键）锁定 → 平移取景构图 → 全按快门。

**适用**：主体不在画面中央、机身对焦点不足、想要"先对焦后构图"。

**注意**：焦点锁定后如果**前后移动**（改变物距），焦点会失效。锁定后只能"左右平移"，不能"前后靠近"。

### 3.4 跑焦的原因与排查

| 症状 | 可能原因 | 排查/修正 |
|---|---|---|
| 全部照片都往一个方向偏（都前移或都后移） | 镜头与机身 AF 校准偏差 | 用机身"AF 微调（AF Fine Tune）"，或送修校准；用对焦测试卡验证 |
| 部分照片准部分不准 | 用了 AF-A、或对焦点选错、或主体遮挡 | 改 AF-S/AF-C；改单点；确认对焦点落在主体上 |
| 近距离准、远处不准 | 景深太浅 + 手抖、或镜头本身球差 | 缩光圈；上三脚架；测试镜头在不同距离的表现 |
| 大光圈全开时对不准，缩光圈后就准 | 镜头大光圈下球面像差/焦点漂移 | 缩 1~2 档使用；了解该镜头的"工作光圈" |
| 弱光下反复拉风箱 | 反差不足，相位/对比检测失效 | 用中心十字对焦点；加对焦辅助灯；改手动对焦 |
| 隔着玻璃/水面拍不准 | 反光干扰 AF | 改手动对焦，或用相机贴紧玻璃消反光 |

### 3.5 景深与超焦距

**景深（Depth of Field）的决定因素**：
| 因素 | 影响 |
|---|---|
| 光圈 | f 值越小，景深越浅（最主要因素） |
| 焦距 | 焦距越长，景深越浅 |
| 物距 | 离得越近，景深越浅 |
| 传感器尺寸 | 画幅越大，同视角同光圈下景深越浅 |
| 输出尺寸/观看距离 | 放大越多、看得越近，越容易看出"不锐" |

**超焦距（Hyperfocal Distance）**：对焦在超焦距点上时，从"超焦距的一半"到无穷远都在景深内。这是**风光摄影获得最大景深的经典手段**。

| 实用口诀 | 说明 |
|---|---|
| 风光常用 f/8~f/16 | f/8 通常是多数镜头最佳画质光圈 |
| 不要超过 f/16（APS-C）/ f/16（全画幅） | 超过后衍射导致整体变软 |
| 对焦点放在画面前 1/3 处 | 经验法则，比用超焦距表更省事，效果接近 |
| 前景极近时 | 改对焦点到前景，或使用焦点堆栈 |

### 3.6 风光对焦策略

| 场景 | 对焦位置 | 光圈 |
|---|---|---|
| 前景 + 远景（大景深） | 画面前 1/3 处，或超焦距 | f/8~f/11 |
| 有极近前景（石头、花） | 前景主体，或焦点堆栈（2~5 张） | f/11~f/16 + 堆栈 |
| 单主体风光（一棵树） | 主体本身 | f/5.6~f/8 |
| 星空 | 手动对焦到无穷远（用实时取景放大到最亮的星对焦） | f/2.8 最大光圈 |
| 水面倒影 | 中景（不是最近的前景） | f/11 |
| 雾气/云雾 | 中景（雾里没有"锐"的概念） | f/8 |

### 3.7 弱光对焦

| 方法 | 说明 |
|---|---|
| 找高对比边缘 | AF 需要反差，对在"亮暗交界"比对在"纯色面"更快（如对在衣服边缘而非脸部中央） |
| 用中心对焦点 | 中心点通常是最灵敏的十字型对焦点 |
| 开启对焦辅助灯 | 内闪/LED 打出一束光辅助合焦（会引人注目，慎用） |
| 用屏幕实时取景 + 放大 | 手动对焦时最可靠，适合夜景与星空 |
| 预先对焦（陷阱对焦） | 先把焦点对在"主体将要经过的位置"，等主体进入再按快门 |
| 用手电/手机照亮对焦处 | 对焦完成后关掉再拍 |
| 对焦无穷远拍夜景 | 城市夜景、烟花、星轨都可以"直接对无穷远" |

## 4. 相机与镜头常识

### 4.1 画幅对视角与景深的影响

| 画幅 | 尺寸（约） | 等效系数 | 特点 |
|---|---|---|---|
| 中画幅 | 44×33mm（或更大） | 0.79 | 画质、动态范围极佳；贵、重、慢 |
| 全画幅（135） | 36×24mm | 1.0 | 画质与体积的平衡点；镜头群成熟；高感好 |
| APS-C | 23.5×15.6mm（尼康/索尼）/ 22.3×14.9（佳能） | 1.5 / 1.6 | 轻便便宜；长焦"更远"；广角更难做；景深更深 |
| M43 | 17.3×13mm | 2.0 | 更轻便；景更深；高感弱 |
| 1 英寸 | 13.2×8.8mm | 2.7 | 卡片机/无人机；画质有限 |

**两个关键结论**：
1. **视角**：同一焦距在不同画幅上视角不同。APS-C 上 50mm 的视角约等于全画幅 75mm。所以"APS-C 拍人像用 35mm"（等效 52mm），"APS-C 拍风光用 10-18mm"（等效 15-27mm）。
2. **景深**：同视角、同光圈下，全画幅景深更浅（虚化更强）。这就是"全画幅虚化好"的物理原因，不是因为全画幅"高级"。

### 4.2 等效焦距换算

**换算公式**：等效焦距 = 实际焦距 × 等效系数

| 想获得的视角（等效 135） | 全画幅镜头 | APS-C（×1.5）需用 |
|---|---|---|
| 超广角 16mm | 16mm | 10~11mm |
| 广角 24mm | 24mm | 16mm |
| 标准 35mm | 35mm | 23mm |
| 标准 50mm | 50mm | 33~35mm |
| 人像 85mm | 85mm | 55~56mm |
| 长焦 135mm | 135mm | 90mm |
| 长焦 200mm | 200mm | 133mm |

**注意**：等效焦距只换算"视角"，不换算"景深"与"透视"。透视只由**拍摄距离**决定，与画幅无关。

### 4.3 镜头分类与选购思路

| 类型 | 特点 | 典型用途 |
|---|---|---|
| **变焦（标准）** | 24-70/2.8、24-105/4 | 通用主力、活动、婚礼 |
| **变焦（长焦）** | 70-200/2.8 | 人像、体育、舞台、动物 |
| **变焦（广角）** | 16-35/2.8、14-24/2.8 | 风光、建筑、室内 |
| **定焦** | 35/1.4、50/1.8、85/1.4 | 大光圈、轻便、画质好、暗光 |
| **微距** | 100mm 微距（1:1） | 花卉、昆虫、产品、首饰 |
| **移轴** | TS-E 24/17/50/90 | 建筑、产品（透视控制） |
| **鱼眼** | 8-15mm | 特殊效果、极限视角 |

**选购思路（按优先级）**：
1. 先确定**你最常拍的题材**，再选焦段，不要先买"便宜的"。
2. 变焦 vs 定焦：变焦解决"拍到"，定焦解决"拍好"。**新手先买一支变焦 + 一支便宜定焦（如 50/1.8）**。
3. 光圈：f/2.8 变焦 vs f/4 变焦的差价很大，先问自己"是否真的需要暗光 + 虚化"。
4. 二手镜头是理性选择，但要检查：镜片有无霉斑/划痕、光圈叶片是否漏油、对焦是否顺滑、卡口磨损、防抖是否工作。
5. **不要迷信"大三元"**：一支 24-70/2.8 的重量是 24-105/4 的 1.5 倍，如果你不带出门，它就没有价值。

### 4.4 光圈叶片与焦外

| 概念 | 说明 |
|---|---|
| 光圈叶片数量 | 叶片越多（7~11 片），光圈形状越接近圆形，焦外光斑越圆润 |
| 圆形光圈 | 现代镜头多采用"圆形光圈"，大光圈时焦外光斑为圆形 |
| 二线性（bokeh 不佳） | 焦外高光边缘生硬（"洋葱圈"感），常见于某些老镜头/廉价镜头 |
| 焦外旋涡（swirly bokeh） | 老式大光圈镜头（如某些 50/1.4）的焦外呈旋转状，是"风格"也是"缺陷" |
| 口径蚀（cat's eye） | 画面边缘的光斑被压成"猫眼"形，正常现象 |

**判断焦外的实战方法**：拍一张"树叶间隙的逆光"或"灯串"，看光斑是否圆润、边缘是否柔和、有无奇怪的环。

### 4.5 机身按键与常用设置

| 设置项 | 建议值 | 原因 |
|---|---|---|
| 拍摄格式 | RAW + JPEG（或纯 RAW） | RAW 保留后期空间 |
| 色彩空间 | sRGB（网络）/ AdobeRGB（印刷） | 不匹配会偏色 |
| 自动对焦模式 | AF-S 或 AF-C（不用 AF-A） | AF-A 判断不可靠 |
| 对焦区域 | 单点或小区域 + 眼部对焦 | 精确控制 |
| 驱动模式 | 单张（静物）/ 低速连拍 3~5fps（人像）/ 高速（运动） | 按题材选 |
| 测光模式 | 评价（默认），逆光/舞台切点测光 | 按场景选 |
| 曝光补偿 | 常挂在 +0.3EV（或按场景调整） | 数码轻微偏暗更安全 |
| 白平衡 | 拍 RAW 时可固定（如 5500K），避免 AWB 乱跳 | 同场景色调一致 |
| 高光警告（斑马纹） | 开启 | 实时发现过曝 |
| 直方图 | 放在回放第一屏 | 按一下就能看 |
| 电子水平仪 | 开启（风光/建筑必备） | 歪地平线极难后期挽救 |
| 网格线 | 开启三分线或九宫格 | 辅助构图 |
| 防抖 | 手持开，三脚架关 | 上架不关会引起微震 |
| 峰值对焦 | 手动对焦时开启 | 提高 MF 成功率 |
| 自定义按钮 | 把常用功能（ISO、AF-L、眼部对焦）绑到快捷键 | 提高现场速度 |

### 5.2 安全快门

**经验公式**：安全快门 ≥ 1 / 等效焦距

| 焦距（等效 135） | 安全快门（无防抖） | 有 4 档防抖时约可到 |
|---|---|---|
| 24mm | 1/30 | 1/4 |
| 50mm | 1/60 | 1/8 |
| 85mm | 1/100（取 1/125 更稳） | 1/15 |
| 135mm | 1/160（取 1/250） | 1/20 |
| 200mm | 1/250 | 1/30 |
| 400mm | 1/500 | 1/60 |

**修正项**（以下情况需要更快的快门）：
- 高像素机身（4000 万以上）→ 快门再快 1 倍
- 手持走拍 → 再快 1~2 倍
- 目标在移动 → 按目标速度决定（走动的成人 ≥ 1/125，跑动 ≥ 1/500，飞鸟 ≥ 1/1000）
- 微距（放大倍率 > 0.5）→ 安全快门要 ×(1 + 放大倍率)

**星空 500 法则**：最长曝光时间（秒）≈ 500 ÷ 等效焦距。例：20mm 全画幅 → 25 秒；APS-C 上用 14mm（等效 21mm）→ 约 24 秒。超过就会出现星点拖线。

## 6. 器材保养与使用

### 6.1 传感器清洁

| 步骤 | 做法 |
|---|---|
| 判断是否需要清 | 光圈缩到 f/16~f/22，对着白墙/天空拍一张，看有无固定的黑斑（固定位置 = 传感器灰尘；随光圈变化 = 镜头灰尘） |
| 日常清洁 | 机身"传感器清洁"菜单（抖掉浮尘）+ 气吹（**不要用嘴吹**） |
| 深度清洁 | 用传感器清洁棒 + 清洁液，单向擦拭，每根棒只用一次；或送专业店 |
| 禁忌 | 不要用棉签、不要用布料反复擦、不要在灰尘多的环境敞开机身换镜头 |
| 换镜头技巧 | 机身卡口朝下、动作快、提前把镜头后盖拧松、避免在风沙/雨中使用变焦镜头的"吸尘泵"效应 |

### 6.2 镜头保养

- **镜片**：先用气吹吹掉沙粒，再用镜头纸/无绒布从中心向外螺旋擦拭，必要时一滴清洁液。
- **镀膜**：绝不用衣服、纸巾干擦（会划伤镀膜）。
- **霉斑**：南方潮湿环境的最大杀手。发现霉斑要立刻送修（霉会"吃"镀膜）。预防靠干燥箱。
- **变焦环/对焦环**：不要用蛮力；进沙后送修，不要自行拆解。
- **UV 镜**：作为"保险镜"使用（磕碰时先碎 UV 而不是主镜片）；廉价 UV 会降低画质，选购多层镀膜的好镜。

### 6.3 防潮

| 环境 | 措施 |
|---|---|
| 南方梅雨季（湿度 80%+） | 电子防潮箱（湿度设定 40%~50%），或密封箱 + 干燥剂（需定期更换） |
| 理想存储湿度 | 40%~50% RH（低于 30% 会让橡胶件与润滑油干裂） |
| 北方干燥冬季 | 注意静电；不要放在暖气旁 |
| 从冷到热（冬天进屋） | 器材会结露，先装在密封袋里等回到室温再取出（约 30~60 分钟） |
| 从空调房到户外（夏天） | 同样会结露，提前 20 分钟把器材拿出适应 |
| 拍摄结束 | 用干布擦掉水汽，取出电池与存储卡，敞开镜头盖晾一晚再收 |

### 6.4 电池与存储卡管理

| 项目 | 做法 |
|---|---|
| 电池 | 充满再出发；带 2~4 块；低温下（0℃ 以下）电量会骤降，放贴身口袋保温 |
| 电池寿命 | 锂电有循环次数（约 300~500 次），衰减后表现为"充满很快就没电" |
| 长期存放 | 电量保持 50%~60% 存放，不要满电也不要空电长期存放 |
| 存储卡 | 每次拍摄前格式化（在相机里格式化，不要用电脑格式化）；不要把卡当长期存储 |
| 卡的速度 | UHS-I（约 90MB/s）够用大多数；4K/连拍/高像素需要 UHS-II（约 250MB/s+） |
| 卡的质量 | 不要买杂牌卡；数据丢失的代价远大于卡的差价 |
| 卡损坏率 | 低价卡 + 频繁读写 + 满卡不换 = 高风险；建议 64~128GB 多张轮换 |
| 读卡 | 用读卡器（不要长期用相机 USB 直连，慢且耗电）；读卡时不要拔卡 |

### 6.5 备份策略（3-2-1）

| 层 | 含义 | 做法 |
|---|---|---|
| **3** | 至少 3 份副本 | 原始卡 + 电脑/硬盘 + 云/异地 |
| **2** | 至少 2 种不同介质 | 硬盘 + 云（或 SSD + 机械硬盘） |
| **1** | 至少 1 份在异地 | 云端、异地硬盘、保险柜 |

**实战流程**：
1. 拍摄时开双卡备份写入（相机支持的话）。
2. 回家立刻导入电脑，**导入完成后才格式化卡**。
3. 导入后立刻同步到一块外置硬盘。
4. 重要商业/婚礼素材，导入当天上传云盘或复制一份到第二块硬盘。
5. 项目交付并确认无误后，才考虑删掉原始卡。

**为什么"导入完成才格式化"**：避免"导入中断 + 卡已格式化 = 素材全丢"。

### 6.6 相机包与出行

| 项目 | 要点 |
|---|---|
| 相机包类型 | 单肩（快速取机、适合街拍）/ 双肩（长途、承重好）/ 腰包（运动）/ 硬箱（航空托运） |
| 出行打包 | 镜头卡口朝上竖放；机身与镜头分开或装好；用隔板固定；电池放随身 |
| 航空 | 锂电池必须随身（不可托运）；机身镜头可托运但要防震；托运箱加"易碎"标签 |
| 防雨 | 相机包配防雨罩；没有就用大号塑料袋应急 |
| 重要拍摄 | 备份机身 + 备份镜头 + 备份电池 + 备份卡，全部随身不托运 |
| 当地电源 | 确认电压与插头（多数相机充电器支持 100-240V） |

## 7. 从入门到精通的训练路径

### 7.1 阶段一：0~3 个月（把机器用法变成本能）

| 项目 | 内容 |
|---|---|
| **目标** | 能在 3 秒内设好"我要的参数"，不再依赖全自动 |
| **必练** | 光圈优先 A 档 + 曝光补偿；三档互易关系；单点对焦 + 对焦锁定；直方图判读 |
| **作业** | ① 同一场景用 f/1.8、f/4、f/8、f/16 各拍一张，比较景深；② 同一天找 20 个"光的方向"（顺/侧/逆/顶/底）各拍一张；③ 拍 100 张"只用一个主体"的照片，练主体突出 |
| **自检标准** | 随手一张照片的曝光正确率 > 70%；能说出"这张照片的光是从哪来的"；能把任何一张照片的直方图读出来 |
| **刻意练习法** | **单一变量练习**：一次只改一个参数，观察变化。改两个以上就分不清是谁的功劳 |

### 7.2 阶段二：3~12 个月（建立观察与方法）

| 项目 | 内容 |
|---|---|
| **目标** | 有明确的个人偏好题材；知道"我想要的画面"并知道怎么实现 |
| **必练** | 构图（三分法、引导线、框架、对称、留白）；测光模式的选择；M 档；闪光灯基础（跳闪） |
| **作业** | ① 每周一个专题（如"只拍影子""只拍蓝色"）；② 模仿 10 位摄影师各拍一组；③ 完成 3 个完整项目（如"我家的一天""一条街的 24 小时"） |
| **自检标准** | 交出一组 10 张照片，主题一致、风格统一、无明显技术缺陷；能对每张照片说出"为什么这样拍" |
| **刻意练习法** | **限制练习**：只带一支定焦、只用一种光、只拍一个主题。限制会逼出创造力 |

### 7.3 阶段三：1~3 年（从"能拍"到"能交付"）

| 项目 | 内容 |
|---|---|
| **目标** | 能完成一个完整的商业/委托项目；形成个人风格；能被别人认出"这是你拍的" |
| **必练** | 布光（多灯、光比控制）；色彩管理（色卡、显示器校准）；后期工作流；项目排期与客户沟通 |
| **作业** | ① 完整跟拍一场活动或婚礼；② 做一组 20 张的"个人项目"并输出成册/展览；③ 接 3 单真实委托（可以有偿或无偿）并完成交付 |
| **自检标准** | 交付的成片率 > 60%（不是靠"拍 5000 张挑 10 张"）；客户复购或转介绍；作品能被同行看出"有个人语言" |
| **刻意练习法** | **复盘法**：每次拍摄后写下"哪三张最好、为什么；哪三张最差、为什么"。持续一年，进步速度会明显超过"多拍不思考" |

### 7.4 通用训练原则

| 原则 | 说明 |
|---|---|
| 单一变量 | 一次只改一个参数，才知道是什么在起作用 |
| 限量拍摄 | 每天只准拍 10 张（"数码时代最贵的成本是挑片"），逼你在按快门前思考 |
| 定期删除 | 拍完立刻删掉明显废片，不让烂片堆积成心理负担 |
| 输出倒逼 | 定期打印/发布一组照片，逼自己面对"这张到底行不行" |
| 看原作 | 看画册、看展览、看印刷品，而不是只看手机屏幕上的图 |
| 复盘记录 | 建立"错题本"，记录每次失败的原因与修正 —— 这是进步最快的方式 |

## 8. 新手常见错误诊断表

| 症状 | 原因 | 修正 |
|---|---|---|
| 照片发灰、不通透 | 曝光不足 + 对比度低（顺光拍雾霾/阴天，或镜头脏） | 曝光补偿 +0.3~+0.7EV；后期加对比；避免在雾霾天顺光拍；擦镜头 |
| 天空一片死白、没层次 | 天空与地面光比过大，对地面曝光导致天空过曝 | 用 GND 渐变镜；或用包围曝光后期合成；或干脆等更好的光线 |
| 人脸是黑的（逆光） | 对背景测光 | 对脸部点测光 + 曝光补偿；或用闪光灯/反光板补面 |
| 背景有路人/垃圾桶/电线杆 | 未检查画面边缘 | 换角度、走近拍、用长焦压缩、后期修补；养成"按快门前扫一遍四角"的习惯 |
| 地平线是歪的 | 未开水平仪 | 开启电子水平仪；后期旋转校正（会裁掉边角） |
| 照片糊（不知道是哪种糊） | 快门太慢（手抖）、跑焦、或主体移动 | 检查：整体糊 = 手抖（加快门/开防抖/上架）；局部糊 = 景深不够；主体糊但背景清楚 = 对焦在对的地方但主体动了 |
| 主体清楚但"不锐" | 光圈开太大、镜头素质、高 ISO 降噪涂抹 | 收 1~2 档光圈；用镜头最佳光圈（通常 f/5.6~f/8）；降 ISO |
| 照片噪点很多 | ISO 过高、欠曝后提亮 | 加光（补光/开大光圈/降快门）；拍 RAW 并向右曝光；后期适度降噪 |
| 人像背景虚化不够 | 光圈不够大、物距太远、焦距太短 | 开大光圈；靠近主体；换长焦；拉大主体与背景的距离 |
| 人像拍得脸大、鼻大 | 用广角近距离拍人 | 改 50mm 以上，退到 2m 外拍；广角只在需要夸张时用 |
| 合影后排的人不清晰 | 景深不足 | 缩到 f/8；用超焦距；或让后排靠前一点 |
| 拍运动物体全是拖影 | 快门过慢 | 提到 1/500 以上（快跑 1/1000，飞鸟 1/2000）；用 AF-C + 连拍 |
| 拍运动物体对不上焦 | 用了 AF-S 或对焦点选错 | 改 AF-C + 区域对焦；或"陷阱对焦"预对在必经之路 |
| 夜景灯光是一团白斑 | 过曝 | 减曝光（-1~-2EV）；缩光圈让灯光呈星芒（f/11~f/16） |
| 夜景长曝出现星点拖线 | 超过 500 法则 | 缩短曝光时间；降低焦距；或使用赤道仪 |
| 室内照片整体发黄 | 白平衡未匹配钨丝灯 | 手动设 2700~3200K；或拍 RAW 后期调；加闪光并给闪光贴 CTO 匹配环境 |
| 同一场景照片色调忽冷忽热 | 用了自动白平衡 | 固定白平衡（如 5500K）拍 RAW，后期统一 |
| 闪光灯直闪，人脸油光 + 身后硬影 | 直闪 | 改跳闪（打天花板/侧墙）；加柔光罩；输出降到 -1EV |
| 闪光灯拍照时部分画面是黑的 | 快门超过闪光同步速度 | 快门压到 1/200 或 1/250 以下；或使用高速同步（HSS，输出会衰减） |
| 拍流水不是丝滑的 | 快门太快 | 加 ND 镜后降到 1/4~2s；上三脚架 |
| 风光的画质整体发软 | 光圈太小（衍射）或三脚架不稳 | 光圈不超过 f/16；用快门线/延时；关防抖；加重三脚架或挂重物 |
| 换镜头后出现固定黑斑 | 传感器进灰 | 气吹 + 传感器清洁；在 f/16 下验证 |
| 存储卡读取报错 | 卡老化/文件系统错误 | 立即停止使用，用数据恢复软件抢救；之后更换卡（不要继续写） |
| 电池显示满格但很快关机 | 电池老化 / 低温 | 更换电池；低温时贴身保温；备用电池 |
| 照片在手机上看偏色 | 用了 AdobeRGB 未转 sRGB | 网络发布前统一转 sRGB |
| 高光（白婚纱、白墙）没细节 | 高光溢出 | 减曝光，拍 RAW 并向右曝光但不溢出；宁欠勿过 |
| 暗部（黑西装、黑猫）成灰团 | 曝光过度导致黑部落在中灰 | 减曝光 -0.7~-1.3EV；后期压暗部 |

## 9. 附件与辅助

### 9.1 核心附件作用与选购

| 附件 | 作用 | 选购要点 |
|---|---|---|
| **三脚架** | 稳定、长曝、精确构图、延时 | 承重 ≥ 器材重量的 2~3 倍；碳纤维（轻、贵）vs 铝合金（重、便宜）；云台：球型（快）vs 三维（精确）vs 液压（视频） |
| **快门线 / 遥控** | 避免按快门引起的震动 | 有线（可靠）vs 无线（方便）；也可用机身"延时 2 秒自拍"替代 |
| **L 型快装板** | 快速切换横竖构图且重心不变 | 需匹配机身型号；拍风光/建筑强烈推荐 |
| **UV 镜** | 保护镜头前组 | 选多层镀膜的优质镜；劣质 UV 显著降低画质 |
| **偏振镜（CPL）** | 消除非金属反光、加深天空、增强饱和 | **风光必备**；注意：广角 + CPL 会有不均匀的天空渐变 |
| **ND 减光镜** | 减少进光，实现慢门（流水、云、人流虚化） | ND8（3 档）/ ND64（6 档）/ ND1000（10 档）；选无偏色的好镜 |
| **GND 渐变镜** | 压暗天空，平衡天地光比 | 软过渡（山峦）/ 硬过渡（海平线）；也可用包围曝光替代 |
| **反光板** | 补光、柔化阴影 | 白/银/金/黑/半透；五合一最实用；银色太硬，白色最自然 |
| **柔光板** | 把硬光变柔光 | 手持或支架；纱质柔光布 + 框架 |
| **黑旗 / 黑卡** | 遮挡杂光、制造轮廓 | 黑绒布最吸光 |
| **闪光灯** | 补光、凝固、压环境光 | 机顶（便携）vs 离机（可控）；支持 TTL + 手动 + HSS |
| **引闪器** | 离机触发闪光 | 支持 TTL/手动、HSS、分组 |
| **色卡 / 灰卡** | 白平衡与色彩校准 | 18% 灰卡最基础；色卡用于精确色彩还原 |
| **备用电池 / 存储卡** | 保证不断电不断卡 | 至少各 2 份 |
| **气吹 / 镜头布** | 清洁 | 气吹用橡胶球（不要用罐装压缩空气，可能喷液） |
| **干燥箱 / 防潮箱** | 防霉 | 电子防潮箱（湿度设定 40%~50%） |

### 9.2 滤镜对曝光的影响（档数速查）

| 滤镜 | 减光档数 | 曝光调整 | 典型用途 |
|---|---|---|---|
| UV | 0 档 | 无需补偿 | 保护镜片 |
| CPL 偏振镜 | 约 1~1.5 档 | 加曝 1~1.5 档 | 消反光、深蓝天、增饱和 |
| ND2 | 1 档 | 快门慢 1 档 | 轻微虚化水流 |
| ND4 | 2 档 | 慢 2 档 | 流水 |
| ND8 | 3 档 | 慢 3 档 | 丝滑瀑布、车流 |
| ND64 | 6 档 | 慢 6 档 | 云层拉丝、白天长曝 |
| ND1000（ND3.0） | 10 档 | 慢 10 档 | 极长曝（30s~2min）、人群消失 |
| GND 0.3 / 0.6 / 0.9 | 1 / 2 / 3 档 | 局部压暗天空 1/2/3 档 | 日出日落、大光比风光 |

**换算示例**：ND1000（10 档），不装滤镜时快门 1/125s → 装后 1/125 × 2^10 ≈ 8 秒。

**长曝计算口诀**：**每 1 档 ND = 快门时间 × 2**。所以 ND8（3 档）= ×8；ND64（6 档）= ×64；ND1000（10 档）= ×1024。

### 9.3 相机包与出行选购

| 需求 | 建议 |
|---|---|
| 街拍/短途 | 单肩或斜挎包，取机快，不引人注目 |

| 防雨 | 自带防雨罩的包 |
