## 0. 光的基本判断

### 0.1 四个维度：任何现场先问这四个问题

判断光 = 判断四件事的取值。四件事定完，曝光和气氛基本就定了。

| 维度 | 问什么 | 取值区间 | 影响 |
|---|---|---|---|
| 光位（方向） | 光从哪来？相对人脸的水平角 + 高度角 | 0°~360° 水平；-30°~90° 高度 | 立体感、阴影位置 |
| 光比（反差） | 亮面与暗面差几档？ | 1:1 ~ 1:16 | 硬朗/柔美、男性/女性倾向 |
| 光质（软硬） | 光源面积相对被摄体有多大？ | 极小→极大 | 过渡带软硬、皮肤质感 |
| 色温（冷暖） | 光源多少 K？混合光有几种？ | 1800K~10000K | 情绪、白平衡、能否混合 |

**光比换算表（这是最实用的一张表）**

| 光比 | 差档数 | 暗面/Normal 感光差 | 观感 |
|---|---|---|---|
| 1:1 | 0 EV | 无阴影 | 平、干净、证件照 |
| 1:2 | 1 EV | 暗面欠 1 档 | 柔和、唯美、日系 |
| 1:3 | 1.5 EV | — | 甜美人像常用 |
| 1:4 | 2 EV | 暗面欠 2 档 | 标准经典、立体 |
| 1:8 | 3 EV | 暗面欠 3 档 | 戏剧、硬朗、男性 |
| 1:16 | 4 EV | 暗面近黑 | 低调（low key）、剪影感 |

**换算口诀**：
- 光比 = 2^(档数差)，反推档数 = log2(光比)。
- 1:2 = 1 档差；1:4 = 2 档差；1:8 = 3 档差；1:16 = 4 档差。
- 实操：只测亮面与暗面各一次，读数差几档就查上表，不用背光比数字。

### 0.2 光质判断：面积决定软硬

**为什么**：阴影的过渡带宽度 = 光源"视面积"（光源尺寸 ÷ 光源到主体距离）的函数。视面积越大→半影区越宽→过渡越柔。

判断方法：举手看自己的影子边缘。
- 影子边缘像刀切 → 硬光（裸闪、直射正午太阳、裸灯泡、聚光灯）
- 影子边缘糊成一片 → 软光（柔光箱、柔光伞、阴天、大面积窗户、反光板反弹）

**视面积速算**：
- 1m 柔光箱在 1m 外 → 视面积角约 53°，很柔
- 1m 柔光箱在 3m 外 → 视面积角约 19°，接近硬光
- **关键结论：柔光箱"越近越柔"，不是"越大越柔"。拉远柔光箱等于把它变小。**

### 0.3 色温速查

| 光源 | 色温 K | 备注 |
|---|---|---|
| 烛光 | 1800~2000 | 极暖 |
| 白炽灯/钨丝灯 | 2600~3000 | 暖黄 |
| 日出/日落（黄金时刻） | 3000~4500 | 越接近地平线越暖 |
| 荧光灯（家用日光管） | 4000~4500（绿偏） | 显色差，需 +15~30 品红校正 |
| 正午阳光 | 5200~5600 | 基准 |
| 阴天/蓝调时刻 | 6500~10000 | 冷青 |
| 电子闪光灯 | 5500~5600 | 与正午一致 |

**混合光判据**：现场若有两种色温，必须二选一当主，另一种要么关掉、要么用色片（CTO/CTB）拉齐，要么主动保留做造型（如蓝调背景 + 暖闪人）。**不能"两个都凑合"**，那会出脏色。

### 0.4 现场观光的 5 步法

**第 1 步 · 找主光方向（30s）**：看脸上高光落在哪侧 = 主光侧；看影子往哪倒 = 光源在反方向。结论只需一个数：水平角多少度 + 高度多少度。
**第 2 步 · 判光质（10s）**：下巴/鼻下影子边缘锐=硬、糊=软；再看柔光物多大、离人多远（视面积法则）。
**第 3 步 · 测光比（20s）**：分别测亮面（朝主光那侧脸颊）与暗面，差几档 → 查 0.1 表 → 决定要柔还是要刚。
**第 4 步 · 定色温与白平衡（20s）**：判定主色温，决定 WB 要"准"还是要"偏"；用闪时先想好闪（5500K）与环境色的关系（齐色 / 冷暖对比）。
**第 5 步 · 算快门能否压得住（30s）**：先定光圈（管主体）→ 调快门（管环境）→ 调 ISO（管全局）；关键判断 **同步速度能否顶住**——环境太亮时 1/200 会过曝，必须走 HSS 或 ND。

**5 步法自检短语（可照念）**：
> "光从左边 45 度、高 30 度来；边缘有点糊，是柔光；亮面暗面差 2 档，光比 1:4；色温 5500K 跟闪一致；快门 1/200 环境不炸。"

## 1. 自然光

### 1.1 一天的时间分区

| 时段 | 大致时间（中纬度） | 色温 | 光质 | 用途 |
|---|---|---|---|---|
| 蓝调时刻（晨） | 日出前 20~40 min | 8000~10000K | 极柔 | 空镜、情绪、城市冷调 |
| 黄金时刻 | 日出后 0~45 min | 3000~4500K | 柔而暖 | 人像主力时段 |
| 上午 | 8:00~10:30 | 5000~5500K | 渐硬 | 通用 |
| 正午 | 11:00~14:00 | 5500~6000K | 最硬（顶光） | 避光或改造 |
| 下午 | 15:00~17:00 | 5000~5500K | 渐柔 | 通用 |
| 黄金时刻 | 日落前 45~0 min | 3000~4500K | 柔而暖 | 人像主力时段 |
| 蓝调时刻（昏） | 日落后 15~40 min | 7000~10000K | 极柔 | 夜景人像打底 |

**核心原则**：黄金时刻好，是因为阳光"高度角低（10°~20°）+ 穿过厚大气被散射"——**方向好 + 光质柔**两者同时具备。其余时段只能二选一。

### 1.2 黄金时刻详解

**位置规律**：太阳高度角 0°~20° 最佳（低于 0° 变蓝调、高于 20° 开始硬）。方向选择：顺光/前侧光（摄影师身后 0°~45°）→ 皮肤暖金最保险；侧光（90°）→ 立体感最强但暗面要补；逆光（人物后 0°~30°）→ 发丝金边最出片，但必须补脸。

**为什么显高级**：暖调关联"温度/怀旧/幸福感"；低角度长阴影带来纵深与引导线；柔和过渡保留皮肤细节。
**技术参数**：逆光金边 → 对天空测光、人物欠 1.5~2.5 档，后期提亮或打闪补脸；逆光 + 闪 → 闪 1/4~1/16 + CTO 1/8 与夕阳齐色；顺光 → 对脸点测直接出片。

### 1.3 蓝调时刻详解

**定义**：太阳落到地平线以下 4°~8° 的窗口，天空饱和深蓝、天光均匀，约 20~40 分钟。

**为什么好用**：天光变成一只巨大"柔光箱"，全向柔光无硬影；天空蓝 + 灯光暖天然冷暖对比；环境光足够，高 ISO 或慢门即可拍，闪光压力小。

**技术参数**：WB 4000~4500K（让天空更蓝）；曝光 f/2.8 + 1/60 + ISO 1600，或 f/4 + 1/30 + ISO 3200；闪 1/8~1/1 + CTO 暖片，压不住就当主光用 1/2~1/1。**注意**：蓝调窗口短，先定机位，不要现场找构图。

### 1.4 正午顶光：最差的天然光位，怎么救

**问题**：太阳高度 70°~90°，眼窝全黑、鼻下投影、脸颊出现"浣熊眼"，轮廓扁平。

**四种解法**：① **找遮挡做柔光**（首选）树下/廊下/屋檐/墙角；人站明暗交界线内侧 30~60cm，让少量直射光扫过脸颊一侧 → 免费的分割光（树影会投影，需柔光布/反光板二次柔化）；② **反光板硬补** 底部银板 60°~75° 仰角打下巴，距离 0.8~1.5m，光比压到 1:2~1:3；③ **打闪压光**（见第 6 节）闪光超环境 1~1.5 档即可压平顶光阴影，闪要加柔光箱；④ **转逆光/侧逆光** 背对太阳做轮廓光，脸靠反射光/反光板。

### 1.5 阴天：被低估的好光

**性质**：整片天空是光源，等于一个 180° 的巨型柔光箱，全向无影，光比接近 1:1~1:2。

**优点**：皮肤零瑕疵感、无需补光、全天可拍；**缺点**：太平缺立体、色温偏冷偏青、天空死白。
**改造方法**：① 加"假主光"——黑旗（黑布/黑卡）挡在人脸暗面一侧 0.5~1m 外，吃掉那侧环境光 1~2 档 → 虚拟光比 1:3，立显立体；② 加暖闪——闪 1/8~1/4 + 1/4 CTO 做主光制造方向感；③ 色温——机内 WB 6000~6500K 校冷偏，或反用青调拍冷峻主题；④ 天空——纯白天空当负空间/留白，或用长焦压缩、低机位贴地减少占比。

**为什么黑旗比加灯高级**：加灯是"加法"容易出假；减光是"减法"，保留自然质感。

### 1.6 窗口光：室内最好用的自然光

**判断要点（4 变量）**：窗户朝向（北半球北窗最佳，全天稳定柔光无直射）；人-窗距离（0.5~2m，越近越柔越亮、越远越硬越暗）；人物与窗夹角（0°=正侧光立体，45°=前侧光通用，90°=侧逆光）；窗面积（越大越柔，落地窗＞飘窗＞小窗）。

**黄金位置**：人物站在距窗 0.8~1.2m，身体与窗平面呈 **30°~45°**，脸朝窗但略偏镜头 15°。→ 得到"前侧光 + 一侧略欠"的经典立体光。

**改造手段**：加白纱/柔光布（贴窗前 30~50cm，光比 1:8→1:3）；白板补暗面（暗面 1m 外，压到 1:2）；黑旗挡掉暗面墙反光做光比；小输出闪在窗前上方与窗光同向补眼神光。

**话术**："你站到这里，肩膀对着窗户，脸转回来一点点看我——对，就这样。你不用管光，只管把下巴往前送两厘米，眼睛看我。"

### 1.7 门洞光：最像影棚的天然光

**性质**：门洞/巷口/车库门是"高窄"矩形光源，方向性强、边缘明确，等于天然"条形柔光箱"。
**用法**：人站门洞内侧 0.5~1m、窄边朝人 → 分割光/窄光，立体感极强；人站门外侧面向门洞 → 变逆光轮廓光；门洞光 + 内部反光板 = 小影棚。
**为什么好**：矩形光源形成"条形眼神光"，高度角天然 20°~45°，接近伦勃朗光高度（走廊、隧道、天桥拱洞同理）。
**注意**：门洞光很暗（可能只有 f/2.8 1/30 ISO 3200），快门须压慢防手抖（≥1/60 或上脚架）。

### 1.8 实拍数据：侧光人像怎么用

场景：晴天下午 2 点，前侧光（太阳在人物右侧前 45°、高 45°）。
1. 让被摄者**鼻子对准阴影侧**（脸朝镜头偏左）→ 光落右脸、左脸过渡（"短边光"，显脸窄）。
2. 测光：右脸 f/5.6、左脸 f/2.8 → 差 2 档 → 光比 1:4。
3. 要柔 → 左脸加白板压到 1:2（f/4）；要硬 → 左脸加黑旗拉到 1:8。
4. 快门 1/250（快过同步速度）→ 不能用闪，纯自然光；非要打闪就降到 1/200 或开 HSS。
5. WB 5600K，或故意 6500K 让阳光更暖。

**反光板距离法则**：能量随距离平方衰减——距离翻倍，补光强度减为 1/4（约 2 档）。板子"稍远一点"往往就够，"贴太近"是新手最大的病（详细反光板特性见第 2 节）。

## 2. 反光板与控光器材

### 2.1 五色反光板

| 颜色 | 反射率 | 补光量（距 1m） | 色温影响 | 适用 |
|---|---|---|---|---|
| 白 | ~90%，漫反射 | +0.5~1.5 档 | 中性 | 通用人像、婴儿、日系 |
| 银 | ~95%，半镜面 | +2~3 档 | 中性偏冷 | 需要强力补光、锐眼神光 |
| 金 | 反射 + 染色 | +2~3 档 | +300~600K 暖 | 逆光暖调、夕阳齐色 |
| 黑（吸光） | 极低 | -1~3 档 | 无 | 做光比、塑造立体 |
| 半透（柔光） | 透射 | — | 中性 | 把硬光变软 |

**一句话选择法**：要自然看不出补光 → 白；要强力有商业感 → 银；要暖/夕阳感 → 金；要立体戏剧 → 黑；要软化直射光 → 半透（当柔光布用）。

### 2.2 反光板的角度法则

**核心规律（入射角=反射角）**：板面法线须平分"主光→板"与"板→脸"两个方向。简化为两条法则：
1. **上下法则**（高度决定阴影方向）：板低于下巴 → 光向上打 → 眼窝亮、额头暗（"上扬光"）；板高于眼睛 → 光向下打 → 额头亮、下巴暗（等同顶光）。
2. **左右法则**（板放主光**对侧**，夹角 60°~120°）：夹角过小（<45°）补的是亮面等于白补；夹角过大（>150°，板靠镜头）光正打脸、脸变平。

**距离法则**：
| 板到人物距离 | 补光效果 | 光比（假设主光亮面 f/5.6） |
|---|---|---|
| 0.5m | +2.5~3 档 | 1:1.4 |
| 1m | +1.5~2 档 | 1:2 |
| 1.5m | +1~1.5 档 | 1:3 |
| 2m | +0.5~1 档 | 1:4 |
| 3m | 基本无效 | 1:8（原值） |

### 2.3 柔光器材

| 器材 | 便携性 | 柔度（同尺寸） | 光损 | 适用 |
|---|---|---|---|---|
| 透光伞（shoot-through） | 极高 | 中 | 1~1.5 档 | 外拍、快速、大范围 |
| 反光伞（带银/白涂层） | 极高 | 中 | 1.5~2 档 | 外拍、光更"包裹" |
| 柔光箱（正方形/长方形） | 中 | 高 | 1.5~2 档 | 影棚主力、可控性强 |
| 八角箱（octabox） | 中 | 极高 | 1.5~2 档 | 人像、圆形眼神光、最像窗光 |
| 条形箱（stripbox） | 中 | 高 | 2 档 | 轮廓光、发丝光、侧面强光 |
| 美颜罩（beauty dish） | 中 | 中（硬中带软） | 0.5~1 档 | 时尚、立体、有"闪光感" |
| 反光碗（bare reflector） | 高 | 硬 | 0 | 强光、轮廓、工业感 |

**尺寸选择**：半身/头像 60~90cm；全身 120cm 以上；全身 + 环境 150~180cm 或八角。
**关键几何**：柔度看"光源直径 ÷ 主体距离"。要得到 90cm 箱在 1.5m 外的柔度，120cm 箱放 2m 外即可。**"箱越大越柔"只在距离相同时成立。**

### 2.4 控光配件

| 配件 | 作用 | 光损 | 光斑角 | 用途 |
|---|---|---|---|---|
| 蜂巢（grid，20/30/40°） | 限方向、防溢光 | 0.5~1.5 档 | 20°~40° | 发丝光、背景光、防近邻光污染 |
| 束光筒（snoot） | 极窄光束 | 1~2 档 | 10°~20° | 点光、局部提亮、戏剧效果 |
| 旗板（flag/gobo） | 挡光 | — | — | 精确控制溢光，最重要也最被忽视 |
| 格栅（barndoors） | 四片可调挡板 | 0.3~1 档 | 可调 | 快速修裁光斑边缘 |
| 色片（gels） | 改变色温 | 0.3~1 档 | — | CTO 暖 / CTB 冷 / 加绿校荧光灯 |
| 减光纱（scrim） | 减弱输出不改变光质 | 0.5~2 档 | — | 保光质前提下微调 |

**旗板为什么最重要**：影棚 80% 的问题是"溢光"而非"光不够"——主光杂散光打到背景/白墙再反弹，会把立体感吃掉。**用黑旗切干净溢光，比加一盏灯有效得多。**
**蜂巢选择**：发丝上打明确光斑、不污染背景 → 20°；给背景打柔光 → 40°；度数越小光越集中、衰减越快、光损越大。

### 2.5 常见错误清单

| 错误 | 现象 | 原因 | 修正 |
|---|---|---|---|
| 反光板贴脸太近 | 脸平、油光、双下巴 | 补光过强 + 板位过低 | 移到 1~1.5m，抬高到眼平以上 |
| 反光板与主光同侧 | 补光无效 | 板补的是亮面 | 板移到主光对侧 |
| 只用银色板 | 皮肤反光、死白 | 板太硬太亮 | 换白板，或加一层柔光布 |
| 柔光箱拉太远 | 光变硬、边缘锐 | 视面积变小 | 拉近，或换更大箱 |
| 柔光箱正对脸 | 无立体、无鼻影 | 光位太正（0°） | 侧移 30°~45° |
| 不用旗板 | 背景被污染、立体感弱 | 溢光 | 主光加旗，或加蜂巢 |
| 伞当柔光箱用 | 光斑椭圆、控制差 | 伞的光斑是圆且溢散 | 需要精确控制就换箱 |
| 忘了闪光比 | 光比失控 | 没有分别测亮暗面 | 每次换位后重测 |

## 3. 人像布光的经典光型

**共同前提**：以下"水平角"以"人物鼻尖指向镜头"为 0°，顺时针为正；"高度角"以眼睛水平线为 0°。

### 3.1 蝴蝶光（派拉蒙光 / Paramount）

- **光位**：水平 0°（与镜头同轴，可偏 5°~10°）；高度 **45°~60°**（关键在"高"——鼻下出现对称蝴蝶形小阴影，影长约鼻长一半）；灯距 1.2~1.8m，配 60~90cm 美颜罩/柔光箱
- **光比**：1:2~1:3（暗面靠辅光或反光板）
- **脸型**：适合鹅蛋/长/方脸（拉宽颧骨、显饱满）；不适合圆脸、婴儿肥、鼻梁过塌
- **为什么有效**：正对光把脸中央打亮、两侧衰减，形成"中心亮、边缘暗"对称渐变，脸显窄显立体；鼻下蝴蝶影是签名
- **参数**：主光 f/8（1/4~1/2 输出）、辅光 f/5.6（或白板 1m）、背景 f/5.6、发丝 f/8
- **话术**："下巴往前送一点点，像下巴下面夹了个鸡蛋。眼睛别抬，看我镜头上方一点的灯。"

### 3.2 伦勃朗光（Rembrandt）

- **光位**：水平 **45°~60°**（脸转 1/4 朝光源）；高度 **40°~50°**；灯距 1.5~2m
- **标志**：暗侧面颊出现**倒三角（菱形）亮斑**，位于眼下与鼻翼之间——唯一的识别标准
- **光比**：1:3~1:8（暗面可少量补光）
- **脸型**：最适合圆脸/宽脸/脸胖/下颌线不明显（暗面直接削掉一侧宽度）；不适合瘦脸、童颜
- **命名/难点**：源自伦勃朗"一侧受光、另侧沉入暗部"的画法；三角大小由灯高 + 脸转角共同决定——灯太高→三角消失（变蝴蝶/顶光），灯太低→变长条（变分割光），需反复微调灯高 ±10° 至成形
- **参数**：主光 f/8、辅光/白板 f/4~f/5.6（保持三角可见）、背景 f/4
- **话术**："左半边脸慢慢转过去——停！就这样，别动，我调灯。"

### 3.3 环形光（Loop Lighting）

- **光位**：水平 **30°~45°**；高度 **25°~35°**（比蝴蝶光低）
- **标志**：鼻影呈"小钩/环状"，从鼻翼旁斜向延伸，**不与暗面颊阴影相连**（与伦勃朗的区别：伦勃朗"闭合成三角"，环形"敞开的钩"）
- **光比**：1:2~1:4
- **脸型/为什么推荐**：**万金油最通用**，绝大多数脸型适用；介于蝴蝶（正）与伦勃朗（侧）之间，既立体又明亮，失误容忍度最高，是最保险的默认光型
- **参数**：主光 f/8、白板 1m 处 f/5.6（比 1:2）

### 3.4 分割光（Split Lighting）

- **光位**：水平 **90°**（正侧面）；高度 30°~45°
- **标志**：脸被鼻梁中线劈成两半，亮一半暗一半，暗面可近全黑
- **光比**：1:8~1:16（甚至更大）
- **脸型**：几乎所有脸型（砍掉一半脸），尤适合"硬朗、神秘、男性、性格"
- **注意**：需正面有极暗环境/黑旗，否则暗面"漏光"；鼻影横跨脸易压在嘴唇上；眼睛高光偏一侧易出"独眼"感，做造型好、常规人像需谨慎
- **参数**：主光 f/8、辅光几乎不要（或极弱 f/2.8）、背景可暗可亮
- **话术**："完全侧过来，看我这边——只看到我一只眼睛就够了。"

### 3.5 宽光与窄光（Broad / Short）

**定义**：脸相对相机转 1/4 或 3/4 时，主光照"离相机近的脸侧"= 宽光，照"离相机远的脸侧"= 窄光。

| 类型 | 主光位置 | 视觉 | 光比 | 适用 |
|---|---|---|---|---|
| 宽光 | 照亮靠向相机的半张脸 | 脸显**宽**、显胖 | 1:2~1:3 | 瘦脸、温柔亲和 |
| 窄光 | 照亮背离相机的半张脸 | 脸显**窄**、显瘦 | 1:3~1:6 | 宽脸、圆脸（最常推荐）|

**为什么窄光显瘦**：让"离镜头近的半张脸"沉入阴影，近端（占画面更大）变暗收缩，面部宽度视觉减半。
**误用警示**：新手常无意识拍宽光，每张脸胖一圈。**默认应是窄光。**
**参数（窄光）**：主光 f/8、暗面白板 f/4（1:4）、背景 f/4、发丝 f/8

### 3.6 轮廓光 / 发丝光（Rim / Hair Light）

**光位**：水平 **135°~170°**（人物背后侧向）；高度 **30°~60°**（越高越能扫到头顶/发顶/肩线）；位置在人物身后 1~1.5m、主光对侧。
**作用**：① 边缘勾一条亮线把主体从背景剥离；② 照亮发丝（黑发在深背景时增层次）；③ 增加顶/背光的立体包裹感。
**光比**：比主光**亮 0.5~1.5 档**（要明显但不过曝）。
**器材**：条形箱（best，光斑细长贴合轮廓）；束光筒/裸灯 + 蜂巢打发顶集中；**必须加蜂巢（20°）或旗板**，否则杂光入镜产生眩光雾化。
**常见错误**：发丝光太亮 → 头发死白失细节；角度太正背 → 变顶光、头顶一热点；打在额头 → 变抢戏亮点；没加蜂巢 → 画面雾。
**参数**：f/8（同主光）~ f/11（略强）；深色发/背景用 f/11。
**话术**："稍微转头背向窗户一点点——好，发丝上那条光出来了，别动。"

### 3.7 眼神光（Catchlight）

**定义**：光源在眼球上的反射点，是"有神"的关键；形状由光源形状决定：

| 光源 | 眼神光形状 | 观感 |
|---|---|---|
| 柔光箱（方） | 方形 | 专业、摄影棚感 |
| 八角箱 | 八角/圆 | 柔和自然 |
| 美颜罩 | 圆盘 + 中间热斑 | 时尚、有眼神 |
| 反光伞 | 圆形/椭圆 | 自然、略随意 |
| 环形闪 | 圆环 | 高冷时尚、"眼神圈" |
| 窗 | 矩形 | 极自然 |
| 反光板 | 正方形小白点 | 增加但略显刻意 |

**关键规则**：① **位置**在瞳孔**上方 10 点~2 点方向**（略高于瞳孔中心）→ 有神采；太靠下（6 点）→ 没精神/惊悚；正中 → 呆板。② **大小为瞳孔面积 10%~25%**，太大像"死鱼眼"，太小看不见。③ **两点同高**（双侧反光板时两眼点应大致同水平，否则显斜视/呆滞）。④ **不要第三个点**（反光伞/白墙/反光板的杂点要用旗板挡掉）。⑤ 让人**抬高下巴、眼睛向下看镜头**（eye line 略低），光点才落在瞳孔里。

**为什么重要**：人眼会自动在对方眼里寻找"光点"判断精神/生命感，缺眼神光的人像显得死气沉沉。

**参数**：来自主光即可，无需专门灯；伦勃朗光下光点偏一侧时可加小反光板补第二个点（须与第一点对齐）。**话术**："头稍微低一点点，眼睛从上面抬起来看我——对，就这样看着我，不要眨。"

## 4. 单灯到多灯

### 4.1 推进逻辑：一次只加一盏，每次只解决一个问题

| 阶段 | 灯数 | 每盏灯的任务 | 光比目标 |
|---|---|---|---|
| 起手 | 1 主光 | 定光型 + 定光比（用距离/反光板） | 1:4（靠距离） |
| 第二步 | +1 辅光（或白板） | 把暗面从 1:8 抬到 1:3 | 1:3 |
| 第三步 | +1 背景光 | 把主体从背景剥离 | 背景比主体暗 1~2 档 |
| 第四步 | +1 发丝光 | 勾边、增层次 | 比主体亮 0.5~1 档 |
| 进阶 | +1 轮廓/背光 | 强化轮廓/造型 | 视风格 |

**"一盏灯一个任务"原则**：每盏灯必须能回答"它负责什么"，说不清就关掉——**加灯的代价是溢光和失控，不是"光更足"**。自检顺序：加完一盏 → 关掉其他先测它单独效果 → 再全开看叠加 → 对比光比是否变化。

### 4.2 多灯光比控制

**光比由三个量决定**（会调这三个就能任意控比）：① **输出功率**（1/2、1/4、1/8…）差一档 = 1 EV；② **灯距**（平方反比）距离 ×1.41 = 差 1 档、×2 = 差 2 档；③ **光损器材**柔光箱 1.5~2 档、蜂巢 0.5~1.5 档。
**换算示例**：主 1/4@2m + 辅 1/4@2.8m → 辅差 1 档（2.8/2=1.41）→ 1:2；主 1/8@1.5m + 辅 1/8@1.5m + 柔光箱(-1.5 档) → 1:3。
**调整优先级**：先动距离（免费），再动器材（改光质，谨慎），最后才动功率（会同时影响全局曝光）。

### 4.3 各灯位的"高度角-水平角"参考表

| 灯 | 水平角 | 高度角 | 距离 | 器材建议 |
|---|---|---|---|---|
| 主光 | 30~60° | 40~50° | 1.5~2m | 柔光箱/八角/美颜罩 |
| 辅光 | 对侧 30~60° | 20~30° | 1.5~2.5m | 柔光箱（大而远）或白板 |
| 背景光 | 人物正后 / 后侧 45° | 30~60° | 1~1.5m | 蜂巢（20~40°）或裸灯 |
| 发丝光 | 背后 135~170° | 30~60° | 1.5~2m | 条形箱 / 蜂巢 20° |
| 顶光/氛围 | 0~30° | 70~90° | 1.5~2m | 柔光箱或格栅 |
| 背光（人物后） | 180° | 20~40° | 2~3m | 裸灯 / 束光筒 |

### 4.4 经典四灯配置（商务/杂志人像）

① **主光** 45°/45°，120cm 八角，f/11（1/2 输出）@2m；② **辅光** 对侧 40°/25°，白板 1.5m 或柔光箱 f/8，制造 1:2；③ **背景光** 人物后上 45°/45°，40° 蜂巢，f/8，打到背景（比人物暗 1 档）；④ **发丝光** 背后 150°/50°，条形箱 + 20° 蜂巢，f/11。
**测光顺序**：先测主光（其他关）定光圈 → 开辅光调光比 → 开背景光调到比人物暗 1~2 档 → 开发丝光调到亮 0.5~1 档。

### 4.5 常见多灯错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 一次开全部灯调位 | 分不清哪盏在起作用 | 关掉其他，一盏一盏调 |
| 辅光比主光还亮 | 变成"双主光"，脸平 | 辅光至少主光 -1 档 |
| 背景光打到人身上 | 背景光溢光污染人物轮廓 | 加蜂巢、加旗、调角度 |
| 三盏灯全用柔光箱 | 全部很柔，没有层次 | 留 1~2 盏用硬光/蜂巢做对比 |
| 灯距不一致却用同样功率 | 光比不可控 | 每次换位后重测 |
| 五盏灯 | 溢光失控 → 立体感全失 | 减到三盏，用旗板代替 |

**核心结论（值得背）**：**好照片的光是被"减"出来的，不是被"加"出来的。** 三盏灯 + 四块旗，胜过六盏灯。

## 5. 热靴闪光灯

### 5.1 TTL vs 手动

| 维度 | TTL（自动） | 手动 M |
|---|---|---|
| 原理 | 相机通过预闪测光，自动算输出 | 你手动设定 1/1~1/128 |
| 优点 | 快、环境变化时不慌、抓拍 | 完全可预测、多灯一致、光比可控 |
| 缺点 | 每张都可能不同（不稳定）、易被反光干扰 | 需要经验预判 |
| 适用 | 婚礼抓拍、活动、移动场景 | 影棚、固定机位、多灯、压光 |

**混合策略（最实用）**：主灯用 M 定光型 → 机顶 TTL 跳闪（+0.7 EV）当辅光 → 环境在变时只靠 TTL 那盏兜底。

### 5.2 闪光指数 GN

**定义与公式**（GN 按 ISO100、距离单位 m）：GN = 光圈 × 距离；即 距离 = GN ÷ 光圈，光圈 = GN ÷ 距离。多数热靴灯标 ISO100 的 GN，如 GN58 @105mm。
**为什么必须懂**：手动模式下 GN 是"报价单"，直接告诉你该开多少光圈，不用现场乱试。
**三个陷阱**：① GN 随变焦变化（GN58 是 105mm 端；24mm 端可能只 GN30~35）——**以当前变焦位置的 GN 为准**；② ISO 翻倍 → GN ×1.41；③ 输出减半 → GN ×0.707。
**换算示例**：
- 灯 GN36（ISO100，35mm 变焦），距离 3m，求光圈：36 ÷ 3 = **f/12**（取 f/11）
- 距离 6m：36 ÷ 6 = **f/6**（取 f/5.6）
- 距离 1.5m：36 ÷ 1.5 = f/24 → 需降到 1/4 输出（GN 减半为 18）→ 18 ÷ 1.5 = **f/12**

### 5.3 变焦灯头

**规律**：灯头变焦数值 = 镜头焦段（越大越"聚"）。24mm 端：光斑大、覆盖广、GN 小 → 近距广角/跳闪；105mm 端：光斑小、集中、GN 大 → 远距直射。
**实操原则**：**灯头焦距 ≥ 镜头焦距**，否则边角覆盖不足。镜头 35mm → 灯头 35~50mm；跳闪时灯头设 24mm 或更广，让光散到更大天花面积 → 更柔。

### 5.4 闪光同步速度与 HSS

| 概念 | 典型值（APS-C/FF） | 含义 |
|---|---|---|
| 最高同步速度 X-sync | 1/200 ~ 1/250s（部分旗舰 1/400） | 快门全开、闪光完整覆盖的时间上限 |
| 超过后会发生 | 出现黑边/半黑条 | 第二帘已开始关闭，部分画面未被闪光照到 |
| HSS / FP 高速同步 | 可达 1/8000s | 闪光变为连续多次微脉冲，全程保持光照 |

**HSS 的代价**：输出大幅下降（通常损失 1.5~2.5 档，取决于相机/灯），耗电快，灯容易过热。

**HSS 正确用法**：白天户外大光圈（f/1.4~f/2.8）压太阳必用；大光圈浅景深 + 闪光时是唯一解；不要为"保险"长期开 HSS（浪费输出）。
**为什么不是更高**：焦平面快门两帘幕走完画幅需时，只有两帘全开（快门 ≥ 帘幕走行时间 ≈ 1/250~1/200s）时闪光才能一次性照亮全画幅。

### 5.5 慢速同步 / 前帘 / 后帘

| 模式 | 闪光触发时机 | 效果 | 适用 |
|---|---|---|---|
| 前帘同步（默认） | 快门一开就闪 | 主体清晰在前，拖影在**后**（拖影盖住主体） | 一般情况 |
| 后帘同步 | 快门将关时闪 | 主体清晰在**后**，拖影在**前**（运动方向感自然） | 移动物体、夜景人像、光轨 |
| 慢速同步 | 快门放慢（1/15~1/2s）+ 闪 | 背景曝光充分（环境亮），主体被闪定格 | 夜景人像、婚礼宴会、衬托环境 |

**为什么后帘同步更自然**：运动物体在拖影**前端**清晰（"拖影跟着它跑"），符合人眼对运动的预期；前帘相反，像"果冻"或拖影倒着走。
**夜景人像标准组合**：后帘 + 慢速同步，1/15~1/30、f/2.8、ISO 800~1600、闪 1/8~1/4 + CTO。

### 5.6 跳闪（Bounce）

**五种跳法**
| 跳法 | 灯头朝 | 效果 | 注意 |
|---|---|---|---|
| 天花板跳 | 上（45°~90°） | 最柔的大面积顶光，最像棚灯 | 天花板需白/浅色且低于 4.5m；有色天花板会染色 |
| 墙面跳 | 左/右 45°~90° | 得到方向明确的侧光 | 墙需白/浅；离墙太远无效 |
| 墙顶夹角跳 | 上 + 侧 45° | 最经典、最稳 | 综合天花板与墙面的优点 |
| 反光板跳 | 用白色卡板折射 | 随身、可控光比 | 光损大（1.5~2 档），需高输出 |
| 助手反光板跳 | 助手举白板/银板 | 最灵活、最专业 | 需要人，但效果最好 |

**跳闪三条铁律**：① 反射面需白/浅且不太远——深色、木色、彩色天花板会吃光 2~3 档 + 染色；② 距离 = 灯→面 + 面→主体（天花板 3m、人高 1.7m → 光程 ≈ (3-1.7)+3 ≈ 4.3m，按总光程查 GN）；③ 跳闪把灯位高度角拉到 60°~90° 易变"顶光"、眼窝发黑——**补救：拉出灯上的白色小卡板（catchlight card）造一个向前的眼神光**。
**话术**："不要看我这边，继续看你的新娘。我这边按一下就走，你不会觉得被闪到。"

### 5.7 离机闪的触发方式

| 方式 | 原理 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 光引闪（光学 Slave/S1 S2） | 从灯感应主灯的闪光 | 便宜、简单 | 怕障碍、怕环境强光误触、距离短（~10m）、直线传播 | 单灯近距离、备用 |
| 红外/光脉冲 TTL | 主灯用红外脉冲通信 | 支持 TTL 与分组 | 同样怕遮挡、距离短 | 中小型布光 |
| 无线电（RF）手动 | 发射器无线触发，手动设功率 | 稳定、远（>30m）、可穿墙、无遮挡问题 | 需手动调、无 TTL | 婚礼、大型、多灯主力 |
| 无线电 TTL（2.4GHz） | 无线 + 自动测光 + HSS | 最灵活、支持 HSS、分组 | 贵、偶尔讯号干扰 | 与拍活动、婚礼、移动场景 |
| 引闪线 | 有线连接 | 完全可靠、零延迟 | 有线缠绕、距离限 | 影棚固定位 |

**选型建议**：单灯外拍/婚礼快速 → 无线电 TTL（PocketWizard、Godox X 系统）；多灯固定影棚 → 无线电手动；应急/极简 → 光引闪 + 手动。
**为什么无线 TTL 是主流**：它同时解决"随时移动/无遮挡触发"和"环境变化不用重设"两个问题，在外拍婚礼里几乎是刚需。

## 6. 压光与环境光平衡

### 6.1 什么是压光

**定义**：让闪光曝光量**超过**环境光曝光量，使主体（闪光照亮）相对背景（环境光决定）变亮，从而在画面里"压掉"环境亮度。

**为什么压光**：① 白天户外顶部硬光把脸打黑 → 用闪提亮到"压过"环境，得干净主体；② 想大光圈浅景深但快门到顶（1/200）→ 用闪控曝光而非环境；③ 婚礼逆光仪式 → 压掉过亮背景保主体细节；④ 要"杂志感"：背景稍暗、主体亮、有分离度。

### 6.2 曝光三角的"分工"

**核心口诀：光圈管主体，快门管环境，ISO 管全局。**
- **光圈**：同时影响闪光与环境 → 定主体/闪光的曝光
- **快门**：只影响环境光 → 调背景亮度（闪光持续极短 ~1/1000s，快门对它无效）
- **ISO**：同时影响两者 → 最后用作整体提亮/降噪

**为什么快门对闪光无效**：闪光持续仅 1/1000~1/10000s，快门 1/200 或 1/60 都在快门全开期间完成曝露。

### 6.3 光比换算（环境 : 闪光）

| 目标 | 操法 | 效果 |
|---|---|---|
| 环境:闪光 = 1:0（不压） | 靠环境曝光，闪不为所动 | 补光、跳闪、TTL 自动 |
| 环境:闪光 = 1:1（等量） | 环境过曝 1 档，闪也过曝 1 档 | 闪光+环境同亮，最自然（婚礼宴会常用）|
| 环境:闪光 = 1:2（暗 1 档） | 环境要过曝 1 档（靠闪把主体提亮 1 档） | 背景比主体暗 1 档，主体开始"跳出来" |
| 环境:闪光 = 1:4（暗 2 档） | 环境处于"过曝 2 档" | 背景明显暗，主体清晰，电影感 |
| 1:8 以上 | 环境接近全黑 | 纯闪光，类似影棚（夜景/婚礼逆光） |

**换算示例 A（上午户外）**：① 对天空测光 f/16 1/125 ISO100（环境正确曝光）；② 想要 1:4（背景暗 2 档）：收光圈到 f/32 太小 → 改快门到 1/500 并开 HSS（1/125→1/500 = 2 档）→ 环境欠 2 档 = 1:4；③ 闪光只需把主体照亮到正确：查 GN ÷ 距离 → 设输出。
**换算示例 B（更常用）**：环境正确曝光 f/8 1/250 ISO100 → 想让背景暗 2 档就收光圈到 f/16（f/8→f/11→f/16）→ 环境欠 2 档 → 人物也暗 2 档 → 用闪光补回 2 档（按 f/16 算 GN）。

### 6.4 白天户外用闪的完整流程（8 步）

① **选时段**：避开 11:00~14:00 硬顶光（除非要压），黄金时刻或阴天更省力；② **定机位与光位**：先构图，先想好主光方向（通常 45°/45°）；③ **收环境**：测环境后把快门收到比正确曝光快 1~2 档（背景暗 1~2 档）；④ **定光圈**：f/2.8~f/5.6（浅景深）或 f/8；⑤ **开 HSS**：快门快过 1/200 必开（否则半黑）；⑥ **算 GN 与距离**：GN ÷ 距离 = 光圈，注意 HSS 下有效 GN 降 1.5~2 档；灯太弱就加 **ND**；⑦ **加控光配件**：柔光箱/伞/CTO/蜂巢，近距（<1.5m）必用柔光箱；⑧ **试拍回放直方图**：看主体是否过曝、背景是否够暗（不靠 LCD 亮度感）。

**关键工具 · ND 减光镜**：大晴天想 f/2.8 + 1/8000 → 超 HSS 上限或灯不够 → 用 ND4~ND8 减 2~3 档。原理：ND 同时减环境与闪，但可造成"环境暗 2 档 + 闪全额" → 等于把光比从 1:1 改成 1:4。

### 6.5 压光 vs 补光：两种完全不同的目的

| 概念 | 目的 | 光比 | 结果 |
|---|---|---|---|
| 补光（fill） | 提高暗部亮度，降低反差 | 1:1~1:3 | 主体"好看"、没有黑脸 |
| 压光（flash as key） | 让闪光成为主光，压过环境 | 1:4~1:8 | 主体"独立"、背景"可控" |

**判据**：先问"我要不要保留背景的亮度"。要 → 补光；不要 → 压光。

### 6.6 压光的三个陷阱

| 陷阱 | 现象 | 修正 |
|---|---|---|
| 只调环境忘了灯 | 背景暗了，人更暗 | 先决定背景暗几档，再按新光圈算灯 |
| HSS 忘开 | 出现黑色横带（上/下半黑） | 快门 > 1/200 时必开 HSS 或降到同步速度 |
| 灯太近导致硬光 | 白脸、光斑、无过渡 | 拉远 + 柔光箱；或对着白墙/助手反光板跳闪 |

## 8. 用光诊断表

| # | 症状 | 原因 | 修正 |
|---|---|---|---|
| 1 | 脸太平、没有立体感 | 光位太正（0°~15°）或光比不足（1:1） | 主灯侧移 30°~45°；去掉辅光或加黑旗把光比提到 1:3~1:4 |
| 2 | 鼻影太重像"小胡子" | 主光高度太低（<20°） | 主灯抬到 40~50°，鼻影缩短下沉 |
| 3 | 眼窝全黑、"熊猫眼" | 主光高度太高（>70°）或正顶光 | 降到 35~45°，或加底光/反光板补眼窝 |
| 4 | 双下巴、下颌线消失 | 相机机位过低 + 主光过低 | 提高机位到眼平以上；主光抬到 40~50°；让被摄者下巴前推 + 额头微压 |
| 5 | 皮肤油光、额头反光 | 硬光直射 + 正面角度 | 换柔光箱/加柔光布 + 主灯侧移；用吸油纸或扑粉 |
| 6 | 头发没有层次、一片黑 | 缺发丝光 | 加发丝光（背后 150°/50°，条形箱 + 蜂巢），比主光亮 0.5~1 档 |
| 7 | 人物与背景"粘"在一起 | 无轮廓分离/背景亮度与主体相同 | 加发丝光；调背景光让背景比主体暗 1~2 档；或让背景亮 1 档形成剪影 |
| 8 | 眼神光太小/看不见 | 主光太远或光源太小 | 主灯靠近到 1.2~1.5m；用更大柔光箱；或加小灯/白卡 |
| 9 | 眼神光位置偏低（没精神） | 主光高度角太低 | 抬高主灯到 40~50°；让人眼睛向下看镜头 |
| 10 | 眼中有 2~3 个眼神光点（"眼球粘东西"） | 现场副光源（反光伞、白墙、反光板）产生的反射点 | 加旗板/蜂巢遮掉多余光源 |
| 11 | 光比太大、暗面死黑 | 主光过强、缺辅光、无墙面反光 | 暗面加白板 1~1.5m 或辅光；把光比从 1:8 压到 1:3 |
| 12 | 光比太小、明暗不分 | 环境反光太强（白墙/白地板）、辅光过强 | 用黑旗吃掉反弹光；降低辅光功率；换深色环境 |
| 13 | 背景出现不想要的亮斑/热点 | 主光溢光/无蜂巢，打在背景上 | 主光加蜂巢（40°）与旗板；背景灯加蜂巢控制光斑 |
| 14 | 鼻下/下巴有"双影"（两重影子） | 双光源（主 + 辅都很硬） | 辅光改柔光箱/白板；或把一盏灯关掉 |
| 15 | 皮肤色偏（黄/绿/红） | 混合色温（荧光灯 + 闪） | 用 CTO/CTB/加绿色片校齐；或关掉其中一个光源；用灰卡重设 WB |
| 16 | 人像偏冷/偏蓝 | 阴天/蓝调时段环境光 + 白平衡未校 | WB 设 6000~6500K；闪加 1/4 CTO 制造暖调 |
| 17 | 逆光下脸全黑（欠曝 3~4 档） | 测光对天空、未补光 | 对脸测光或对天空测光后人物补光/闪；用反光板 1~1.5m 或闪 1/4 输出 |
| 18 | 出现"黑色横带" | 快门超过同步速度（>1/200） | 降快门到 1/200 以下，或开 HSS |
| 19 | 慢门拖影盖在人物上方 | 用了前帘同步 | 改后帘同步 → 拖影移到人物后方 |
| 20 | 跳闪后脸是暗的、眼窝黑 | 天花板跳闪导致光位太高，无正面光 | 拉出灯头小卡板（catchlight card）；或改为墙顶夹角 45° 跳；或加一支离机补光灯 |
| 21 | 跳闪后画面偏黄/偏脏 | 天花板/墙是暖色或脏色 | 换用白色/浅色反射面；灯加 1/4~1/2 CTB 校正；或改用离机闪 + 反光板 |
| 22 | 大晴天闪光压不住太阳 | 灯输出不够（尤其 HSS 下） | 加 ND 减光镜把环境压 2~3 档；提高 ISO 让灯"够亮"；换高 GN 灯 |
| 23 | 闪光过曝（脸死白） | 灯太近或输出太高 | 降输出 1/2 → 1/4；拉远到 1.5m 以上；加柔光箱/纱减光 |
| 24 | 影棚全白背景有灰边/暗角 | 背景灯不足或未对称 | 加第二只背景灯（左右各一）打均匀；让背景过曝 1 档；避免背景灯打到人 |

## 9. 参数速查

### 9.1 场景参数区间

各题材（写真/证件照/商务/逆光/夜景/婚礼仪式/婚礼宴会/儿童/商品/静物）的快门·光圈·ISO·色温·闪光区间，见 **第 7 节各方案表格的「参数」行**，此处只列跨场景通用规律：

| 通用规律 | 建议 |
|---|---|
| 影棚/闪光为主 | 1/125~1/200，f/8~f/11，ISO 100~200，WB 5500K |
| 自然光唯美 | 1/250~1/1000，f/2.8~f/4，ISO 100~400 |
| 环境光弱（宴会/夜景） | 1/15~1/100，f/2.0~f/5.6，ISO 800~3200 |
| 好动主体（儿童/运动） | 快门 ≥1/250，ISO 200~800 |
| 色温策略 | 与现场主光齐色；或主动冷却环境（WB 3800~4400K）+ 暖闪 |

### 9.2 光比对照卡

| 光比 | 亮面:暗面 | 用途 |
|---|---|---|
| 1:1 | f/8 : f/8 | 证件照、无影平光 |
| 1:2 | f/5.6 : f/4 | 日系、甜美人像、儿童 |
| 1:3 | f/5.6 : f/3.5~f/4 | 通用写真、商务 |
| 1:4 | f/8 : f/4 | 经典立体、伦勃朗 |
| 1:8 | f/11 : f/4 | 戏剧、男性、硬朗 |
| 1:16 | f/16 : f/4 | 低调、剪影 |

### 9.3 距离 → 输出（快查）

**假设主灯 1/4 输出、柔光箱、1.5m 得到 f/8。想在同一 f/8 下换距离：**

| 距离 | 需要的输出 |
|---|---|
| 1m | 1/8 |
| 1.5m | 1/4 |
| 2m | 1/2 |
| 3m | 1/1（全功率）|

**规则**：距离翻倍 → 需 +2 档输出；距离减半 → 需 −2 档。

### 9.4 换算速记（给 Agent 的"小抄"）

- 光比 = 2^档数差；差 1 档 = 1:2，差 2 档 = 1:4，差 3 档 = 1:8
- 距离 ×1.41 = 差 1 档；×2 = 差 2 档
- GN ÷ 距离 = 光圈；GN 随 ISO 翻倍 ×1.41
- 柔光箱/反光伞光损 ≈ 1.5~2 档；蜂巢 ≈ 0.5~1.5 档
- HSS 输出下降 ≈ 1.5~2.5 档
- 同步速度：1/200~1/250（FF/APS-C 常见）
- 黄金时刻：日出后 / 日落前 45 min 内
- 蓝调时刻：日落前后 15~40 min 的窗口
- 闪灯色温 ≈ 5500K，与正午一致

### 9.5 曝光平衡口诀

| 想做什么 | 动什么 |
|---|---|
| 主体更亮（闪光） | 加输出 / 拉近灯 / 开大光圈 |
| 背景更暗（压光） | 收光圈 / 加快门 / 加 ND |
| 背景更亮（提环境） | 放慢快门（≤同步速度）/ 开大光圈 / 提 ISO |
| 整体提亮 | 提 ISO |
| 保留现场氛围 | 慢速同步 + TTL + 色片齐色 |
| 画面更柔和 | 换大面积柔光 / 拉近灯 |
| 画面更硬更有质感 | 换裸灯 / 束光筒 / 蜂巢，光比提到 1:4~1:8 |
