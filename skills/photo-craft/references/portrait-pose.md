## 0. 人像摄影的总体判断

### 0.1 一张人像先看什么（重要度排序）

拍完先别急着看构图和色调，按这个顺序看，前一项不过关，后面全是白搭：

| 优先级 | 检查项 | 判断标准 | 不合格怎么办 |
|---|---|---|---|
| 1 | 眼神 | 眼睛合焦、有眼神光、视线有内容（不是空的） | 重拍。眼睛糊了这张就废了，除非是刻意的氛围片 |
| 2 | 表情 | 肌肉是"动的"还是"端着的"，嘴角有没有真的提起来 | 别喊"笑一个"，改用逗笑/聊天/连拍抓 |
| 3 | 姿态 | 有没有脖子、有没有腰线、有没有支撑腿 | 微调肩线胯线，让身体出现曲线而非一根棍 |
| 4 | 光 | 脸上有没有明暗过渡（塑形），有没有难看的阴影 | 转脸、换机位、加反光板补下巴阴影 |
| 5 | 背景 | 是否有抢眼元素、是否有"长在头上"的杆子/树/灯 | 左右挪半步，或加大光圈虚化 |
| 6 | 构图与技术 | 水平、裁切位置、高光不炸 | 后期可救，优先级最低 |

**为什么是这个顺序**：人看照片第一眼落在对方眼睛上，第二眼落在表情上，第三眼才看身材和环境。技术瑕疵（轻微欠曝、构图偏一点）观众几乎不会注意，但"眼神空""表情假""站得像罚站"是路人一眼就能看出来的。所以现场把精力花在前三项，别在构图上来回磨。

### 0.2 现场 5 秒自检（背下来，每换一个姿势就默念一遍）

1. **眼睛是在看什么？** —— 视线必须有一个明确的落点（镜头、镜头外 45°、某个具体的东西），不能是"随便看"。
2. **重心在哪条腿？** —— 必须有一条明确的支撑腿，另一条腿放松。两条腿平均受力 = 罚站。
3. **手在干什么？** —— 手必须有"事情做"（插兜、扶帽、拨头发、拿东西、搭栏杆），垂在两侧 = 僵硬。
4. **下巴和脸转了几度？** —— 脸不要正对镜头，转 15°～30° 是通用安全值；下巴微收，但不要收到有双下巴。
5. **背景里有没有长在他头上的东西？** —— 杆、树、灯、别人的头。挪半步解决 90% 的问题。

### 0.3 三条现场铁律

- **先解决光，再解决姿势**。光不对，再好的姿势也难看；光对了，一个普通站姿就很高级。
- **一次只改一件事**。不要同时说"你往左、头低一点、手抬起来、笑一下"——对方会全部做错。改一个，让他保持，再改下一个。
- **拍到第 20 张之前不要下结论**。素人的前 15～20 张基本都是僵的，那是热身，不是成品。要有耐心熬过这段。

### 0.4 判断"这张能不能用"的快速标准

- 用小屏看：**缩小到手机屏幕大小还好看**的，才是能交的片。放大看细节是自我安慰。
- 连续 3 张眼神都空 → 不是运气问题，是引导方式有问题，停下来换方法（见第 4 节）。
- 一组片里如果所有姿势的手都在同一个位置 → 你今天只拍了一种姿势，需要换套路（见第 3 节）。

## 1. 焦段与机位

### 1.1 各焦段的人像效果与适用场景

| 焦段 | 脸型效果 | 空间感 | 适合 | 不适合 | 现场提示 |
|---|---|---|---|---|---|
| 24mm | 鼻子被推大、脸变形严重 | 环境极强 | 大长腿、环境人像、狭小室内、创意夸张 | 特写、证件照、脸型偏圆的人 | 只拍全身且离远一点，脸尽量放在画面中心 |
| 35mm | 轻微变形，可控 | 环境强于人物 | 街拍、旅拍、环境人像、情侣抓拍、室内全身 | 大头照 | 低机位 + 靠近 = 腿长神器；但脸别贴边缘 |
| 50mm | 接近人眼，最自然 | 中性 | 半身、日常写真、纪实、家庭 | 想强调环境张力时 | 万能备胎，不知道怎么选就用 50 |
| 85mm | 最讨喜的"人像头"，脸型最正 | 轻微压缩 | 半身、特写、情绪片、婚纱 | 狭窄室内（退不开） | 首选。永远先在 85 上试，不行再换 |
| 135mm | 强压缩，脸更平更精致 | 背景成奶油 | 特写、情绪片、远距离抓拍 | 需要交代环境时 | 抽离感强，"偷看"的感觉，适合安静情绪 |
| 70-200 | 可用 200 端极致压缩 + 强虚化 | 压缩极强 | 婚纱、旅拍、儿童远处抓拍、活动 | 与环境结合的片子 | 200mm + f/2.8 是婚纱最稳的搭配 |
| 100mm 微距 | 极锐 | 无 | 眼部/嘴唇特写、戒指、细节 | 完整人像 | 细节补片用，不要拿它拍全身 |

**核心原理（为什么）**：透视只跟"拍摄距离"有关，跟焦段无关。广角让你靠近拍，鼻子离镜头近所以变大；长焦让你退远，五官到镜头的距离差被压缩所以脸变平变瘦。所以"脸大"的根因是距离近，不是镜头坏。

### 1.2 机位高度对脸型与气质的影响

| 机位 | 效果 | 适合 | 注意 |
|---|---|---|---|
| 高于眼平 30° 以上 | 眼睛变大、下巴变尖、显瘦显萌 | 女生成年人显脸小、儿童、可爱风 | 过头会"上大下小"，腿变短；不要给圆脸男生用 |
| 略高于眼平 10°～15° | 最安全的显瘦位 | 通用，尤其亚洲女性半身/特写 | 这是默认机位，不确定就用这个 |
| 与眼平齐 | 平等、真实、有力量 | 商务形象、男士、纪实、访谈感 | 显瘦效果无，靠光位和脸转角度补 |
| 略低于眼平 10°～20° | 显气场、显高、下颌线明显 | 男士、酷系、英雄感、长腿 | 女生长时间用会显男相/显鼻孔 |
| 低于眼平 30° 以上 | 压迫感、威严、夸张 | 创意、舞台、儿童（仰拍显可爱） | 容易拍到鼻孔和下巴底面，需要脸微低补 |

**为什么不建议默认平视以外的极端机位**：机位是"态度"。俯拍 = 我在看护你（可爱、弱势、亲昵）；仰拍 = 我在仰望你（崇拜、力量、压迫）；平视 = 我们是平等的（真实、可信）。选机位之前先想清楚这张片想传达什么关系。

### 1.3 拍摄距离与畸变控制

| 想拍 | 建议距离 | 建议焦段 |
|---|---|---|
| 特写（头肩） | 1.2～1.8m | 85 / 135 |
| 半身 | 2～3m | 50 / 85 |
| 七分身 | 3～5m | 50 / 85 / 135 |
| 全身 | 5～8m | 35 / 50 / 85 |
| 大长腿全身（低机位） | 3～4m，机位降到膝高 | 35 |

**实操算法**：先决定"我要拍多大的景"，然后**退到合适的距离**，再**转动变焦环去匹配**，而不是先转焦段再挪位置。距离决定透视（脸正不正、腿长不长），焦段只决定你框进多少。

**畸变急救**：
- 边缘的脸/头被拉扁 → 人物远离画面四边，居中或轻微偏离中心。
- 圆的物体变成椭圆 → 同上，广角的锅。
- 多人合影两侧的人脸变形 → 别用 24mm 挤，换成 35mm 后退，或分两组拍再接。

### 1.4 变焦镜头的人像纪律

- 宁可**退后 + 长焦**，不要**靠近 + 广角**。前者脸正，后者脸变。
- 70-200 拍人时，固定一个焦段（比如 135）连着拍十来张，不要一张一个焦段——否则一组片的空间感会散掉。
- 室内退不开时：改拍特写/半身，别硬上全身然后被广角把脸搞变形。

## 2. 摆姿的底层几何

摆姿不是背姿势，是**控制四条线的相对关系**：重心线、肩线、胯线、头线。把这四条线摆出"不对称但有平衡"的状态，人自然就好看。所有具体姿势都是这四条线的排列组合。

### 2.1 重心与支撑腿（最重要的一条）

- **永远有且只有一条主力支撑腿**。支撑腿要"直而不过伸"，膝盖不锁死；另一条腿放松、膝盖微屈、脚尖可以点地或外撇。
- **重心压在支撑腿的髋关节上**，骨盆会自然向支撑侧倾斜，胯线就出来了——这就是腰线的来源。
- 两条腿平均分力的站姿 = 罚站，是素人默认状态，必须改掉。
- **重心不能压在脚后跟上**：会往后倒、显肚子。重心应在"脚掌中前部"。
- 坐姿时支撑点是**坐骨 + 一只脚**，不要整个屁股坐满椅子——坐满会显胖、显瘫。坐椅面前 1/3，身体前倾一点。

**话术**："把重量放到后面那条腿上，前面这条腿轻轻点地就行，膝盖不要绷直。"

### 2.2 S 形与 C 形曲线

| 曲线 | 怎么做出 | 视觉含义 | 适合 |
|---|---|---|---|
| S 形 | 头向一侧倾 + 胯向另一侧顶 + 支撑腿同胯侧 | 优雅、柔美、性感 | 女性写真、婚纱、晚礼服 |
| C 形 | 头、胸、胯同向弯曲成一个大弧 | 温柔、内敛、柔顺 | 女性情绪片、孕妇、儿童 |
| 反 C / 弓形 | 身体后仰 + 胸打开 | 舒展、自信、欢快 | 婚纱、旅拍、跳跃前蓄势 |
| 折线 | 肩胯成锐角，肘部成三角 | 硬朗、有设计感、酷 | 男士、时装、街拍 |

**怎么做 S 形（口诀）**：脚一前一后 → 重心在后腿 → 胯往前腿方向顶一点点 → 上身往反方向倒一点 → 头再歪回顶胯那一侧。四步做完就是 S。

**为什么 S 形显瘦显高**：直的轮廓是一条信息量极低的线，观众的眼睛无处停留；S 形的边缘是有起伏的，眼睛会沿着起伏走，视觉上就把人"拉长"了，同时曲线的凹陷处（腰）自然地暗示了细。

### 2.3 肩线、胯线、头线的关系

- **肩线与胯线不要平行**。平行 = 呆板。夹角 10°～20° 就够。
- **头线（两眼中点连线）要与肩线产生角度**，不要把脸摆成正的。脸转 15°～30°。
- **三者理想态**：胯线向一侧倾，肩线向另一侧倾，头线回归或轻微反向——形成一个"Z"字结构，也就是常说的"扭麻花"。
- 转动是**从下往上逐级转**：脚先摆好，再摆胯，再摆肩，最后摆头。不要只转头——只转头会显得脖子短且刻意。
- **胸不要正对镜头**：胸部正对镜头 = 平面化 + 显宽。侧转 30°～45° 让身体有厚度。

### 2.4 手部"有事做"原则

手是人像里最难搞的部分。规则：

1. **手要有具体动作**：插兜、扶帽檐、拨头发、抱臂、撑栏杆、拿杯子、扶包带、摸耳环、解扣子、抱膝、托腮（用拳不用掌，掌托显脸大）。
2. **手指要分开、要放松**，不要五指并拢像把刀，也不要攥成拳头（除非是酷系）。
3. **手不要与身体轮廓重叠**：手放在身体前面会挡住腰线、让腰变宽。手放身体轮廓外或轮廓的凹陷处（腰窝）。
4. **手不要朝向镜头呈"掌心向上"的乞讨状**，也不要五指张开对着镜头。
5. **一个人身上最多两只手，两只手不要做同一件事**，也不要让手出现在脸的前面（会挡脸、抢戏）。
6. **手的高度**：手腕在腰线附近最百搭；高过下巴容易挡脸；低于胯会显得手太长。

**话术**："手插兜，大拇指留在外面搭着。""一只手摸耳朵，另一只手搭在包带上。""两只手扶着前面这根栏杆，身体往后靠一点。"

### 2.5 避免关节正对镜头

- **肘、膝、肩、胯，任何关节正面朝向镜头都会变成"一个点"或"一个方块"**，视觉上难看且显短。
- 肘关节应指向侧后或斜下方；膝关节应侧转 30° 以上；肩关节应"侧对"而非"正对"。
- **手臂不要贴在躯干上**：贴住会让手臂看起来和身体一样宽。手肘离身体 5～15cm，露出一条缝，这条缝就是"瘦"的来源。
- **不要拍"关节折角朝镜头"的姿态**（比如正面的"抱臂"），改成侧身抱臂。

### 2.6 脚位与朝向

| 脚位 | 效果 | 说明 |
|---|---|---|
| 一脚前一脚后（前后站） | 显瘦、显高、重心稳 | 最通用。前后差 20～30cm |
| 丁字步 | 优雅、纤细、显腿长 | 后脚脚尖点在支撑脚足弓处 |
| 双脚并拢直立 | 僵、显腿短 | 只在军姿/制服/正式场合用 |
| 双脚外八打开 | 稳、有气势 | 男士常用，女士慎用 |
| 交叉腿（一腿绕到另一腿前） | 极细、时装感 | 需要平衡能力，注意别站不稳 |
| 一腿抬起（靠墙/扶物） | 放松、俏皮 | 儿童和休闲风常用 |

**脚是姿势的地基**：脚摆对了，身体自然就对了。反过来，脚没摆好，上面怎么调都别扭。**永远先喊脚，再喊上半身。**

### 2.7 "三不"原则

- **不僵直**：任何一条线都是直的（脊柱、腿、手臂），画面就死。要有至少一处弯曲。
- **不对称**：左和右不能一样。手位不同、腿位不同、肩高不同、头歪向一侧。
- **不重复**：连续几张不能是同一个结构。换一张就换一个变量：换机位高度、换朝向、换手位、换视线、换景别。

**为什么**：人的眼睛对"对称"的刺激极不敏感（所以无聊），对"有变化的重复"会疲劳。三不原则本质是在给眼睛不断提供新信息。

### 2.8 摆姿的推进顺序（现场 SOP）

从下往上、从大到小，一次改一项：

1. 脚位（前后、丁字） →
2. 重心（哪条腿） →
3. 胯（顶向哪边） →
4. 躯干（侧转多少） →
5. 肩（一高一低） →
6. 手（做什么） →
7. 头（转多少、倾多少） →
8. 下巴（收多少） →
9. 视线（看哪里） →
10. 表情（说一句话逗他）

前 6 步是"骨架"，可以快速连喊；后 4 步是"表情包"，每张只微调一两项。

## 3. 全身/半身/特写摆姿库

每条都可直接照念。格式统一：**身体朝向 → 重心 → 手 → 头/下巴 → 视线 → 风格**。

### 3.1 女性 · 全身姿势（14 个）

| # | 姿势名 | 具体动作 | 适用风格 | 注意 |
|---|---|---|---|---|
| 1 | 侧身回眸 | 身体侧对镜头约 45°，重心在后腿，前脚尖点地，双手在背后轻握，头回转向镜头，下巴微收，视线看镜头 | 优雅、婚纱、礼服 | 回头的幅度别超过 90°，否则脖子会拧 |

## 4. 表情与情绪引导

### 4.1 为什么"笑一个"必然失败

素人在被要求"笑一个"时，动的是**嘴角的肌肉（颧大肌）**，但**眼睛没动（眼轮匝肌不动）**。这叫社交假笑，观众天生能识别，因为它缺少"眼睛的皱"。真笑的标志是：下眼睑上抬、外眼角出现鱼尾纹、颧骨推高。**只有真的开心，这块肌肉才会动。**

所以引导的本质不是"让他笑"，而是**让他真的有一瞬间的情绪**，然后抓住那一瞬间。

### 4.2 六种情绪的引导话术

| 情绪 | 引导方式（照念） | 身体配合 | 抓拍时机 |
|---|---|---|---|
| 真笑/大笑 | "你上次笑到肚子疼是什么事？讲给我听。"或直接开玩笑、自己先笑出声 | 身体略后仰、头微抬、肩放松 | 讲到一半、笑出来的前 0.5 秒最好，连拍 |
| 微笑 | "想着一个只有你自己知道的、觉得很得意的小秘密，别说出来。" | 嘴角自然上扬、眼微眯 | 安静地笑 1～2 秒后按快门 |
| 含羞 | "低头，眼睛看着地面，然后慢慢地、只把眼睛抬起来看我。" | 头低 10°、下巴收、肩略内收、手有事做 | 抬眼的那个瞬间，是一次性的，别错过 |
| 沉思 | "别看镜头，看那边那片云，想一件很久以前的事。" | 视线下垂、头略低、肩下沉、手托腮或抱臂 | 保持 3 秒以上，可以慢慢换角度拍 |
| 酷/冷 | "下巴微抬，用'我知道你在拍我但我懒得理你'的眼神看我。" | 下巴微抬、肩下沉后展、抱臂或插兜 | 前 3 秒最自然的冷感，久了会僵 |
| 温柔/慈爱 | 对孕妇、亲子、情侣用："看着他的眼睛，想一句你从来没说出口的话。" | 视线真切、身体向对方靠、手有接触 | 情绪上来后 2～3 秒，眼睛会变软 |

### 4.3 素人放松的 8 个实操技巧

1. **让他做一件小事**（整理衣服、往前走两步、把头发拨开）。有事做的人不会想着"我在被拍"，脸自然松。
2. **你不停地说话**。安静是最尴尬的，尴尬会写在脸上。你哪怕聊天气都行，只要嘴不停。
3. **用连拍代替命令**。不要"笑！"然后按一张，而是让他做一个连续动作（走两步、转个圈、跳一下），按住连拍，回来挑。
4. **先拍几张"废片"作为热身**。明确告诉他："前二十张肯定是废的，我们就是热身，你不用管好不好看。"——去掉压力，表情立刻松。
5. **不要在他还没准备好的时候按快门**（除了刻意的抓拍）。听到快门声会让人紧张。可以先举着相机不动，聊两句，突然在自然状态按下。
6. **给他一个具体的看的地方**。视线没有落点，眼睛就是空的。"看我的左手""看那朵花""看你自己的鞋尖"。
7. **别让他看预览**。看了预览他会开始"表演"和"分析"，眼神就不真了。你可以看，但不给他看。
8. **降低他的音量感**：你不用一直夸，但要在必要时给明确的正反馈（见 5.4）。

### 4.4 眼神方向与眼神光

| 视线方向 | 效果 | 用法 |
|---|---|---|
| 直视镜头 | 与观众建立连接、有力量 | 商务、气场、封面、证件 |
| 看镜头外 30°～45° | 自然、不尴尬、有想象空间 | 通用、写真、情绪（素人最适合） |
| 看斜下方 | 温柔、害羞、内敛 | 少女、情绪、短发女生 |
| 看斜上方 | 期待、回忆、希望 | 毕业、旅拍、孕妇 |
| 平视远方 | 坚定、疏离、纪实 | 男士、街拍、背影 |
| 闭眼 | 沉浸、享受、安静 | 情绪收尾、孕妇、情侣 |

**眼神光（catchlight）是让眼睛"活"的关键**，不是可有可无的细节。怎么做：

- 光源在人物面前偏上、偏一侧，眼珠上会出现一个小亮点。
- 用反光板/白墙/天空当成唯一光源方向，就能得到干净的大眼神光。
- 侧面光可以产生两个亮点（主光 + 补光），两个亮点会让眼睛更有神，但位置不能一左一右太散。
- **如果眼睛里没有亮点，眼睛会显得死、显疲惫**，后期补眼神光只能救一半。

**眨眼配合**：抓表情时用连拍，一定会有闭眼的废片，多拍两张。对频繁眨眼的人："我先数三下，第三下你看着镜头别动。"

## 5. 沟通与现场管理

### 5.1 拍摄前沟通清单（拍摄前 1～3 天必问）

1. **用途**：这组片子用在哪里？（社交头像 / 求职简历 / 婚礼 / 纪念 / 商用）——用途直接决定风格和裁切。
2. **风格偏好**：发 3～5 张参考图让他确认（不要只问"你想要什么风格"，素人说不清，看图最快）。
3. **不想要的**：明确排除项。"有没有绝对不能接受的风格/角度/服装？"这条比想要什么更重要。
4. **服装**：让他发 1～3 套备选的照片给你确认颜色和领型。**避免**：大面积细条纹（摩尔纹）、纯白（容易过曝/显胖）、纯黑（缺层次）、大 logo、荧光色。
5. **妆造**：自己化妆 / 工作室化妆 / 素颜；带几件配饰。
6. **身体顾虑**：主动问："有没有哪个角度或者身体部位你比较在意？"（例：觉得自己手臂粗、觉得自己脸大、刚做了牙齿）。知道了他才不紧张。
7. **时间与场地**：确认黄金时段（日出后 1 小时 / 日落前 1.5 小时）、场地是否要预约/收费、周边有没有洗手间和换衣点。
8. **体力与生理**：是否空腹、有没有需要定时休息的人（老人/小孩/孕妇）、备水和零食。
9. **交付**：张数、交付时间、是否精修、是否加水印、版权与用途。

### 5.2 现场口令与节奏

- **口令要短、要具体、要分解**。"左边膝盖再弯一点"比"放松一点"有用一百倍。
- **一次只给一个指令**。改完等他保持住，再给下一个（见 2.8 的顺序）。
- **用"我们"而不是"你"**："我们试一下往那边挪半步"比"你站错了"舒服。
- **节奏模板（一个姿势拍 8～12 张）**：
  1. 喊骨架（脚→重心→胯→侧身→手，5 秒内一口气说完）
  2. 调头与视线（"头往右一点点，下巴低一点点，眼睛看我"）
  3. 说一句逗笑/聊一句
  4. 连拍 3～5 张
  5. 微调一个变量（换视线 / 换手位 / 换机位），再拍 3～5 张
  6. "好，我们换一个姿势" → 回到第 1 步
- **每组之间给 30 秒缓冲**，让他自己活动一下。连续喊口令超过 3 分钟，人一定会僵。

### 5.3 试拍回看

- **第二组之后**，主动把 2～3 张好的给他看（最多 3 张，且必须是你挑过的）。目的：**建立信任**。素人看到一张"原来我能好看成这样"，后面会放松 50%。
- 不要给他看废片，不要让他自己翻——他会开始纠结"这张我下巴好怪"。
- 如果他对某张不满意，**不要争辩**，"这张确实不是最好的，我们换个角度再来一组"。

### 5.4 夸奖与纠正的说法

| 情况 | 不要这样说 | 要这样说 |
|---|---|---|
| 拍得好 | "好看！"（太笼统，他不知道好在哪） | "这个角度你下颌线特别好看，我们多拍几张。" |
| 表情突然很好但已经错过 | "刚才那个表情特别好！再来一次。"（再做不出来） | 不下命令，直接连拍；事后说"我刚抓到你特别好的一个状态" |
| 需要纠正姿势 | "手放下来一点，你手太僵了。" | "手搭在包带上，对，就这样，很自然。" |
| 他笑得很假 | "笑得自然一点。" | "别笑了，先深呼吸，跟我一起骂一句今天怎么这么热……"（先破掉假笑） |
| 他整个人是僵的 | "你太紧张了。" | "我们先走两步，就当散步，不用管相机。" |

**纠正的三条原则**：① 用**动作指令**替代**评价**；② 每一句纠正后面**跟一句肯定**；③ 不在他刚摆好时立刻否定，先拍一两张再调。

### 5.5 尴尬化解

- **冷场就换场地**。"走，我们去那边看看那棵树。"移动本身就能化解尴尬。
- **自己先出丑**。你可以先示范一个夸张的姿势，对方一笑，气氛就破了。
- **把相机给他看屏幕的反面**："你不用管我在拍什么，你就当我不在。"
- **允许他说"不行"**。他想休息、想换个想法，直接答应，不要硬推。硬推出来的一定是僵的。

### 5.6 时长与体力分配

| 拍摄类型 | 建议时长 | 节奏 |
|---|---|---|
| 证件照/商务头像 | 15～30 分钟 | 集中、高效，不拖 |
| 个人写真 | 1.5～2.5 小时 | 分 3～4 段，中间休息 5～10 分钟 |
| 情侣/闺蜜 | 2～2.5 小时 | 每小时休息一次，换场地就是休息 |
| 婚纱 | 4～8 小时 | 每小时休息 10 分钟，必须吃饭补水，新娘要换鞋 |
| 儿童 | 45～90 分钟 | 孩子状态好只有 30～45 分钟，必须提前布好光 |
| 家庭 | 1～1.5 小时 | 老人小孩优先，先拍最累的，最后拍轻松的 |

**关键原则**：**把状态最好的前 30 分钟留给最重要的那个人的最重要那张片**。素人的表现力是递减的，不要拿前 30 分钟拍花絮。

### 5.7 音乐与氛围

- 蓝牙音箱是性价比最高的道具。音乐能让素人的呼吸和节奏变慢，肩膀会自然下沉。
- 歌单按风格定：日系清新 → 民谣/城市流行；情绪写真 → 后摇/纯音乐；婚纱 → 轻 jazz/甜蜜流行；儿童 → 儿歌（但要控制音量，太吵会让孩子亢奋）。
- 音量保持在"能正常聊天"的程度。太大会听不清口令。
- 见面时**先聊五分钟再拿相机**。这五分钟决定后面两小时的质量。

## 6. 不同人像题材专项

### 6.1 个人写真

- **核心难点**：素人没有"镜头前的人格"，前 30 分钟全是尬的；同时你要在一组片里做出"多样性"，别拍成同一张的 100 个版本。
- **机位与焦段**：85mm 为主力（半身/特写），35mm 拍全身和环境。机位以略高于眼平 10° 为默认，特写用 135。
- **摆姿要点**：一套写真至少覆盖 5 种结构：① 正脸特写 ② 侧脸轮廓 ③ 半身带手 ④ 全身带环境 ⑤ 背影或闭眼收尾。每种结构拍 2～3 个角度。
- **引导话术**："我们先拍几张热身的，你不用管好不好看。""不用看镜头，看那边的楼顶，想点别的。""手别停，随便做点什么。"
- **常见翻车**：全是大头照没环境；全程一个机位；表情全是微笑（没有大笑、没有安静、没有侧脸）；背景杂乱抢戏；拍到后面人疲了还在硬拍。

### 6.2 情侣

- **核心难点**：两个人单独面对镜头都尴尬，凑一起更尴尬；容易出现"两个人并排站着对镜头微笑"的僵尸照。
- **机位与焦段**：35mm 抓互动（需要靠近且有环境），50mm 拍半身互动，85mm 拍特写（手、眼神、额头相碰）。
- **摆姿要点**：**永远给两个人一个"任务"**——牵手往前走、互相对视别说话、男生从背后蒙眼睛、女生回头男生站着、一起看同一个方向、一个坐着另一个从背后抱、额头相碰、共用一副耳机、一起吃一个东西。**两人身体必须有接触或明确的关系（前后、包围、依靠）**，不能各站一边。
- **引导话术**："你俩看着我，我数三下你们自己看着对方，别笑，坚持三秒。"（他们一定会笑，抓那个瞬间）"男生跟她说一句你今天没说出口的话。""你们正常走路，走的时候顺便聊最后一句。"
- **常见翻车**：只有合影没有互动细节；两个人都看镜头；身高差太大拍得别扭（用一坐一站/台阶/男生屈膝/低机位解决）；只拍甜没拍安静；衣服颜色打架（提前协调同色系不同深浅）。

### 6.3 闺蜜

- **核心难点**：人多（3 人以上）容易拍成一排傻站；笑点太低导致全是糊的/全是扭曲表情；风格不统一。
- **机位与焦段**：35mm 抓互动，50mm 拍半身，85mm 拍两人特写。人多用 35 后退，别用广角挤。
- **摆姿要点**：利用**高度差**（一坐一站、一蹲一站）、**前后错身**（一人从另一人身后探头）、**动作同步**（一起跳、一起回头、一起比手势、一起看同一个方向）、**实物互动**（一人给对方戴帽子、互相搂肩、一起举杯）。
- **引导话术**："来，一起往左走三步，走到第三步一起回头看镜头。""你们聊刚才那件事，我抓拍。"（闺蜜之间最自然的状态是聊天）"一个人低头，另外两个人看着她。"
- **常见翻车**：全员看镜头微笑；手势重复（所有人都比耶）；3 人以上排成一条直线；有人被挡住半张脸；道具只给了一个人。

### 6.4 家庭

- **核心难点**：人数多、年龄跨度大、有人（尤其老人和男的）极度不配合；每个人都在等别人先摆好。
- **机位与焦段**：35mm 或 50mm，机位略高（需要看到所有人的脸，特别是后排）。人数超过 6 人要有高度分层（站/坐/蹲/抱）。
- **摆姿要点**：**分层**是第一原则——站后排、坐中排（椅子/沙发/台阶）、蹲或坐地面前排（孩子）。核心人物（孩子/老人）放在**几何中心或三分点**，其他人都"朝向"他。给每个人一个手掌的位置（搭肩、扶椅背、抱孩子、牵手），手不空就自然。
- **引导话术**："全体看我这边，我说三二一你们一起说'茄子'——不对，说你们家最爱吃的菜。"（说食材比说茄子好笑）"爸爸把孩子举起来。""奶奶先坐好，其他人围过来。"
- **常见翻车**：有人闭眼（连拍解决）；有人被挡住（分层解决）；后排的人太小（增加高度差）；拍太久孩子哭了（先拍完最重要的组合，再拍花絮）；眼神没统一（指定一个"看这里"的目标点，比如你的手举着的玩偶）。

### 6.5 儿童

见第 7 节专项。

### 6.6 孕妇

- **核心难点**：体态在变化，孕妇容易累、容易不自信；同时要平衡"美"与"母性"，不能只有"大肚子"。
- **机位与焦段**：85mm 为主，侧身轮廓用 50mm。**机位不要过高**（会显脸大），略低或平视更能强调腹部曲线。
- **摆姿要点**：**孕期最好的角度是侧身 3/4 到全侧**——肚子曲线是主角，正对镜头会显腊肠。核心姿势：① 双手上下捧着肚子（上手在胸下、下手在腹底，形成环抱），侧身 45°；② 一手扶后腰、一手托肚子，身体后仰一点点（孕期自然站姿），侧身；③ 坐姿，双手环抱肚子，头低看肚子；④ 躺姿俯拍（手放肚子上）；⑤ 与伴侣互动：额头相碰、伴侣从背后环抱双手捧肚、伴侣亲吻肚子、两人一起看肚子。深色贴身连衣裙最能出曲线，避免松垮大袍子。
- **引导话术**："手放松地放在肚子上，像在跟他打招呼。""看着他（伴侣），想一句你以后想跟孩子说的话。""不用吸气，放松，你现在这样就很好看。"
- **常见翻车**：全程正面；手压肚子压出褶；光线从上方直射压在脸上的阴影（孕晚期本来就累，别用顶光）；穿宽松衣服看不出曲线；拍太久（孕妇 30～45 分钟就该结束）；忘了拍"孕期的手、脚、B 超单"等细节。

### 6.7 证件照与商务形象照

- **核心难点**：要求"标准、干净、像本人"，容错率极低；同时又要比证件照好看，不能是"关进监狱"的观感。
- **机位与焦段**：85mm 或 100mm，机位与眼平齐或略高 5°～10°，距离 2～2.5m。**不要用广角贴近拍**（五官会变形，看起来不像本人）。
- **摆姿要点**：
  - 正脸或轻微左侧/右侧转 10°（不转 = 呆板，转太多 = 不像证件照）。
  - 双肩一前一后约 5cm，肩下沉后展（消除圆肩）。
  - 下巴微收但不压（用"下巴向前平推一点再收回"的口令来消除双下巴，而不是"低头"）。
  - 手：'证件照不露手'，商务形象照可插兜或抱臂但要有商务感。
  - 视线：看镜头，看镜头内/外的那个"小点"（镜头正中心或稍偏 2cm），不要看镜头边缘。
  - 领口：衬衫领子要立挺，领带结要正。女性建议深色 V 领或衬衫，避免高领（显脖子短）。
- **引导话术**："下巴往前送一点点，对，然后收回来一点，停住。""肩膀往后往下，像被人往下按了一点点。""用'刚开完一个很顺利的会'的状态看我。"
- **常见翻车**：镜头太近导致鼻子变大；顶光在眼窝和鼻子下方留阴影；背景不干净或背景与头发颜色相近（头发糊进背景）；衣服太花或有大 logo；表情过硬（真笑不是证件照要求，但完全没精神也不行）；眼睛没对焦在瞳孔上。

### 6.8 古风与主题

- **核心难点**：服装和场景的"信息量"很大，人容易变成道具的一部分；手势和仪态错一点就露怯。
- **机位与焦段**：85mm / 135mm 为主（压缩背景，把环境和人压在一起）；35mm 拍环境大景。机位可以略低，配合宽袍大袖的垂坠感。
- **摆姿要点**：
  - **动势优先于静态**：甩袖、回身、提裙上行、执扇半遮面、抚琴、低头嗅花、执剑而立。古风的静态站姿非常容易僵，必须给到"动作的中途"。
  - **手部必须有道具**：团扇、油纸伞、折扇、书卷、酒壶、灯笼、剑。空手古风极难拍好。
  - **仪态**：挺胸收腹、含肩（不要耸肩）、脖子略长。女性手腕要有"兰花"的松弛感，不要五指张开。
  - **视线**：古风不常直视镜头，多用垂眸、回望、看向远方。
  - **身体的朝向要顺着衣料的走向**，让衣摆和袖子的线条在画面里形成对角或弧线。
- **引导话术**："袖子往那边甩出去，甩到一半的时候停一下。""扇子举到眼睛下面一点点，只露眼睛看我。""想象你刚从台阶上走下来，我在下面看你。"
- **常见翻车**：现代物品入镜（手表、手机、运动鞋、牛仔裤边、塑封奶茶）；妆容太现代；阴天拍深色衣服变成一坨黑影；背景建筑风格混搭；光比太大导致脸黑衣服白；动作全是"站着不动拿个扇子"。

### 6.9 街拍人像

- **核心难点**：环境不可控，路人和杂物随时入镜；光比大（阴影和直射光混杂）；拍久了被围观会尴尬。
- **机位与焦段**：35mm（经典焦段，人与环境的关系）或 50mm；85mm 用于从远处压缩街景做背景。机位可以低一点拍长腿，也可以找一个环境线条引导视线。
- **摆姿要点**：街拍的核心是"**像抓拍一样的安排**"。所有姿势都要有"正在做某事"的由头：过马路、看手机、系鞋带、买咖啡、扶栏杆看车流、靠着橱窗、翻包、抽烟（或拿杯代替）、回头。
- **引导话术**："你从那边走过来，走到这块砖的时候停一下看我。""就当我不在，你看着车流发呆。"（然后连拍）
- **常见翻车**：背景有垃圾箱/垃圾桶/违停车/别人的后脑勺；拍到路人的脸（要么虚化要么避开）；死人光（正午顶光）拍出来眼窝全黑，用阴影侧/建筑遮挡/反光板；画面里现代杂物太多导致"脏"；只拍人没拍街，失去街拍的意义。

### 6.10 旅拍

- **核心难点**：时间紧、人累、光线不可重来、机位不能反复试；同时要交代"这是哪里"。
- **机位与焦段**：双机双镜最稳：35mm（人 + 环境）＋ 85mm 或 70-200（压缩风景做人像）。**一定要拍两种照片**：环境大景（人物小、地方大）和人像特写（人物大、背景虚）。
- **摆姿要点**：
  - **利用地形**：台阶、石阶、桥、沙滩、山顶、巷子——让空间产生纵深。
  - **利用当地元素**：当地小吃、招牌、路牌、门、窗、花草、交通工具、当地人的手工艺。
  - **动作要"在路上"**：走、登、望、坐、回头、上台阶、下台阶、指远处。
  - **大场面构图**：人物放在三分点或画面 1/3 处，保持画面里的"空"（天空、海、墙面），不要把人塞满。
- **引导话术**："从这里往上走，走到第七级的时候回头看我。""看着远处那条线，想象你刚爬上来。""拿一下这杯东西，边走边喝，自然一点。"
- **常见翻车**：全是近景没有地标（回来不知道去了哪）；全是地标没有人（变成风光照）；中午顶光硬拍；行程排太满导致后面全在敷衍；道具没带（帽子、丝巾、墨镜、当地小物）；衣服与目的地不搭（古城穿运动 shorts）。

## 7. 儿童人像专项

儿童摄影只有一个核心：**你不能指挥他，你只能创造条件让他自己表现出你要的东西**。所有"看这里""笑一个"在儿童身上基本无效。

### 7.1 年龄分段行为特征与策略

| 年龄段 | 行为特征 | 拍摄策略 | 焦段/机位 |
|---|---|---|---|
| 0-1 岁（婴儿） | 大部分时间在睡/吃/哭；不会坐；颈无力（3 个月前不能竖抱） | **拍细节 + 睡姿 + 手脚**：睡姿特写、抓父母的手、小脚、睫毛、耳朵、刚剪的指甲。醒着的时候（喂完奶后 30～60 分钟）是他状态最好的窗口 | 85mm / 100mm 微距；机位与婴儿眼平（趴着或俯拍）。**闪光灯禁用，用自然光或持续光** |
| 1-3 岁（幼儿） | 刚会走会跑，坐不住超过 30 秒；不会听指令；情绪切换极快 | **抓拍为主**：走路、摔倒前、吃东西、玩玩具、看别的小孩。给一个具体的东西拿在手里，他就不跑了 | 35mm / 50mm（要跟着跑）；机位降到他的眼平或略低 |
| 3-6 岁（学龄前） | 能听懂指令 1～2 个步骤，喜欢角色扮演；开始"表演"，会做鬼脸 | **游戏化引导**："你是一只小熊，从那个洞里出来。""你能比这个树还高吗？"他会真的去做，动作就自然了 | 50mm / 85mm；机位与他眼平，蹲下来拍 |
| 6-12 岁（学龄） | 能沟通、能配合、会害羞、在意"我是不是好看" | **给任务 + 给选择**："你想在钢琴前拍还是在窗边拍？"有参与感就配合。可以适当摆姿，但要给一个动作的由头 | 85mm / 135mm；机位可以略低拍出"成长感" |

### 7.2 玩具与道具

**道具的作用是"给他一个不看你手机的理由"**，让他的注意力落在某个具体的东西上，表情就自然了。

- 通用：泡泡水（最有效，所有年龄通杀）、气球、风车、弹力球、小汽车、绘本、小狗小猫（真动物最好）、水果、帽子、雨伞、梯子/纸箱（爬进去）。
- 婴儿：柔软的毯子、摇铃、木质字母、父母的手。
- 不要：过于尖锐、有小零件（误吞）、容易掉的（会哭）、你舍不得弄坏的。

**用法**：把道具给他，然后**退后，等他忘了我**。不要举着泡泡机一边吹一边喊"看这里"——他只会看泡泡。

### 7.3 安全注意（比画面重要）

1. 婴儿趴姿下面**必须有软垫**，且全程在父母视线内。任何时候不要把婴儿放在高处边缘。
2. 不要为了构图把孩子放在窗台、桌边、栏杆上。一秒钟的转身可能出事。
3. 婴儿不要用闪光灯直射（尤其 6 个月内），改用自然光/柔光灯/反光板。
4. 不要让婴儿长时间保持非自然姿势，或把婴儿裹成"蜡烛包"拍（影响髋关节）。
5. 户外注意地面：石子、水边、台阶、车辆。要在孩子跑动的路线上先看一遍（旁边有没有马路边、池塘）。
6. 不要让家长把孩子抛得很高做"抓拍"（颈椎风险）。
7. 玩偶服/重头饰不要给婴幼儿穿（散热不良）。

### 7.4 抓拍 vs 摆拍

- **0-3 岁：95% 抓拍**。你唯一能做的准备是光位和背景，其余全部靠等。
- **3-6 岁：60% 抓拍 + 40% 引导**。用游戏把动作"引"出来，然后抓。
- **6-12 岁：可以 50% 摆拍**，但每个姿势都要给一个"任务"或"故事"。
- **永远不要让小孩为了拍照停下来站着**。孩子静止 3 秒以上，表情就散了。你要拍的是"他正在做的事"，而不是"他站着的样子"。
- 连拍是儿童摄影的主武器。孩子的有效表情只存在于 0.2 秒的窗口里。

### 7.5 家长配合

**家长是最好的"诱饵"，也是最常见的干扰源。**

- 拍之前明确分工：**让家长站在你的位置后方 30cm～1m，视线与你一致**，不要站到你对面（孩子会看家长不看镜头）。
- 让家长负责"逗"和"抱"，你负责"拍"，不要两边都逗（孩子会蒙）。
- 让家长**不要喊"看镜头笑一个"**。这是儿童摄影最大杀手。要提前明确告诉他们。
- 拍婴儿时，家长的手可以入镜（托肚子、握手），这是加分项，不要裁掉。
- 家长如果自己很紧张，孩子也会紧张。**先安抚家长**。
- 给家长明确的休息信号："接下来五分钟我想拍他一个人玩，你们在旁边坐着休息就行。"

### 7.6 哭闹处理

**原则：哭也是照片的一部分，不要慌，先判断是"情绪"还是"需求"。**

| 情况 | 判断 | 做法 |
|---|---|---|
| 刚哭，有眼泪，委屈 | 情绪 | **直接拍**。委屈的表情常常是全组片里最有生命力的。拍到他不哭了再拍笑的 |
| 大哭、尖叫、脸涨红 | 需求（累/饿/怕/疼） | 停下来。放下相机，让家长抱。不要拍，不要试图"哄好再拍" |
| 突然哭了 | 常见原因：闪光灯吓到（关闪光）、陌生人（你退后，让家长抱）、饿了/困了、衣服扎人 | 逐一排除；给他 10 分钟 |
| 断续哼哼 | 闹脾气/要东西 | 换场地或换道具。转移注意力比讲道理有效 |
| 一直哭，无法安抚 | 今天不适合 | **坦诚地跟家长说改期**。硬拍出来的东西家长也不会满意，别为了交付毁了信任 |

**哄孩子的话术**（不要用哄婴儿的语调和学龄前儿童说话）：
- "你的鞋子好酷，可以给我看看吗？"（先建立关系，不谈拍照）
- "我们来数数，看这里有几只蚂蚁。"
- "我数到三，你要不要跑过来看这个？"（给一个选择而不是命令）

## 8. 素人引导话术库

以下口令可直接照念。**注意语气要平、要慢、要有耐心**，不要用命令句。每条都尽量"指令 + 确认"成对出现。

### 8.1 站位与身体朝向

1. "来，侧身一点，身体对着那边，脸转回来看着我。"
2. "往前站半步，脚跟那条线对齐这里。"
3. "往我这边挪一点点，对，就一点点。"
4. "背对那个方向，对，就这样，别动。"
5. "你往那边走三步，走到第三步停一下。"
6. "再往左转一点，转到你能看到我右手的位置。"
7. "身体稍微转过去一点，脸回来找我。"
8. "往后退两步，好，就这样。"

### 8.2 重心与脚位

9. "重量放在后面那条腿上，前面这条腿轻轻点地就行。"
10. "前面这只脚的脚尖点一下地，放松，不用使劲。"
11. "后脚撇开一点，对，不用绷直。"
12. "别站太直，膝盖放软一点。"
13. "重心往前一点点，别站在脚后跟上。"
14. "两只脚别并在一起，前后错开一点。"
15. "腰放松，肩膀往下沉。"
16. "想象你刚走完一段路，很随便地站着。"

### 8.3 手位

17. "手插兜，大拇指留在外面搭着。"
18. "两只手扶在前面这根栏杆上，身体往后靠一点。"
19. "一只手摸耳朵，另一只手搭在包带上。"
20. "手别垂着，随便做点什么——理一下袖子也行。"
21. "手肘离身体远一点，别贴着。"
22. "手放腰上，对，就是这个位置。"
23. "手拿一下这杯东西，自然一点，不用举高。"
24. "手在身前交叠，放松，不要握紧。"
25. "手从头发里过去，慢慢拨，对，就这样。"
26. "一只手托着下巴，用拳头，轻轻搭着就行。"

### 8.4 头位与下巴

27. "头往右偏一点点，对，就一点点。"
28. "下巴再低一点点，别低多了，好，停住。"
29. "下巴往前送一点，然后收回来一点——对，就是这个位置。"（消双下巴）
30. "头别正对着我，往旁边转一点。"
31. "脖子别前伸，往回收一点。"
32. "头往左歪一点，像听别人说话那样。"
33. "脸颊往我这边转 30 度左右，对。"

### 8.5 视线

34. "看我的左手，对，就看着它。"
35. "眼睛看我，不用笑，就这样看着我就行。"
36. "看镜头外面，四十五度的方向，对，就看着那棵树。"
37. "低头，看着地面，然后慢慢地、只把眼睛抬起来看我。"
38. "不用看镜头，看远处那条线，随便想点别的。"
39. "闭上眼睛，深呼吸一下，好，慢慢睁开。"

### 8.6 表情与情绪

40. "不用笑，先放松——来，深呼吸，肩膀放下来。"
41. "想着一个只有你自己知道的、很得意的小事，别说出来。"
42. "你上次笑到肚子疼是什么事？讲给我听听。"
43. "下巴微抬，用'我知道你在拍我但我不太想理你'的眼神看我。"
44. "看那边，想一件很久以前的事。"
45. "别看我了，看那边，我数三秒你们自己看着对方，别笑。"
46. "别紧张，我们先拍几张废片热身，前面二十张都不算。"

### 8.7 复合口令（一口气说完，用于换姿势）

47. "侧身，重心放后腿，前脚尖点地，手插兜露拇指，下巴微收，眼睛看我。"
48. "往那边靠墙站，一条腿屈起来点着墙，双手插兜，肩放松，看我。"
49. "转身背对我，手插兜，头侧过来一点，露出侧脸，看远处。"
50. "坐下来，坐台阶前沿就行，一条腿伸出去，手撑在后面，身体往前倾一点。"
51. "站起来往前走，走的时候自然摆臂，走到我面前的时候顺便看我一眼。"

### 8.8 使用提示

- **口令要拆开给**，不要一次说完 47、48 那种复合句给素人（复合句是给有经验的模特的）。素人用 1～46 的单条口令，一次一条，等他做完再给下一条。
- 每条口令后面**停 1～2 秒**，等他做完，必要时重复一遍（用同样的词，不要换说法）。
- 说**"对，就这样"**比说"好"更能让他保持住——"好"会让他以为拍完了然后松掉。

## 9. 翻车与修正诊断表

遇到问题先在这张表里找症状，再按"修正"执行。修正顺序建议从下往上：先动最简单的（机位、距离），再动复杂的（换焦段、换场景）。

| # | 症状 | 原因 | 修正 |
|---|---|---|---|
| 1 | 脸大 | 机位过高 + 广角近距 + 脸正对镜头 | 换 85mm、机位降到略高于眼平 10°、脸侧转 15°～30° |
| 2 | 双下巴 | 低头 / 脖子前伸 / 机位太低 | 下巴"前推再收"，机位略高 10°，脖子往回收 |
| 3 | 脖子短/粗 | 高领 + 正对镜头 + 头正 | 换 V 领/低领，脸侧转，机位略低一点让脖子露出长度 |
| 4 | 鼻子大 | 广角近距正面拍 | 退远 + 长焦；脸转 3/4，鼻子会藏在轮廓里 |
| 5 | 显胖 | 正面站、肩线与胯线平行、手臂贴身体 | 侧身 30°～45°、手肘离身、露出腰线、重心压一条腿 |
| 6 | 腿短 | 高机位俯拍、广角远距 | 机位降到膝/腰高、用 35mm 靠近、腿往画面下角延伸 |
| 7 | 手臂粗 | 手臂贴躯干 + 手肘正对镜头 | 手肘外展留缝、手放腰上做三角、侧转避开正面 |
| 8 | 站得像罚站 | 两条腿平均受力、双手垂两侧、头正 | 移重心到一条腿、手有事做、脸侧转、肩一高一低 |
| 9 | 假笑 | 被要求"笑一个" | 停拍，先逗笑/聊天，用连拍抓真笑瞬间 |

| 15 | 背景抢戏 | 背景太亮/太艳/杂物多 | 加大光圈、换更长的焦段、换个纯色背景、让人离背景更远 |

| 19 | 手挡腰线 | 手放在腰最宽处 | 手往上到腰窝、或往下到胯侧、或干脆插兜 |

| 21 | 腿显短且粗 | 机位高 + 腿正面朝镜头 | 低机位 + 丁字步/交叉腿 + 前后错开 |

| 28 | 鞋子太抢戏 | 运动鞋/亮色鞋入镜 | 裁掉脚部，或换鞋/换浅色鞋，或者让人坐/蹲 |
| 29 | 衣服颜色与背景撞 | 未提前确认服装与场地 | 提前沟通服装色系；现场用反光板/ 换位置拉开明度 |
| 30 | 整体没气场 | 机位过高、光太平、姿势太软 | 机位降到眼平、加大光比、让人物做有张力的动作 |
| 31 | 素人越来越僵 | 一直没给正反馈 | 停下来给他看 2～3 张好的，建立信心 |
| 32 | 儿童拍不到正脸 | 只看你、或者一直跑 | 让家长站到你身后、用道具吸引、连拍等他抬头 |
| 33 | 儿童满脸不高兴 | 困了/饿了/被打断 | 立即停拍，交给家长休息 10 分钟，不要硬拍 |
| 34 | 合影有人被挡 | 排成一条直线 | 分层（站/坐/蹲）、前后错身、增加高度差到 15cm 以上 |
| 35 | 合影无人看镜头 | 多个"看这里"的目标 | 只留一个目标点（你的手/玩偶/举起的道具），其他人也看它 |
| 36 | 婴儿没法竖抱却要竖着拍 | 月龄不足 3 个月 | 改拍趴姿/躺姿/俯拍，家长用手托住头颈 |

### 9.1 诊断的使用顺序

遇到问题按这个优先级排查，**不要一上来就换镜头**：

1. **先看光**（眼窝黑、眼睛死、背景抢戏 → 多数是光的问题，不是姿势问题）
2. **再看机位**（脸大、腿短、显宽、没气场 → 先动机位高度和距离）
3. **再看姿态**（站得像罚站、显胖 → 重心的锅）
4. **再看表情**（假笑、眼神空 → 引导方式的锅）
5. **最后才换器材/换场景**（焦段、背景、场地）

**为什么不先换器材**：80% 的"不好看"是机位和姿态造成的。换镜头能解决的只有"透视变形"和"背景虚化"两类问题；换镜头解决不了"她站得像罚站"。
