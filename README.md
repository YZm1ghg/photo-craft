# photo-craft · 摄影专业 Agent

一位懂行的摄影指导——**给数字不给形容词**；若你自备书库，还能**回溯到原书页码**。

---

## 安装

### 方式一：下载发布包（推荐）

到 [Releases](https://github.com/YZm1ghg/photo-craft/releases) 下载
`photo-craft-v1.0.0.zip`，解压后放进你的插件目录：

```
<你的插件目录>/photo-craft/
```

解压后应能看到 `.zcode-plugin/`、`commands/`、`skills/`、`agents/`、
`README.md`、`LICENSE`。

### 方式二：git clone

```bash
git clone https://github.com/YZm1ghg/photo-craft.git
```

放到插件目录下即可，效果与方式一相同。

### 依赖

**无第三方依赖。** 技法能力（人像/用光/构图/后期/商业/婚礼儿童）开箱即用，
不需要 Python、Node 或任何包管理器。

> 只有想自建检索书库（拿到"书名+页码"出处）时，才会用到
> `corpus/` 里的 Python 脚本，详见下方「自己搭一个书库」。

### 验证安装

装上后，输入 `/photo` 或直接说"这张照片哪不对"。
若能看到本技能被触发，即为安装成功。

## 五层诊断法

用户说"这张照片哪不对"时，按顺序排除，每层都落到具体动作：

1. **光** —— 光位太正？光比不足？光质太硬？色温不对？
2. **机位／焦段** —— 机位高度？焦段畸变？距离太近？
3. **姿态／表情** —— 僵直？对称？下巴角度？眼神散？
4. **构图／背景** —— 主体不突出？背景抢戏？裁切不当？
5. **后期** —— 影调平？色彩脏？质感丢失？

**输出**：一句结论 → 2-3 个具体动作 → "为什么"。

## 版权与使用说明

本插件**只包含原创的提炼笔记与工具脚本**：

- **不含任何图书正文**。发布包中**没有**任何书籍的 OCR 文本、摘录汇编或电子书副本。
- `references/` 与 `knowledge/` 是根据摄影专业知识整理的方法论笔记，
  把领域知识重新组织成**可直接执行的动作**（参数、光位、话术、步骤），不是原文抄录。
- `corpus/` 是**检索工具**（`tools.py`／`extract_gpu.py`／`make_cards.py`），
  不含任何数据。检索层需要**你自己准备书库**。

**要使用"原文出处"功能，请自备合法获得的图书副本。**
请使用你**依法持有**的书籍（自行购买、图书馆借阅或其他合法途径），
并遵守当地著作权法律。本插件不提供、不代为分发任何书籍内容。

## 自己搭一个书库（可选）

插件的技法能力开箱即用，不依赖书库。只有当你想要**"书名 + 页码"级别的原文出处**时，
才需要自建检索层：

```bash
# 1. 把你合法获得的摄影书 PDF 放进一个目录
export PHOTO_BOOKS_DIR="/path/to/your/photography/books"

# 2. 抽取成可检索文本（用 GPU 抽取，详见 corpus/BUILD.md）
python corpus/extract_gpu.py

# 3. 建索引、生成卡片
python corpus/tools.py index
python corpus/make_cards.py
```

**重建建议用 GPU** —— CPU 会慢很多（量级差别，详见 `corpus/BUILD.md`）。
GPU 环境的几个坑全部记在 `corpus/BUILD.md`。

### 源 PDF 目录的解析顺序

`tools.py` 按此顺序找源 PDF（只影响**书号**，检索读 `out/` 不受影响）：

1. 环境变量 `PHOTO_BOOKS_DIR`
2. `corpus/config.json` 里的 `books_dir`

**没有内置默认路径** —— 必须由你指定。未指定时 `list`／`status` 会提示源目录未设置，
此时书号从 `out/index.json` 恢复，`read <书号>` 仍正常。

## 已知边界

- **部分 PDF 是原生文字层**，未走 OCR；**部分扫描件**走 OCR。
- **OCR 有少量错字**，尤其繁体竖排。引用时若错字影响理解，应说明"原文 OCR 此处为…"。
- **有些具体手法在你自己的书里可能检索不到**（0 命中）——这时要明说"库内未检索到"，
  不要硬凑出处。
- 未自建书库时，**不给原文出处**，只给专业建议。
